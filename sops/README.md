# 모의 SOP 카탈로그

`mock-catalog-v1.json`은 검색·원문 인용·개정판 필터링을 시험하기 위해 프로젝트에서 작성한
**가상의 문서**다. 제조사, 연구실, 현장의 승인된 SOP가 아니며 생산품의 판정이나 설비 조치에
사용할 수 없다. 문서 ID와 개정판, 유효 기간, 제품, 사람이 직접 선택한 결함 유형을 함께
확인한다. 이미 폐기된 개정판은 검색하지 않는다.

이 파일은 이미지나 모델 출력으로부터 결함 원인을 생성하지 않는다. 사용자가 유형을 모르면
근거를 제시하지 않으며, 문서가 없거나 유효 개정판이 중복되면 결과를 보류한다.
