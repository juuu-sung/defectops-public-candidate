## 연구실에서 확인할 내용

Windows의 기존 모델·정상 및 불량 예측 캐시·Q90 저장 지도·원본·승인 복구 파일은
실행 시 지문을 확인한다. 이 환경에서 해당 파일이나 Windows PowerShell 실행을 직접 검증하지 않았다.
원시 지도는 전달받은 ZIP에 없으므로 아직 미탐 원인이나 추가 학습 효과를 판정하지 않았다.

진단은 새 학습, 새 모델 추론, 임곗값 변경, 서비스 전환을 하지 않는다.
정상 원본64→256장 확대와 반복 연장은 별도 검토 제안이며 현재 실행기에 포함하지 않는다.
