# EfficientAD 저장 지도 진단 실행 준비

2026-10-04. 직전 고정12장 검출0/12 결과의 원인을 좁히기 위한 CPU 진단이다.
사용자의 후속 진행 동의에 따라 구현했다. 새 모델 실험이나 정확도 개선 결과가 아니다.

## 범위

- 직전 동일12불량, 개발 고반응3장, 보정 고반응3장, 경고 기준 정상1장, 중앙 점수 정상1장.
- 총20사진의 원본·ST·AE·합성·상위656픽셀을40개 카드와 HTML로 연결한다.
- 기존 점수·보정 계약을 재현하고 합성 상위656위치의 ST/AE 기여도를 분리한다.
- 새로운 추론·학습·임곗값 변경·미선택 시험 이미지 열람·서비스 교체는 없다.
- 0006의 사진 전체 위치 통계 제외와0054의 기존 승인 복구 예외를 유지한다.

## 구현 확인

- 실제 수령 ZIP에서 고정20장 명단을 재현했다. 정상 기준 사진은0217, 중앙 사진은0469다.
- 학습 소스137개·평가 소스141개 지문은 변경0이다. 새 진단 파일을 과거 실행 identity에 추가하지 않았다.
- 이전 자료에서 원본·마스크 provenance와 전체 cohort가 평가 계획과 정확히 일치함을 확인했다.
- 신규 CPU 테스트15개: 부호 보존, 동일 상위픽셀 기여도 합산, 동점의 GT 겹침 범위,
  손상 마스크 예외, 승인 복구 PNG 경로, 지도·receipt·점수 재현, 변조 거부, CLI 경로,
  카드·ZIP 생성, 완료 결과 재사용, 중단 카드 보존·재개를 검증했다.
- 모의 지도로 생성한1280×2144 카드의5개 열·6개 영역·라벨을 직접 확인했다.
  실제 연구실 지도에 대한 시각 판독은 아직 수행하지 않았다.
- 전체 pytest747개·52 subtest 통과(102.45초). 신규15개도 별도 재실행해 통과했다.
  기존 의존성 사용 중단 예정 경고1개와 의도적 중복 ZIP 검사 경고2개가 있었으며 실패는 없다.
  실제 Windows PowerShell은 이 Mac 환경에서 실행하지 못했다.

## 연구실 실행과 다음 판단

[실행 안내](../docs/mpi-efficientad-map-diagnostics-v1.md)의 명령으로 기존 원본과 저장 지도를 읽는다.
GPU 작업이 아니며 같은 입력 폴더에 쓰는 작업만 동시에 실행하지 않는다.
완성된사진은 원자적으로 저장하고 재실행 시 지문을 재확인한다. ZIP에도 모든 전달 파일의 지문을 넣는다.

결과 ZIP을 받아 결함 반응 자체·지도 결합·점수 집계·정상 보정 영향을 구분한다.
진단만으로 과적합이나 학습 부족을 확정하지 않으며, 다음 변경은 증거를 확인한 뒤1개만 결정한다.
