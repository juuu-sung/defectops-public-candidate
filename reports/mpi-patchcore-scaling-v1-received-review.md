# MPI PatchCore 정상 256장 확대 결과 검토

검토일: 2026-10-08

정상 학습 원본을 64장에서 256장으로 늘린 PatchCore는 관찰된 불량 55장을 모두 검출했다. 기존 Q90의 미탐 0019·0024를 추가 검출하면서 기존 53장과 고정 회귀검사 12장을 모두 유지했다. 그러나 별도 정상 256장의 오경보가 14장에서 16장으로 늘었고 보정 민감도 목표도 통과하지 못했다. **개선된 연구 후보로 보존하되 운영 모델로 채택하지 않는 것이 적절하다.** 기존 Q90·서비스·자동 PASS 정책은 변경하지 않았다.

## 비교 결과

| 항목 | 기존 Q90 64장 | 확대 후보 256장 |
| --- | ---: | ---: |
| 불량 검출 | 53/55 (96.36%) | 55/55 (100%) |
| 미탐 | 2 | 0 |
| 기존 검출 손실 | 기준 | 0 |
| 정상 시험 오경보 | 3/54 (5.56%) | 1/54 (1.85%) |
| 별도 정상 검증 오경보 | 14/256 (5.47%) | 16/256 (6.25%) |
| 사진 AUROC | 0.994613 | 1.000000 |
| warm 평균 원본사진 처리 | 1.153160초 | 1.153045초 |
| warm p95 원본사진 처리 | 1.160192초 | 1.163377초 |

AUROC는 불량55장과 정상54장에 한정되며 별도 정상256장을 포함하지 않는다. 55/55는 이미 반복 관찰한 표본의 탐색·회귀검증 결과이고, 미래 불량을 전부 검출한다는 보장이 아니다. 정상54장과 정상256장을 합치면 양 모델 모두 오경보17/310이지만 서로 다른 정상 집합의 변화가 상쇄된 것이므로 각각의 결과를 유지한다.

사전 정확도 목표 중 기존 검출 보존 및 오경보≤2/54는 통과했다. 오경보≤12/256은 16장으로 실패했다. 미탐 개선은 확인됐지만 전체 정확도 목표 통과로 표현하지 않는다.

## 학습과 실행 조건

- 정상 원본256장 × 12영역 = 3,072타일. 기존64장을 포함한 고정 명단이다.
- 전체 후보3,145,728개에서 대표78,643개를 선택했다. 최종 bank는 기존과 같은 78,643×768이다.
- 최종 선택 목록은 기존64장 출신19,633개, 추가192장 출신59,010개이며 256장 모두에서 대표가 선택됐다. 이는 구성 확인이지 각 사진의 성능 기여도 추정은 아니다.
- 정상 개발128장과 보정169장은 가중치/특징 bank 구성에 섞지 않았다. 학습256장과 개발·보정·별도 정상검증의 원본 ID 교집합은 0이다.
- 공식 eps=0.9를 유지하면서 후보 수 증가로 투영 차원은335→369가 됐다. 데이터 수만의 엄밀한 인과 분리나 모든 난수에서의 우월성을 입증한 실험은 아니다.
- 학습·보정·재로딩 3,530.37초(58.84분), 평가611.09초(10.18분). 각 실행 시도는 완료1회, 오류0회다.
- 학습 과정 RAM 표본 피크3.388GiB, PyTorch GPU allocated 피크4.434GiB, reserved 피크4.529GiB, 장치 전체 사용 표본 피크6.389GiB. 장치 전체 사용과 PyTorch reserved는 다른 범위다.
- 평가 과정 RAM 표본 피크2.618GiB, allocated2.668GiB, reserved2.928GiB. 두 모델을 순차 실행한 전체 평가 피크이지 후보 단독 사용량은 아니다.

시간 측정은 원본1장당12영역 읽기·검증·디코딩·전처리·GPU 추론·지도 전송·상위1% 집계를 포함한다. 모델 로딩, 지도/JSON 저장, HTTP/UI는 제외한다. 같은 정상20장을 3회 측정했으며 이는 60개의 독립 제품이 아니다. 최종 bank 크기를 유지한 조건에서 이번 관측 속도 차이는 매우 작다.

## 새로 검출한 두 사례의 의미

두 사진 모두 최종 경고를 결정한 영역은 grid3-2이며 해당 영역에 실제 GT 결함이 있다.

| 사례 | 기존 원점수 | 기존 영역 환산 경고선 | 새 원점수 | 새 영역 환산 경고선 |
| --- | ---: | ---: | ---: | ---: |
| defect/0019 | 41.549653 | 41.695899 | 41.983334 | 40.691525 |
| defect/0024 | 41.000721 | 41.695899 | 41.692117 | 40.691525 |

원점수는 영역 지도의 상위1% 평균이다. 환산 경고선은 `정상 중심 + 정상 폭 × 사진 경고선`이다. 두 모델의 정규화 사진 경고선2.316961과3.001444만 직접 비교하면 잘못 해석할 수 있다. 정상 분포의 중심과 폭도 달라졌기 때문이다.

새 모델에서 두 결함의 원점수가 조금 높아졌고, 정상 자료로 계산한 이 영역의 경고 경계가 낮아져 둘 다 검출됐다. 기존에도 결함 위치 반응은 있었으므로 완전히 새로운 위치 신호를 처음 학습했다고 단정하지 않는다. 불량 정답에 맞춰 경고선을 사후 조정한 결과는 아니다.

grid3-2 상위656픽셀에 포함된 결함 픽셀은 0019에서384→398/GT552, 0024에서435→422/GT576이었다. 사진 검출 개선이 모든 위치 지표의 일관된 개선을 뜻하지는 않는다.

불완전 GT인0006을 제외한313개 GT 양성타일에서 상위656픽셀과 GT의 겹침 하한이0인 타일은47→25개, 타일별 위치 AUROC 단순 평균은0.93786→0.96020이다. 이는 내보낸 위치 요약의 집계이며 전체 pixel AUROC나 독립 제품313개의 성적이 아니다. 0006은 사진 정확도 평가에는 포함했다.

## 남은 오경보와 보정 불안정

정상 시험의 기존 오경보0012·0023·0046은 해소됐지만0018이 새 오경보가 됐다. 별도 정상검증에서는0812·0970이 해소되고0412·0853·0276·0961이 새 오경보가 됐다. 정상 라벨을 임의 변경하거나 이 사례들을 삭제하지 않는다.

정상 자료를 복원추출해 같은 산식을 다시 계산한 민감도 검사600회는 모두 유효했다. 아래는 각 조건200회에서 검출 수의 2.5/50/97.5백분위다.

| 다시 뽑은 정상 자료 | 기존 Q90 | 확대 후보 |
| --- | --- | --- |
| 개발128장만 | 5.975 / 52 / 55 | 35.95 / 55 / 55 |
| 보정169장만 | 45 / 53 / 55 | 50 / 55 / 55 |
| 개발과 보정 모두 | 3 / 51 / 55 | 24.975 / 55 / 55 |

중앙값과 하단은 개선됐지만 개발 자료를 다시 뽑는 조건에서는 목표인 하위2.5백분위≥50을 충족하지 못했다. 양쪽 재표집의 오경보 상위97.5백분위도7/54·28.025/256으로 한도5·25를 초과했다. 세 조건 모두 전체 안정성 목표는 실패했다. 소수는 백분위 보간값이며 모집단 성능 신뢰구간이 아니다.

실제 양쪽 재표집 최저 검출은5/55(시행19), 개발만은24/55(시행194), 보정만은42/55(시행10)였다. 단일 최악값이 전형적인 성능은 아니지만 여전히 큰 흔들림이 존재함을 보여준다. 개발 정상의 영역 중심·Q90 폭과 상위 정상 점수의 영향은 후속 원인 분석 대상으로 남긴다.

## 수령 검증

입력: `mpi-patchcore-scaling-v1.zip`

- ZIP SHA256: `976601795064eba599f25f6641695c0df60988c04e6c3cd4d03180900cc62c7d`
- ZIP CRC, 중복/위험 경로,22개 payload SHA256 일치.
- plan 및 실행 소스205개 LF 지문, 이전 승인 ZIP의 고정256장 명단 일치.
- 단계 영수증1,345개의 자체 해시와 실행 identity 일치. 특징256개, 투영49개, 선택80개, 모델1개, 정상 예측594개, 평가 예측365개.
- 예측 영수증959개와 내보낸 sample·사진 명단 해시 일치.
- 대표78,643개 인덱스 중복 없음·범위 정상, 선택 저장 단계0/1000…78000/78643 확인.
- 정상297장 재로딩 점수 차이0, 판정 변화0 재계산 일치.
- 정상 자료에서 산출한 경고 계약, 두 모델 전체 판정·증감 사례·AUROC,600회 동일 재표집·요약 및 warm 통계 재계산 일치.
- 모델 SHA256 기록: `ee3ba8d57a1100f0ce97e0baaf431cc0c5af8cde0951505582b3cba2d50a0e25`.

Windows 모델 실물·특징 배열·선택 단계 최소거리 배열·전체 이상 지도는 ZIP에 없다. 해당 파일의 기록된 해시를 대조했지만 Mac에서 그 파일 실물의 해시를 다시 계산하거나 GPU 재추론·선택 전 과정·픽셀 지표를 독립 재실행한 것은 아니다. 평가 시작 정상8장 gate는 실행기에 있으나 해당 별도 결과는 이 ZIP에 없으며, 제공된 baseline gate 및297장 reload 기록과 구분한다.

## 다음 단계 제안

1. 현재 모델·정상 보정 산식·경고선을 고정해 개선된 연구 후보로 보존한다. 기존 Q90과 서비스는 그대로 둔다. 이번 결과만으로 재학습·경고선 변경·운영 승인을 하지 않는다.
2. 저장된 점수와600회 재표집 기록으로 안정성 저하를 일으킨 정상 사진·영역·중심·폭·최종 경고선 변화를 한 번에 분석한다. 우선 GPU 재학습은 필요 없다.
3. 새 오경보5장과 정상 고점수 사례의 지도·최근접 정상 참조를 확인한다. 외관 다양성 문제인지 점수 보정의 민감도인지 구분한다. 필요한 그림만 연구실 저장 지도에서 내보낸다.
4. 근거가 모이면 한 가지 보정/참조 변경을 사전 고정해 비교한다. 이미 본 불량55장을 이용한 경고선 탐색은 독립 검증으로 포장하지 않는다. 개발에 사용한 정상검증256장도 그 이후의 독립 평가자료로 재사용했다고 주장하지 않는다.

이번 결론은 후보 폐기가 아니라 **미탐 개선을 보존하면서 오경보와 보정 안정성을 해결하는 단계로 이동할 가치가 있다**는 것이다. 새 GPU 실행 명령은 이 검토에서 추가하지 않았다.
