# MPI PCB 영역별 정상 대표 균형 비교 결과

검토일: 2026-10-08

## 결론

실행은 정상 완료됐다. 불량 55장 검출은 유지했고 정상 보정 표본 변화에 대한 검출 민감도는 개선됐다. 그러나 정상 오경보가 늘었고 결함 위치 구분이 약해져 이번 후보는 현재 조건으로 채택하지 않는다. 정확도 목표와 전체 안정성 목표 모두 미달이다. 기존 모델·경고선·서비스는 변경하지 않는다.

이미 관찰한 MPI 자료에 대한 탐색·회귀 비교다. 독립 일반화 성능이나 생산 승인 근거가 아니다.

## 비교 조건

직접 기준선은 정상 학습256장·개발256장 보정을 사용한 기존 전역 greedy 모델이다. 최초 정상64장 Q90 모델과 혼동하지 않는다.

- 학습256장×12영역, 후보3,145,728개, 특징768차원과 투영369차원 캐시는 동일하다.
- 대표 총78,643개를 유지한다. 기존 영역별4,694~11,648개 대신 첫7영역6,554개·뒤5영역6,553개를 독립 선택해 합쳤다.
- 추론은 여전히 전체 대표를 검색한다. 같은 영역에만 검색을 제한하지 않는다.
- 정상 개발256장·보정169장과 점수 산식은 동일하며 새 모델 점수로 별도 보정한다. 시험·검증·오경보 사진을 대표 선정에 넣지 않는다.

## 보정 표본이 달라질 때의 변화

같은 정상 재표집 인덱스로600회 계산했다. 불량55장 전부를 유지한 경우는532/600→591/600으로 늘었다. 이는 같은 관찰 자료의 민감도 계산이지600개의 독립 시험 또는 일반화 확률이 아니다.

| 정상 자료 변경 범위 | 전부 검출한 횟수 기존→후보 | 최저 검출 수 기존→후보 |
| --- | ---: | ---: |
| 개발자료만200회 | 188→199 | 39→51 |
| 보정자료만200회 | 179→199 | 42→54 |
| 둘 다200회 | 165→193 | 32→50 |

둘 다 바꾼 검출 수의2.5~97.5백분위 범위는43.975~55에서54~55로 좁아졌다. 하지만 정상54장의 오경보 상단은8.025장으로 허용5장을 넘는다. 보정자료만 바꾼 경우도 정상54장·256장 오경보 상단9장·26장으로 목표5장·25장을 초과했다. 개발자료만 변경한 안정성 조건은 통과했지만 전체 안정성 목표는 통과하지 못했다. 이 범위는 재표집 분포의 백분위이지 독립 성능 신뢰구간이 아니다.

약한 불량0024의 자기 경고선 대비 여유는0.2957→1.0743으로 커졌다. 이 불량보다 높은 정상검증 사진도14→8장으로 줄었다. 유용한 순위 개선 신호지만 이 불량 점수로 경고선을 다시 맞추지는 않는다.

## 결함 위치 구분은 약해졌다

GT 사용 가능한54개 불량 사진의 결함 포함313타일에서 영역 내 pixel AUROC를 단순 평균하면0.9602→0.9244다. 50타일 상승·263타일 하락했다. 이는 전체 픽셀을 합쳐 계산한 pooled AUROC가 아니며313타일도 독립 사진313장이 아니다.

상위656픽셀에 포함되는 GT 비율의 하한을 타일별 평균하면0.2946→0.2683이다. 이 지표는 고정 픽셀 경고선의 recall이나 사진 미탐률이 아니다.

하단grid4-1의 평균 위치AUROC는0.9459→0.8749, grid4-3은0.9331→0.8300으로 낮아졌다. grid3-2는약0.9970을 유지했다.

예를 들어 불량0024의grid3-2는 상위656픽셀과GT 교집합422→431로 유지·개선됐다. 반면grid4-3은34→0, 위치AUROC0.9328→0.7961이다. 결함 신호가 완전히0이라는 뜻이 아니라 높은 점수 순위에서 밀려났다는 뜻이다. 사진은12영역 중 가장 높은 점수로 경고하므로55장 전부에 경고하면서 일부 결함 위치는 더 나쁘게 표시할 수 있다.

두 하단 영역의 대표 수가 줄었다는 사실과 하락 방향은 부합하지만, 대표 수 감소가 단독 원인이라고 확정하지 않는다. 할당이 늘어난 영역에서도 하락이 있었다. JSON 지도 통계를 분석한 결과이며 실제 새 지도 이미지의 시각 검토는 아니다.

## 새 오경보는 원점수 상승만으로 설명되지 않는다

같은 후보 우승 영역에서 원점수와 원점수 단위 경고 경계(center + scale × threshold)를 비교했다.

| 정상 사진과 영역 | 원점수 기존→후보 | 원점수 경고 경계 기존→후보 |
| --- | ---: | ---: |
| good0021 grid2-2 | 41.0699→40.9345 | 41.3150→40.7476 |
| good0028 grid3-2 | 39.7206→39.4969 | 41.0298→39.1039 |

두 사진은 원점수가 내려갔지만 경고 경계가 더 낮아져 새 경고가 됐다. 따라서 모든 새 오경보를 정상 특징 부족으로 설명할 수 없다. 정상 자료에서 산출한 중심·폭·사진 경고선의 결합도 영향을 준다. 두 모델의 정규화 경고선 숫자만 직접 비교해서 원인을 단정하지 않는다.

## 실행 비용

정상 대표 선정·보정·재로딩을 포함한fit 기록은1,408.06초(약23분28초), 평가 기록은609.46초(약10분9초)다. 합계 약33분38초는 기록된 두 시도의 합이며 실행기 전체 벽시계 시간과 동일하다고 보장하지 않는다.

fit RAM 표본 최대3.63GiB, GPU allocated 최대2.67GiB·reserved 최대2.93GiB이며 자원 오류 없이 완료했다. warm은동일20사진×3회·사진당12타일이다. 검증된 이미지읽기/해독·전처리·GPU·지도전송·점수집계를 포함하고 모델초기화·파일저장·HTTP는 제외한다. 약0.7% 평균 차이는 속도 개선으로 주장하지 않는다.

## 무결성과 검증 범위

- ZIP CRC·중복 없는24개 항목 구성·manifest의23개 payload SHA256을 확인했다.
- 현재 고정 소스218개와 부모 자료로 실행계획을 재구성해 첨부계획과 일치했다.
- 개발256·보정169·시험109·검증256의790개 첫 점수와 역할을 확인했다.
- 정상 보정계약, 전체 판정·비교, 재로딩425개 점수 비교, 600회 민감도 기록을 재계산해 첨부 결과와 일치했다. 재로딩 점수차이는0이다.
- 대표78,643개 중복·범위·영역별 수와96개 선택 진행기록 연결, 1,215개 예측기록의 서명·출처 연결을 확인했다.
- 이전 결과와 겹치는63사진의기준선756타일 지도 통계는 이전 ZIP과 정확히 일치했다.
- 모델실물·특징캐시·최소거리배열·이상지도 배열은 첨부되지 않았다. 실제 greedy 선택·모델텐서·픽셀 통계를 Mac에서 다시 실행해 검증한 것은 아니다. 비기준표146텐서 불변과선정 원특징 일치는 연구실 기록이다.

## 다음 판단

이번 균등 배분 후보를 현재 조건으로 채택하지 않는다. 개선된 검출 민감도 근거와 모델은 연구자료로 보존한다. 전역 선택 모델 역시 운영 승인 모델이 아니다.

재학습이나 할당량 반복 조정보다 저장 결과를 이용한 한 번의 대조를 제안한다. 신규 오경보8건(시험3·검증5)과 하단 결함 위치 악화 사례를 원본·GT·두 모델의 같은 색 기준 지도로 묶어 본다. 정상의 어디에 반응하는지와 실제 결함이 높은 점수에서 밀리는지를 확인하고, 정상 학습자료에서의 대표 포괄성 근거와 연결해 다음 변경 여부를 결정한다. 알려진 불량 점수에 맞춘 경고선 인상은 하지 않는다.

이 검토에서는 새 실행기·학습·경고선 변경을 수행하지 않았다. 추가 GPU 학습을 다시 실행할 필요는 없다.
