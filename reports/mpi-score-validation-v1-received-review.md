# MPI 점수 후보 재현·미사용 정상 검증 수령 결과

검토일: 2026-09-29. 연구실 실행 commit: `c07b36a2331dc6c5dafcfdde2b6110d19ff05de6`.

**기존 406장의 점수와 판정이 정확히 재현됐다. 미사용 정상 256장의 오경보는 기존 A 13장(5.08%),
Q90 14장(5.47%), 원시 점수+MAD 18장(7.03%)이다. Q90은 후속 검증 우선 후보로 유지할 근거가 있지만,
세 방법 모두 관측 오경보 5% 이하 목표를 넘었고 새 불량의 검출률은 이번에 검증하지 않았다.**

## 입력과 검증 범위

- 수령 ZIP: `mpi-score-validation-v1.zip`
- SHA256: `4f995562c08b3c768ff591025a5f22db01daad5d52020b2d296912f4814bd73a`
- 내용: freeze, plan, raw-scores, report, runtime-probes, handoff-manifest의 JSON 6개.
- ZIP CRC 및 manifest가 기록한 5개 payload SHA256을 확인했다.
- 사전 고정 설정과 수령 freeze, plan의 freeze가 정확히 일치한다.
- 이전 preparation·score-probe·external-evaluation ZIP과 원시 점수의 고정 해시를 대조했다.
- 기존 준비 자료의 픽셀 지문을 이용해 검증 정상 256장의 명단·선택 순서·중복 배제 결과를 재구성했다.
- plan의 freeze/cohort 해시 및 실행 소스의 LF 정규화 SHA256을 로컬 코드와 대조했다.
- 개발128·보정169·기존 시험109·검증 정상256, 총662장의 사진 식별자와 영역 순서를 대조했다.
- 기존406장 × 12영역의 top1/native_raw 최대 절대 차이는 **0.0**이다. 세 방법의 판정 변경도 없다.
- 수령 원시 점수로 기존 혼동행렬과 새 정상의 모든 판정·영역 통계·paired 비교를 재계산해 report와 일치함을 확인했다.
- 별도 Python 표준 라이브러리 계산으로 중앙값, MAD/Q90 간격, 임곗값과 오경보 수를 다시 확인했다.
- 정상8장 사전 실행 점검이 통과했고 환경은 이전 fit 전달물의 reload 기록과 일치한다.

이번 수령 검증은 기록·점수의 일관성 검증이다. Windows 원본 이미지 전체와 checkpoint를 맥북에서
다시 추론한 것은 아니다. 이미지 자체의 디코딩·체크섬 점검은 연구실 실행 코드와 전달 기록에 근거한다.

## 결과를 두 종류로 구분

| 방법 | 이미 본 불량55장 검출 | 이미 본 불량 미탐 | 이미 본 정상54장 오경보 | 미사용 정상256장 오경보 |
| --- | ---: | ---: | ---: | ---: |
| 기존 A: top1 + MAD | 33 (60.00%) | 22 | 3 (5.56%) | 13 (5.08%) |
| Q90: top1 + Q90 간격 | **53 (96.36%)** | **2** | 3 (5.56%) | **14 (5.47%)** |
| 원시 점수 + MAD | 46 (83.64%) | 9 | 3 (5.56%) | 18 (7.03%) |

첫 세 수치 열은 후보 선정에 사용한 시험 자료의 재현 결과이며 새로운 독립 시험 성적이 아니다.
마지막 열은 방법·임곗값을 고정한 뒤 처음 점수를 계산한 정상 자료다. 새 불량은 0장이다.
서로 다른 모집단을 단순 합쳐 하나의 전체 정확도·F1로 요약하지 않는다.

관측 목표 5%는256장 중12장까지 충족한다. 기존 A13장과 Q9014장 모두 초과이므로 목표 통과로
표시하지 않는다. Q90과 A의 차이는1장, 0.390625%p이며 이 관측만으로 통계적 동등성을 주장하지 않는다.
동일 데이터셋의 정확한 픽셀 중복을 배제했지만 독립 기판·촬영 세션까지 보장되는 표본은 아니다.

## Q90으로 무엇이 바뀌었는가

Q90은 기존 A가 잡은 불량33장을 모두 유지하고20장을 추가 검출했다. 남은 미탐은
`defect/0019`, `defect/0024`다. 원시 점수 후보는14장을 추가로 잡았지만 기존 검출1장을 새로 놓쳤다.

새 정상 자료에서 Q90과 A가 함께 경고한 사진은12장이다. Q90은2장을 새로 경고했고1장은 해소됐다.

| 검증 정상 ID | 변화 | 주 반응 영역 | 기존 A 점수 / 기준 | Q90 점수 / 기준 |
| --- | --- | --- | --- | --- |
| 0970 | Q90에서 새 오경보 | grid2-2 | 5.054947 / 5.496628 | 2.419518 / 2.316961 |
| 0998 | Q90에서 새 오경보 | grid2-2 | 5.062938 / 5.496628 | 2.423343 / 2.316961 |
| 1415 | Q90에서 오경보 해소 | grid3-3 | 5.756881 / 5.496628 | 2.315788 / 2.316961 |

Q90은 영역마다 정상 점수의 높은 쪽 변동 폭을 사용한다. 원점수로 환산하면 grid2-2의 경고 경계가
44.086에서42.922로 내려가 새 정상2장에 더 민감해졌다. grid3-3의 경계는43.070에서43.506으로 올라
1415의 오경보가 해소됐다. 1415는 Q90 기준보다 약0.00117만 낮아 경계에 매우 가깝다.

이 수치는 판정이 바뀐 계산상 이유를 보여준다. 조명·위치·부품 외관 중 무엇이 원점수에 영향을
줬는지는 원본/지도 없이 확정할 수 없다. 이번 ZIP에는 원본이나 이상 지도가 없다.

## 실행 비용

- 환경: Windows11, RTX5060, Python3.12.0, PyTorch2.8.0+cu128, Anomalib2.2.0.
- 미사용 정상 원본1장(12영역 순차 처리): 평균 **1.154초**, p95 **1.161초**.
- 범위: ZIP 읽기·이미지 디코딩·전처리·GPU 추론·지도 전송·top1 계산. 최초 모델 로딩,
  검토 DB 등록·UI·파일 저장 전체 응답시간은 포함하지 않는다.
- 사전 정상8장 점검 중 PyTorch GPU peak 할당 약2.67GiB, 예약 약2.92GiB.
  전체662장 실행의 peak나 GPU 전체 사용량이 아니며 RAM 값은 기록되지 않았다.
- 세 점수 방법은 같은 추론 출력을 재계산하므로 이 결과를 Q90만의 별도 속도 측정으로 보지 않는다.

## 해석과 다음 행동

1. 재현성 확인은 통과했다. 개선이 점수 파일 불일치에서 생긴 것으로 보이지 않는다.
2. 이번256장에서는 Q90 오경보의 큰 증가가 관찰되지 않았다. A보다1장 많았으며 원시 점수 후보보다4장 적었다.
3. Q90을 후속 검증 우선 후보로 유지한다. 고정 기준은 보존하며 서비스 적용·자동 PASS로 승격하지 않는다.
4. 다음 좁은 진단은 새 오경보0970/0998, 해소1415와 기존 미탐0019/0024를 원본·지도에 연결해 검토하는 것이다.
   이 자료로 같은256장의 임곗값을 다시 맞추고 검증 통과로 재표현하지 않는다.
5. 새로운 불량 검출률을 주장하려면 별도 미관찰 불량과 촬영 조건을 포함한 평가가 필요하다.
   현 데이터로 가능한 것은 탐색·원인 진단과 회귀 검증이다.
6. v1의 transistor 검사·검토 통합 작업은 별도 추진하며 이번 결과를 transistor 개선으로 옮겨 말하지 않는다.
