# MPI 정상 다양성 후보 점수 변화 분석 결과

2026-10-02. **저장 점수365장 전수 분석 완료. 새 미탐과 새 오경보는 원점수와 정상 보정의 복합 변화였다.**
새로 학습하거나 판정 기준을 바꾸지 않았다. 후보2 비채택과 기존 Q90의 연구 전용 상태를 유지한다.

## 무엇을 분석했는가

정상 학습64장을 다양성 기준으로 바꾼 후보2는 기존보다 불량을3장 더 놓치고 정상256장의
오경보를14→19장으로 늘렸다. 이번에는 그 차이를 원점수·정상 중앙값·정상 변동 폭·최종 경고
임곗값의 네 요소로 나눴다. 기존 시험109장과 정상256장을 모두 포함했다.

경고 여유는 `12영역 중 최고 보정 점수 − 경고 기준`이다. 0 이상이면 경고, 음수면 경고하지 않는다.
아래의 +/−는 **경고 여유를 높이거나 낮춘 점수 기여**이지 정확도 변화율이나 원인 확률이 아니다.
요소를 바꾸는24가지 순서를 모두 평균해 순서 하나에 좌우되지 않게 했고, 영역 전환도 반영했다.
중간 조합은 유효 모델이 아니므로 그 성능을 계산하거나 좋은 조합을 고르지 않았다.

## 정상 오경보 증가도 원점수만의 문제는 아니다

정상256장에서는 기존 오경보8장이 사라지고13장이 새로 생겨 순증5장이 됐다.

새 오경보13장 중11장은 원점수 기여가 양수이고,12장은 보정 요소 합계가 양수였다.
평균적으로 원점수 상승과 정상 폭 변화가 함께 경고를 밀어 올렸다. 사라진8장은 모두 원점수
기여가 음수였다. 평균은 사례별 차이를 지우므로365장 상세 값과 함께 보관했다.

특히 정상0827과0412는 원점수 기여가 각각 −0.0761, −0.0101로 경고를 줄이는 방향인데도
오경보가 새로 생겼다. 정상 폭 기여가 +1.4854, +1.7571로 더 컸기 때문이다.
두 사례는 기존/후보 모두 grid2-3이 최고 영역이었다. 이 영역의 정상 폭은4.5938→2.3413으로
좁아져 같은 정상 편차가 더 크게 평가될 수 있다.

반대 사례도 있다. 정상0399는 원점수 영향 +2.9787, 보정 합계 −0.2010으로,
보정이 경고를 억제했어도 원점수 상승이 더 커서 새 오경보가 됐다. 모든 오경보를 보정 하나로
설명할 수 없다는 반례다. 별도 정상54장의 새 오경보3장과 제거2장도 상세 결과에 빠짐없이 포함했다.

## 전체 자료와 원래 미탐의 상태

불량55장 전체에서는 원점수 기여 평균이 +0.0685로 약간 양수지만 정상 보정 합계는 −0.2065,
최종 여유 변화는 −0.1380이다. 이를 “새 bank의 모든 결함 반응이 나빠졌다”로 일반화하면 틀린다.
또한 원점수 평균 상승만으로 정상과 불량의 구분 능력이 좋아졌다고 할 수 없다.

원래부터 놓친0019는 여유 −0.0446→−0.3086,0024는 −0.2121→−0.3552로 모두 음수다.
0024는 원점수 기여 +0.0608에도 정상 보정 합계가 더 부정적이었다. 두 미탐은 해결되지 않았다.
이번 분석에는 결함 위치·최근접 정상 패치 정보가 없어, 특징 부족인지 잘못된 패치 비교인지
물리적 원인을 확정할 수 없다.

총365장 중168장은 실제 두 모델의 최고 영역이 달랐다. 불량55장에서는1장, 정상54장에서는35장,
정상256장에서는132장이다. 한 영역만 고정한 설명으로 모든 사진을 해석하지 않은 이유다.

## 검증 범위와 제한

- 입력 ZIP3개의 파일 지문·CRC·내부 해시를 확인했고, D단계가 기록한 원본 점수 지문 및 동결 소스를 대조했다.
- 첫 연결 시 공간 재현본의 전체 JSON 지문이 D단계 원본과 달라 중단했다. 출력은 생성되지 않았다.
  D단계가 실제 참조한 점수 검증 ZIP을 추가로 확인했고, 공간 재현본과 명단·영역 원점수가 완전히
  같음을 검증했다. 지문 검사를 제거하거나 데이터를 바꾼 것이 아니다.
- 정상128/169장 계약과 두 모델의 실제 점수·판정·성적을 재계산했다. 실제 끝점 점수 오차0,
  성적/추가·상실 검출 목록 일치, 기여 합계 최대 오차8.88×10⁻¹⁶으로1e-10 조건을 충족했다.
- 365장 전체에 별도 부분집합 가중식으로 기여도를 재계산한 차이도 최대8.88×10⁻¹⁶이었다.
- 새 진단 테스트23개, 전체 테스트578개와52개 하위 테스트가 통과했다. 기존 경고3개는 유지된다.
  이는 계산·실패 처리의 검증이지 모델 정확도의 추가 근거가 아니다.
- 성공 실행의 입력 검증·계산은0.238초, 프로세스 peak RSS86.77MiB였다. 최종 파일 쓰기와
  개발·테스트 시간은 제외한다. GPU나 모델 추론 비용이 아니다.
- 입력·모델·임곗값은 수정하지 않았다. 관찰 자료의 산술 분해이며 인과관계, 미래 정확도,
  새 독립 성능을 입증하지 않는다. 기존 재표집 안정성 실패와 C단계 자원 위반은 그대로 남는다.

## 다음 단계 판단

이번 진단은 여기서 종결한다. 같은 자료로 원인 분석을 계속 늘리기보다 다음 방향을 결정한다.

1. **후보2로 모델을 바꾸지 않는다.** 일부 정상 오경보는 줄었지만 검출 보존·전체 오경보·안정성에서 실패했다.
2. **추가 학습보다 기존 bank를 고정한 정상 보정 안정화의 새 설계를 우선 제안한다.** 보정이 경고를
   억제하거나 증폭하는 경로가 수치로 확인됐고, 기존 bank를 유지하면 새 bank가 만든 원점수 악화를
   섞지 않고 변경 효과를 비교할 수 있다. 이는 다음 비교의 논리이지 개선을 보장하는 결론이 아니다.
3. 후보1의50% 공유 비율을 다시 조정하는 탐색은 하지 않는다. 다른 보정 방식1개를 선택하려면
   정상 자료만으로 정하는 규칙·표본 민감도·기존 검출 보존·오경보·비용 조건을 새 카드에 먼저 고정한다.
4. 원래 미탐2장까지 보정으로 해결할 수 있다고 약속하지 않는다. 새 설계 근거가 부족하면 학습을
   시작하지 않는다. 새로운 독립 성능을 주장하려면 별도 자료·검증이 필요하다.

이번에 새 후보를 선정·실행하지 않았다. 연구실 Windows에서 추가로 할 작업은 없고,
다음 진행 대상은 **새 사이클의 단일 보정 후보 설계와 승인**이다. 자동PASS·서비스 교체는 계속 금지한다.
