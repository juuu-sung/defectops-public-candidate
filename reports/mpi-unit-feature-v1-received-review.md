# MPI 특징 정규화 결과와 비채택 결정

검토일 2026-10-03. **실행과 수령물 검산은 통과했지만 성능은 크게 악화되어 이 후보를 비채택한다.**
기존 Q90 연구 기준선과 서비스 모델은 바꾸지 않았다. 이번에 제안한 벡터 길이 정규화는
현재 고정 bank 구성에서 개선 방법으로 적합하지 않았다.

전달물 `mpi-unit-feature-v1.zip`의 SHA256은
`32654cfa0732d48411fec6e48d2a05a1bcd87cf302c43205f413bacf24826095`다.
[기계 판독 검산 결과](mpi-unit-feature-v1-verification.json)와 [실행 전 설계](../docs/mpi-unit-feature-v1.md)를 함께 보존한다.
실행 때 해시로 잠근 설계·코드는 이번 수령 검토에서 수정하지 않는다.

## 무엇이 잘못됐는가

이번 변경은 모든 패치 특징을 길이1로 만들어 **특징의 크기 정보 없이 방향을 비교**했다.
좋은 경우 정상 외관 차이를 덜 민감하게 볼 수 있다는 가설이었으나 이번 결과는 반대다.
오경보를 줄이지 못하면서 기존 불량 반응의 구분력을 크게 잃었다.

단순히 최종 경고 기준 하나가 높아진 문제로 볼 수 없다. 사진 점수의 정상·불량 순서 자체를
평가하는 AUROC가0.9946→0.8495로 하락했다. 불량 사진 점수 중앙값은2.9778→1.9580,
정상54장 중앙값은0.6620→0.6807이다. 각 방식이 자기 정상 자료로 보정된 점수이며
원시 거리 단위가 달라졌으므로 원시 점수 크기를 서로 직접 비교하지 않는다.

기존부터 진단하던 grid3-2 영역의 원점수 AUROC도0.9983→0.9468로 낮아졌다.
이 영역에서조차 구분력이 약해졌다는 보조 근거이지, 이 영역만 검사하라는 권고가 아니다.
사진 최고 반응 영역은 불량55장 중 기존54장·후보49장에서 grid3-2였다.

**해석:** 크기 정보를 제거한 거리 변경과 기존 대표 bank의 조합이 좋지 않았다는 근거다.
다만 bank 대표 행을 새 거리에 맞춰 다시 선정하지 않았고 실제 feature norm·최근접 패치·
지도는 이번 ZIP에 없으므로, 크기 정보 제거와 bank 대표성 문제 각각의 기여는 분리할 수 없다.
모든 정규화 방법이 실패한다거나 PatchCore 자체가 불가능하다는 결론은 아니다.

## 실행 검증과 자원

- ZIP12개 파일의 중복·안전 경로·CRC, manifest11개 payload 해시 통과.
- 실행 당시 소스·설계·설정131개 LF 해시가 현재 파일과 일치.
- 기존 고정 자료와 후보의 사진·영역·입력 경로 연결,959개 사진 receipt와 gate 해시 통과.
- 원 모델 정상8장/96영역 재현 두 번 모두 차이0. 후보 bank 지문도 두 재구성에서 일치.
- 정상297장 후보 재로딩 원점수 차이0, 고정 판정 변경0.
- 생산 계산 함수와 별도로 전체정렬 median/Q90/Q95 및1324개 사진 판정을 다시 계산해 일치 확인.
- 총1193.565초, 약19분54초.1회 시도, 기록된 실행 오류0.
- 샘플링 RSS peak2.729GiB, PyTorch allocated peak2.668GiB, reserved peak2.928GiB.
  장치 전체 사용량 샘플 peak4.064GiB는 이 프로세스만의 점유로 해석하지 않는다.

정해 둔2시간·RSS20GiB·reserved6GiB 상한 이내다. 전체 실행 시간은 모델 로딩·재현·사진 읽기·
계산·캐시 저장 등을 포함하며 초기 입력 해시와 최종 ZIP 내보내기는 제외한다.
정식 paired warm 지연시간 측정은 하지 않았다. 약20분을 순수 학습시간이나 서비스 속도로 쓰지 않는다.

고정 성적 실패에 따라 사전 규칙대로3,000회 정상 재표집을 생략했다.
**안정성 미실행**이지 안정성 검사를 통과하거나 실제로 실패한 결과가 아니다.
Mac에는 이번 검토에 필요한 원본 ZIP·checkpoint·CUDA 텐서가 없으므로 실제 모델을 독립 재실행하지 않았다.
확인한 것은 전달 기록의 무결성·기존 자료 연결·계약·판정·집계의 일관성이다.

   이미 완료한 동일영역·공간26×26·정상64장 재선정·폭 보정 실험을 반복하지 않는다.
