# SuperSimpleNet 제한 학습 실행 준비 검토

2026년 10월 5일 사용자 승인에 따라 작은 고정 합성 문제의 학습 가능성을 확인하는 실행기를 준비했다.
연구실 GPU 결과는 아직 없으며, 학습 성공이나 실제 불량 검출 개선을 주장하지 않는다.

## 실행 범위

[실험 계약](../docs/mpi-supersimplenet-learnability-v1.md)에 따라 기존 300 epoch 최종 모델 복사본에서
정상 한 사진의 8타일을 500회 반복 학습한다. 특징 추출기는 고정하고 변환부와 검출부를 업데이트한다.
고정 seed 42·공식 합성 잡음·원래 시작 학습률을 사용하며 새 AdamW로 시작한다.
개발·보정·시험 이미지를 이번 학습에 사용하지 않는다. 기존 체크포인트와 경고 기준은 변경하지 않는다.

## 확인한 항목

- 기존 Python 파일은 수정하지 않았다. 새 실행기의 계획에는 추가 소스와 문서 해시를 포함한다.
- 0·50·100·200·300·400·500회 상태와 원시 지도·점수·손실 기록을 저장한다.
- 정상 Ctrl+C는 완료 체크포인트로 복귀하며, 재실행한 업데이트도 예산에 누적한다.
- 강제 종료 기록 누락·자원 실패·원본 변경·체크포인트 변조·재로딩 차이는 자동 통과시키지 않는다.
- 결과 ZIP에 이미지·특징 텐서·가중치를 넣지 않도록 구성했다.

전체 CPU 테스트는 892개와 52개 하위 검사를 통과했다. 이후 입력 선택·실행 경로·특징 통계에 관한
3개 검사를 추가했고, 제한 학습 전용 14개 테스트가 모두 통과했다. 전체 검사에서 기존 경고 3건은
라이브러리 사용 중단 예고와 의도적인 ZIP 중복 이름 검증 사례였다.

CPU 모의 runtime은 저장·재개·오류 경로를 검증한다. 실제 torch 역전파·CUDA 메모리·500회 학습과
원본 모델 로딩은 Windows RTX 5060 환경에서 아직 실행하지 않았다. 시간 30분과 RAM/GPU 상한은
계산 경계에서 점검하며, 사전 체크섬 검증과 ZIP 내보내기 시간은 계산 예산 밖이다.

## 결과 수령 후 판단

손실의 감소와 학습·추론 모드의 사진/픽셀 구분력 향상이 함께 나타나는지 확인한다.
작은 고정 문제를 외운 성적을 일반화 성능으로 보고하지 않는다. 실패 시 학습량을 자동 연장하지 않고
특징/잡음 규모, 위치 손실, 분류 손실, 모드 차이를 근거로 다음 조건 하나를 설계한다.
