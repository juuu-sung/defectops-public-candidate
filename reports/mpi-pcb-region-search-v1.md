# MPI-PCB 동일 영역 검색 결과 수령 검토

검토일: 2026-09-28. 실제 Windows RTX 5060 실행 ZIP의 기록·점수·계약을 재검증했다.
원본 이미지·checkpoint·NPZ는 Mac에 없어 GPU 재실행과 실제 지도 픽셀 검증은 아직 하지 않았다.

**결론: 같은 영역으로 제한하면 약 7.9배 빨랐지만 불량을 더 놓쳤다. 기존 A를 유지한다.**

최대 영역에 결함이 있는지, 그 안에서 점수가 결함에 집중되는지는 지도 검증 전 확정하지 않는다.

## 왜 원점수가 올라가도 미탐할 수 있나요?

검색할 정상 예시가 줄면 정상·불량 모두 거리 점수가 오를 수 있다. 그래서 후보 정상
128장으로 중앙값·MAD를, 정상169장으로 경고 기준을 같은 규칙으로 다시 산출했다.
기존 기준선은 바꾸지 않았다. 정상 점수의 상승과 결함 점수의 상승은 별개다.

예를 들어 defect/0046, grid3-2의 top1 원점수는 **43.662→44.812**로 올랐다.
하지만 이 영역의 경고 경계는 **43.630→46.251**로 더 크게 올랐다.
정상화 사진 점수의 경계 차이는 +0.0186→−0.8706이 되어 새 미탐이 됐다.
이것은 수치 설명이지 결함의 시각적 반응이나 원인의 확정이 아니다.

정상 보정0411/grid2-3이 두 방식 모두 95% higher 기준을 결정했고, 각각 이보다 높은
정상 사진이 8장 있었다. 후보의 정상 지도가 저장되지 않아 paired 정상 위치 비교는 할 수 없다.
고득점이라는 이유만으로 0411을 제거·재라벨링하지 않는다.

## 검증한 것

- 수령 ZIP SHA256 `c56b03bd6d573b54cbbbe1543e3179eb697652919fd41e92a96bd2b547f0a107`.
- 10개 파일의 CRC·명단 및 9개 payload 해시, 동결된 코드 62개 LF 해시·실행 identity 일치.
- 기존 bank 78,643개 벡터의 출처 메타데이터·영역별 routing 재구성 일치.
  한 영역의 벡터 수 4,961–9,362, 합계78,643. 실제 벡터는 GPU에서 독립 재검증하지 않았다.
- 기존 top1 4,872개 재현 차이0, 두 시험 218개 사진 점수·판정·짝 비교 재계산 일치.
- 혼동행렬·순위 지표·복구 제외 분석 재계산 일치. Wilson 구간 계산의 플랫폼 부동소수점
  차이는 최대5.55e−17로 허용1e−12 이내이며 성적·판정 차이가 아니다.
- 단일 프로세스 기록, 정상/특징/후보 gate 및 bank 보존 기록 일치.

이는 이미 관찰한 시험의 탐색 비교다. 다른 영역의 정상과 매칭됐다는 이유만으로
오매칭을 확정할 수 없으며, 이번 실패가 모든 영역별 모델의 실패를 뜻하지도 않는다.
