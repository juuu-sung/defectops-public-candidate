# MPI PatchCore 확대 후보의 정상 보정 민감도 분석

2026-10-08. 기존 모델·지도·점수·실제 경고선을 고정하고 수령 ZIP의600회 재표집을 분석했다. **정상 변동 폭 추정의 변화가 검출 불안정의 우선 점검 대상이다.** 새 오경보도 모델 원점수 상승만으로 설명되지 않는다. 추가 모델 학습보다 별도 정상 개발자료의 표본 수를 늘리는 단일 변경을 우선 검토한다. 효과는 아직 시험하지 않았으며 시각 근거 확인도 남아 있다.

## 수행 범위

- 원본 입력 ZIP SHA256 `976601795064eba599f25f6641695c0df60988c04e6c3cd4d03180900cc62c7d`, Q90 원점수 기준 ZIP `4f995562c08b3c768ff591025a5f22db01daad5d52020b2d296912f4814bd73a`를 고정했다.
- 두 모델의 기존 사진 판정·AUROC·증감 목록을 재현하고, 원래600회 난수 인덱스·확대 후보의 결과를 다시 계산했다. 새로 표집하거나 유리한 시행만 남기지 않았다.
- 정상 중심·정상 폭·사진 경고선을 원래 값과 해당 시행 값으로 조합한8가지 계산을 시행별로 모두 기록했다. 이 계산은 원인 분해용이며 새 후보 채택이나 불량 정답에 맞춘 경고선 탐색이 아니다.
- 세 요인의 변경 순서6가지를 평균해 상호작용을 배분했다(Shapley 분해). 합은 실제 미탐 변화와 일치한다. 물리적 촬영 원인의 인과효과를 추정한 것은 아니다.
- 정상 개발128장·보정169장에서 한 번에 한 장만 계산상 제외하는 민감도297회도 기록했다. 실제 사진·명단·경고선은 변경하지 않았다.
- 새 오경보5장 및 기존 평가에서 고정한 고점수 정상12장의 원점수와 경고 경계를 비교했다. 중복0018을 합쳐16개 사진이다.

전체 시행 및 계산 기록은 로컬 `artifacts/analyses/mpi-patchcore-scaling-sensitivity-v1/report-final.json`에 있다. 실행기는 `scripts/analyze_mpi_patchcore_scaling_sensitivity.py`다. 모델 로딩·GPU 추론·새 이미지 열람은 하지 않았다.

## 정상 폭과 사진 경고선이 함께 검출을 흔든다

| 다시 뽑은 정상 자료 | 검출50장 미만 시행 | 평균 미탐 | 중심 변화 배분 | 폭 변화 배분 | 경고선 변화 배분 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 개발128장만 | 12/200 | 1.265 | -0.0167 | 1.1433 | 0.1383 |
| 보정169장만 | 1/200 | 0.355 | 0 | 0 | 0.355 |
| 양쪽 | 27/200 | 3.020 | 0.0258 | 2.0333 | 0.9608 |

배분 단위는 미탐 사진 수이며 음수는 다른 요인의 손실을 일부 상쇄했다는 뜻이다. 양쪽 변경에서 평균 미탐 증가3.02장 중 폭의 계산상 배분은약67%, 경고선은약32%다. 중심 이동은 상대적으로 작았다. 이 비율은 다른 데이터에도 적용되는 일반 법칙이 아니다.

정상 개발자료로 영역별 중앙값과 `Q90−중앙값` 폭을 만든다. 같은 이상 원점수라도 이 폭이 커지면 정규화 점수가 작아진다. 보정 정상169장에서는12영역 최대값의Q95로 사진 경고선을 정하므로 다른 영역의 정상 고점수도 경고선에 영향을 준다.

양쪽 시행19에서는55장 검출이5장으로 줄었다. 아래는 모델 점수는 동일하게 두고 계산 요소만 바꾼 결과다.

| --- | ---: |

| 폭만 | 33 |

한 요인만의 영향보다 두 요인의 상호작용이 컸다. 주요 결함 영역grid3-2의 폭은2.201에서3.141로 커졌다. 개발 정상Q90을 결정하는 관측값은0969의36.2868에서1554의37.3812로 이동했다. 1554가 잘못된 정상이라는 뜻이 아니라 재표집으로 같은 순위의 관측값이 달라졌다는 뜻이다.

개발만 최악 시행194에서도 같은Q90 사진1554가 선택됐고 폭은3.340이었다. 반면 보정만 최악 시행10에서는 폭이 고정된 상태에서 경고선이3.0014→4.0606이 되며 검출42장으로 줄었다. 두 경로를 구분해야 한다.

### 경고 경계에 관여한 정상 사진

양쪽 재표집의 검출50장 미만27회에서Q95 경계 소유 사진/영역은0411/grid2-3이7회,0616/grid1-2가4회,0360/grid1-2가3회 등이다. 개발만의 저검출12회에서는0411/grid2-3과1213/grid4-2가각3회,0705/grid4-1이2회다. 이는 경계 관측값의 빈도이며 해당 사진이 모든 문제를 유발한다는 인과 판단은 아니다. 같은 경계값의 동률과 재표집 중복 횟수도 기록했다.

한 정상 사진씩 제외한297회에서는 모두55/55 검출,1/54 오경보를 유지했고 별도 정상 오경보만14~17/256 사이에서 변했다. 따라서 특정 정상 한 장 삭제를 해결책으로 삼을 근거는 없다. 여러 표본의 구성과 순위 변화가 중요하다.

## 새 오경보는 원점수와 경고 경계를 함께 봐야 한다

각 사진의 새 모델 최대점 영역을 기준으로 기존과 새 모델의 동일 영역을 비교했다. 원점수는 지도 상위1% 평균, 원점수 경계는 `중심 + 폭 × 사진 경고선`이다.

| 정상 사진 | 영역 | 원점수 기존→새 | 원점수 경계 기존→새 |
| --- | --- | ---: | ---: |
| good/0018 | grid4-1 | 43.406→42.148 | 44.766→41.590 |
| validation/0412 | grid2-3 | 43.128→43.533 | 44.833→43.009 |
| validation/0853 | grid1-1 | 43.266→42.912 | 46.124→41.749 |
| validation/0276 | grid4-2 | 42.127→41.974 | 42.482→40.405 |
| validation/0961 | grid4-2 | 41.521→41.754 | 42.482→40.405 |

0018·0853·0276은 원점수가 낮아졌는데 경계가 더 크게 낮아져 경고로 전환됐다. 따라서 새 오경보5장을 모두 정상 외관 학습 부족으로 단정하면 안 된다. 정상 개발 집합의 폭이 좁아진 효과와 별도 정상집합의 외관을 함께 확인해야 한다.

이 계산만으로 반사·핀·조명·검은 여백을 원인으로 확정할 수 없다. 이전64장 모델의 정상 지도 관찰을 새256장 모델에 그대로 옮겨 쓰지도 않는다. 특히 새 오경보4개 validation 사진의 지도 요약은 수령 평가ZIP에 없었고, 원본/지도 픽셀은 전부 없었다.

## 다음 변경은 정상 개발자료 확대를 우선 검토한다

현재 근거상 다음 단일 변경의 우선안은 **모델 학습량이 아니라 정상 척도 개발자료를128→256장으로 확대**하는 것이다. 기존128장을 포함하고, 학습256장·보정169장·관찰 검증256장·시험 사진 및 중복 사진군과 분리된 미사용 정상128장을 고정 규칙으로 추가해야 한다. 적격 자료의 확보 가능성부터 확인하며 이미 본 오경보 사진을 개발자료로 이동하지 않는다.

모델 파일, bank, 전처리, 패치, 점수 산식, 보정169장, Q95 규칙은 유지한다. 개발자료가 바뀌면 중심·폭과 같은 보정169장에서 산출한 사진 경고선은 자연스럽게 다시 계산되므로 기존 경고선 숫자를 무조건 고정하는 실험은 아니다. 기존 모델의 계약은 덮어쓰지 않는다.

이는 표본 크기/정상 표현 범위 변경을 시험하는 후보이며 보정 불안정 또는 오경보 개선을 보장하지 않는다. 정상 폭 공유·Qn·공간 점수 변경을 다시 섞거나 임의 폭 하한/경고선을 불량에 맞춰 탐색하지 않는다. 자료 적격성·시각 검토·사전 조건이 확정되기 전에는 새 계약을 실행하거나 채택하지 않는다.

## 시각 확인을 위한 연구실 작업

다음 항목을 합쳐 중복을 제거한 **정상23장 각1영역, 총23타일**을 선정했다.

1. 새 오경보5장과 이미 고정한고점수 정상12장의 최대점 영역.
2. 세 재표집 조건의 저검출 시행에서 경계를 자주 결정한 상위3개 사진/영역(해당 조건에3개 미만이면 모두).
3. 주요 결함 영역grid3-2의 고정Q90 및 최악 시행Q90에 해당하는 정상0969·1554.

`export_mpi_patchcore_scaling_review.py`는 원본ZIP 해시, 기존 예측 영수증, 지도에서 재계산한top1, PNG 바이트/픽셀 해시를 확인한 뒤 해당 원본PNG와 저장된지도만 내보낸다. GPU·재추론·모델·경고선 수정·시험 불량 열람은 없다. 선택된 정상은 이미 점수 계산한 사진이며 새로운 독립 평가가 아니다. 최근접 학습 패치 매칭은 이번 내보내기에 포함하지 않는다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_patchcore_scaling_review.ps1'
```

전달 파일: `C:\개인 프로젝트\defectops\artifacts\handoff\mpi-patchcore-scaling-normal-review-v1.zip`.

완료한 학습·평가 폴더와 기존ZIP을 그대로 둔다. 출력이 이미 있으면 내용이 같은지 확인하고, 다르면 덮어쓰지 않는다. 실패하면 오류와 파일을 보존한다. 이미지와지도는 공개 저장소/노션에 올리지 않고 현재 비공개 검토에만 사용한다.

시각 파일을 받은 뒤 정상 고점수의 위치를 확인하고 위 단일 변경의 실행 조건을 확정하는 것이 다음 단계다. 현재까지는 CPU 수치 진단과 내보내기 준비 완료이며 시각 원인 확정이나 성능 개선 실험 완료가 아니다.
