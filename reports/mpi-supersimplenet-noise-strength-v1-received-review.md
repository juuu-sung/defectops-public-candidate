# SuperSimpleNet 잡음 강도 비교 결과 검토

2026년 10월 6일. 잡음 0.03과 0.06을 각각 500회 학습했으나, 원래의 약한 합성 이상이나 강한 합성 이상 모두에서 뚜렷한 구분력 개선을 확인하지 못했다. 강도 추가 탐색과 데이터·학습량 확대를 보류하고 학습 신호 진단으로 전환한다.

검토 ZIP은 `mpi-supersimplenet-noise-strength-v1.zip`이며 SHA256은 `f058d2c8c067f4d0f9441a016d4bf578c68388dfe5a49f4dd0b22ca8c2c943dd`다. 사용자 제공 파일은 변경하지 않았다.

## 검산 결과

31개 항목의 ZIP inventory와 30개 payload hash, 9개 phase receipt, 소스 21개와 정책 일치를 확인했다. 저장 배열에서 135개 평가 묶음과 27개 집계를 재계산했다. 공식 수식으로 손실 분해 270개를 별도 계산한 최대 절대차는 약 0.000000191이었다.

각 후보 500회, 총 1,000회이며 학습 난수와 합성 마스크 hash는 기존 varying500의 같은 step과 일치했다. baseline과 두 원본 시작 상태의 출력은 이전 ZIP과 독립 대조해 모두 차이 0이었다. 최종 checkpoint 재로딩 차이 0과 원본 보존은 연구실 기록으로 확인했다. ZIP에 가중치가 없어 Mac에서 GPU 재추론까지 확인한 것은 아니다.

## 같은 약한 합성 이상에서 비교

| 학습 강도 | 타일 분류 AUROC | 픽셀 AUROC | 같은 위치 정상 대조 대비 AUROC |
| --- | ---: | ---: | ---: |
| 기존 0.015 | 0.6303 | 0.5035 | 0.4999 |
| 0.03 | 0.6178 | 0.5036 | 0.4999 |
| 0.06 | 0.6178 | 0.5045 | 0.4999 |

네 평가 난수의 평균이며 참고42는 제외했다. 같은 원본 한 사진의 8타일을 반복 합성한 진단으로 실제 결함 성능이 아니다. 0.03 후보를 0.03에서 검사해도 픽셀 AUROC 0.5036, 0.06 후보를 0.06에서 검사해도 0.5045였다.

정상 대조 점수에 합성 정답표를 붙인 진단 분류 AUROC는 두 후보 모두 0.6203으로, 실제 합성 타일 구분력 0.6178보다 높았다. 원래 외관에 따른 순위와 합성 이상 반응을 구분해야 한다.

실제 잡음 RMS는 각 지정 강도와 일치했다. 정상 특징 대비 잡음 RMS 비율은 0.015에서 약 3.5~4.1%, 0.03에서 7.1~8.3%, 0.06에서 14.1~16.5%였다. “강도 설정 미적용”으로 설명할 수 없다.

첫50회와 마지막50회 평균 손실은 0.03에서 1.060285→1.057384, 0.06에서 1.060222→1.057367이었다. 학습 부위의 gradient는 유한하고 가중치는 변경됐으며 backbone은 보존됐다. 업데이트 발생과 유용한 구분 학습은 다르다.

## 비용과 다음 단계

실행 396.48초, RAM 최고 2.572 GiB, GPU allocated 3.464 GiB, reserved 5.318 GiB로 상한 내였다. 전체 device 사용량 표본 최고 6.845 GiB는 reserved와 다른 범위다. 실제 시험 사진·mask 접근과 서비스 교체는 없었다.

공식 위치 L1 손실은 정상·이상 각 평균의 합이므로 이상 픽셀 비율 평균 1.87%만으로 정상 쏠림 원인을 확정하지 않는다. 이번 후보들은 원래 정식 모델에서 추가 학습했으므로 초기 상태 영향도 미분리다. [정상·이상 gradient 진단](../docs/mpi-supersimplenet-gradient-audit-v1.md) 후 필요하면 검출부 초기화 여부만 바꾸는 작은 대조 실험을 설계한다. 실제 불량·Q90·서비스는 유지한다.
