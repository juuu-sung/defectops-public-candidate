# SuperSimpleNet 정상과 합성 이상 학습 신호 검토

2026년 10월 6일 수령 결과에서 검출부의 정상·합성 이상 기울기가 강하게 반대 방향을 향했다.
그러나 기울기가 끊긴 것은 아니며 이 현상만으로 구분력 저하의 원인을 확정할 수 없다.
후속은 잡음·학습량 변경 없이 검출부 초기화 여부만 비교하는 제한 실험이다.

## 확인한 증거

수령 파일은 `mpi-supersimplenet-gradient-audit-v1.zip`이며 SHA256은
`29afe559caa02330e23062235419b3deb7187a4cc9e77445bece5b4bacab058f`다.
76개 항목 중 75개 payload의 체크섬·목록, 24개 작업 receipt, 26개 소스 해시와 고정 조건을 확인했다.
3개 상태 × 2개 잡음 강도 × 4개 난수이며 업데이트·시험 접근·경고 기준 변경은 모두 0이다.
기록된 실행 시간은 46.54초, RAM peak 2.602GiB, GPU allocated 3.335GiB, reserved 5.203GiB다.

저장 Gram 행렬에서 96개 요약을 재계산했다. 플랫폼 부동소수점 차이 최대 4.44e-16은 불일치로 해석하지 않는다.
24개 원시 학습 출력은 앞선 강도 비교와 차이0이다. 손실 분해를 별도 계산한 최대 차이는 1.11e-7 미만이다.
기록된 정상·이상 신호 합과 전체 손실 신호 차이는 최대 절대 1.18e-6, 상대 L2 약0.0112% 이하다.
작업 전후 상태 해시가 같고 파라미터에 남은 gradient가 없다는 기록도 확인했다.
체크포인트와 전체 gradient 벡터가 첨부되지 않아 Mac에서 역전파 자체를 독립 재실행한 검증은 아니다.

## 잡음 0.015에서의 주요 관찰

아래는 네 평가 난수의 평균이다. 방향 유사도 -1은 두 신호가 거의 반대 방향임을 뜻한다.
합산 비율은 `||정상+이상|| / (||정상||+||이상||)`이며 정확도나 학습 효율의 백분율이 아니다.

| 상태 | 부위 | 방향 유사도 | 합산 비율 |
| --- | --- | ---: | ---: |
| 정식 원본 | 변환부 | -0.0641 | 0.8450 |
| 정식 원본 | 위치 검출부 | -0.9500 | 0.1600 |
| 정식 원본 | 분류 최종층 | -0.9985 | 0.2050 |
| 0.015 추가500회 | 변환부 | -0.0485 | 0.8447 |
| 0.015 추가500회 | 위치 검출부 | -0.9143 | 0.2135 |
| 0.015 추가500회 | 분류 최종층 | -0.9986 | 0.2080 |

0.06 모델과 강도를 바꾼 평가에서도 큰 차이가 없었다. 추가 학습 후 위치 검출부의 상쇄가 줄었지만
실제 합성 구분력은 좋아지지 않았으므로 상쇄만이 원인이라는 해석은 근거가 부족하다.
분류 손실이 위치 검출부로 전달되지 않는 부분은 고정 `stop_grad=True` 구조와 일치한다.
정상·이상 신호의 일부 대립은 학습 목적상 생길 수 있고, 원시 gradient는 AdamW의 실제 갱신 방향과 같지 않다.

## 다음 실험

[검출부 초기화 대조](../docs/mpi-supersimplenet-head-reset-v1.md)로 기존 학습 상태의 영향을 확인한다.
정식 원본의 특징 추출부·변환부를 보존하고 검출부의 파라미터와 BatchNorm 통계만 새로 만든다.
같은 8타일·잡음0.015·학습률·500회·학습 난수를 유지한다. 원본과 기준 모델은 변경하지 않는다.
