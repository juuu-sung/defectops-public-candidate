# MPI Qn 정상 보정 비교 결과

2026-10-03. **Qn 후보는 비채택입니다. 정상 오경보는 줄었지만 불량 검출10장을 잃었고,
정상 보정 표본을 바꿔 뽑았을 때의 안정성도 개선 조건을 통과하지 못했습니다.**
이번 사이클은 정한 후보1개에서 종료합니다. 기존 모델과 Q90 계약은 연구 기준선으로 보존하며
서비스 교체·자동 합격·새 후보 탐색은 하지 않았습니다.

## 무엇을 실행했는가

기존 PatchCore 모델·정상 bank·원점수·중앙값·12영역 max를 그대로 두고, 영역의 정상 변동 폭만
Q90−중앙값에서 Qn 비례 척도로 바꿨습니다. 정상 개발128장으로 폭을, 별도 정상169장으로
사진 경고 기준을 계산하고 그 계약을 먼저 저장했습니다. 이후 관찰 불량55장·정상54장과
관찰 정상256장을 비교하고 정상 재표집3,000회를 모두 실행했습니다.

수식·자료·성공 조건은 [실험 카드](../docs/mpi-qn-scale-v1.md)와 [설정](../configs/mpi-qn-scale-v1.json)에
고정했고, 실제 계산 전에 실행기·설정·테스트를 로컬 커밋 `e2ec0a1`로 잠갔습니다.
설정의 `designed_not_executed`는 설계 당시 기록입니다. 변경하지 않았으며 후속 실행 동의를
실행 identity와 카드에 별도 기록했습니다. 현재 실행 상태와 결과는 이 보고서가 최신입니다.

## 왜 검출을 잃었는가

이번에는 모델 원점수와 중앙값이 완전히 동일합니다. 따라서 차이는 정상 폭·그 폭에 따라
다시 계산한 사진 임곗값의 결합에서 발생했습니다. 임곗값 숫자만2.317→8.011로 비교하면 안 됩니다.
분모의 단위가 바뀌었기 때문입니다.

두 방식을 같은 원점수 단위로 바꾸면 영역의 경고 경계는 `중앙값 + 정상 폭 × 사진 임곗값`입니다.
영역 중 하나라도 이 경계를 넘으면 사진 경고가 됩니다. 새 미탐10장 모두 두 방식에서
최고 반응 영역은 `grid3-2`였습니다.

| grid3-2 계산 | 기존 Q90 | Qn |
| --- | ---: | ---: |
| 중앙값 | 34.1007 | 34.1007 |
| 정상 폭 | 3.2781 | 1.1353 |
| 사진 임곗값 | 2.3170 | 8.0108 |
| 원점수 단위 경고 경계 | 41.6959 | 43.1953 |

이 영역에서는 **같은 불량 반응이라도 약1.4994 더 높은 원점수가 필요해졌습니다.**
폭이 작아졌다는 사실만으로 더 민감해지는 것이 아닙니다. 다른 영역까지 합친 정상 사진 기준을
다시 정하면서, 최종적으로 이 영역의 검출 경계가 올라갔습니다.
고정 임곗값을 지지한 정상 사진은 두 방식 모두 `calibration/1365`지만 그 사진이 잘못됐다는 뜻은 아닙니다.
특정 사진 제거·grid3-2 예외 규칙·임곗값 내리기는 시행하지 않았습니다.

이것은 고정 계산의 설명이지 정상 이미지의 물리적 원인이나 새로운 데이터에서의 효과를 입증한 것이 아닙니다.
앞선 [정상 영향 분석](mpi-normal-influence-v1-review.md)에서도 보정 불안정이 한 사진만의 문제가 아니며
다른 영역의 정상 반응이 공통 사진 경계에 영향을 주는 구조를 확인했습니다. 같은 원본·지도 검토를 반복하지 않았습니다.

## 정상 표본 구성에 따른 안정성

각 상황1,000회에서 정상사진 행을 복원추출하고12영역을 함께 움직였습니다.
두 방법은 매번 같은 추출 인덱스를 사용했습니다. 아래는 검출 수의2.5%–97.5% 분위수입니다.

| 다시 뽑은 정상 자료 | 기존 Q90 | Qn 후보 | 안정성 조건 |
| --- | ---: | ---: | --- |
| 개발128장만 | 4–55 | 9–53 | 실패 |
| 보정169장만 | 45–55 | 15–54 | 실패 |
| 두 집합 모두 | 3–55 | 4.975–55 | 실패 |

4.975는 정수 검출 수들을 정렬한 뒤 linear 방식으로 계산한 분위수입니다. 사진 일부를 검출했다는 뜻이 아닙니다.
세 상황 모두 하단50장 이상·변동 폭 절반 이하 조건을 실패했습니다. 특히 보정169장만 바꾼 경우
변동 폭이10장에서39장으로 커졌습니다. 무효 반복은0이며 실패한 반복을 삭제하지 않았습니다.
보정만/둘 다 상황의 정상54장 오경보 상단은8/8, 정상256장 상단은26/27로 각각5/25 조건도 실패했습니다.
이 범위는 보정 표본 민감도이지 미래 검출률의 신뢰구간이나현장 실패 확률이 아닙니다.

## 시간과 검증

- Mac CPU 본 계산5.937초, 프로세스 peak RSS57,769,984바이트(약55.09MiB). 누적30분·2GiB 상한 내 완료.
- 이는 저장 점수 분석 시간입니다. GPU 추론·서비스 응답시간이 아니며 모델을 다시 학습하지 않았습니다.
- 기존662장(128+169+109+256)의 보정 점수 재현 최대 오차0, 판정 변경0.
- 별도 전체정렬 계산으로 고정 계약·662장 판정과 재표집3,000회의 인덱스·파라미터·계수를 검산했습니다.
  최대 파라미터 차이0, 별도 검산8.257초. 검산 시간은 본 비교 실행 시간과 구분합니다.
- 최종 소스의 전체 테스트600개와52개 subtest 통과. 기존 의존성 경고 및 중복 ZIP 테스트 경고3개 유지.
- 입력과 결과는 지문으로 고정했습니다. 전수 판정·반복별 인덱스·파라미터·계수·시도 비용은
  `artifacts/analyses/mpi-qn-scale-v1/`에 약8.76MB로 보존했습니다.

## 결정과 다음 단계

Qn 후보 비채택, 사이클2 종료입니다. 기존 Q90도 안정성을 통과하지 않았으므로 서비스 승격은 없습니다.
관찰한109/256장은 탐색·회귀 자료이고 새 독립 불량 검증은 수행하지 않았습니다.

**다음은 다른 폭 공식의 연속 시험보다 ‘영역 점수 보정 후12영역 max와 공통 경고 기준을 쓰는 구조’를
변경할 근거가 충분한지 설계 수준에서 점검하는 것이 적절합니다.** 후보를 이미 골랐다는 뜻은 아닙니다.
이미 있는 정상 영향·지도·이번 경계 결과를 함께 보고, 정상 오경보 통제와 결함 검출을 어떤 단위로
설계할지 결정해야 합니다. 전체 영역에 적용할 수 있는 규칙·한 가지 변경·검증 자료 역할을
명확히 정의하지 못하면 새 성능 계산을 시작하지 않습니다.

이 다음 설계 검토는 미실행입니다. 특정 영역만 유리하게 처리하거나이미 본 불량으로 기준을 맞추지 않습니다.
추가 학습·데이터 다운로드·연구실 Windows 명령은 현재 필요 없습니다.
