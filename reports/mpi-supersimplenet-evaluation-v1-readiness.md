# SuperSimpleNet 고정 모델 평가 실행 준비 검증

2026-10-05. 사용자 승인에 따라 정식300epoch 모델의 회귀검사 실행기를 준비했다.
연구실 CUDA 평가는 아직 실행하지 않았다. 다음 증거는 실행 준비와 CPU 동작 검증에 한정한다.

## 구현 범위

- 수령 학습 ZIP 전체 SHA256과 내부 파일 해시, 기존 학습 소스 지문, 최종 모델과 정상 예측 파일을 대조한다.
- 추론 전용 로더는 optimizer 생성·업데이트·네트워크 다운로드 없이 최종 가중치를 strict 로딩한다.
- 정상8사진에서 가중치 지문·분류 원점수·원시지도·사진 점수·판정을 재현한 뒤 불량 검사를 연다.
- 고정12장 모두 유지 시만 전체365사진 비교와 두 모델의 동일 정상 반복 속도를 측정한다.
- 성적·속도 통과 시600회 사진 단위 정상 재표집을 수행한다. 주 계약은 변경하지 않는다.
- 저장 사진별 해시와 정상 재현 기록을 대조하며 Ctrl+C 재개와 완료 결과 재내보내기를 지원한다.
- 오류·시간/메모리 상한·미기록 강제 종료는 보존 후 검토하도록 중단한다.
- 이미 승인된0054 복구 파일만 지연 로딩한다. 원본·학습·Q90·서비스 파일은 변경하지 않는다.

## 검증 결과

- 신규 평가 테스트29개 통과. 12장 실패 시 나머지 입력 미접근, 실패 결과 내보내기,
  정상 재현 실패 시 불량 미접근, 파일 변경 거부, Ctrl+C 재개, 자원/누적시간 초과 차단을 검증했다.
- 학습·점검을 포함한 SuperSimpleNet 관련71개 통과.
- 전체 테스트848개와 하위 검사52개 통과. 기존 경고3개이며 실행117.22초다.
- CLI 도움말 진입을 확인했다. Mac에는 CUDA/torch가 없으므로 실제 GPU 로더·성능은 연구실에서 검증한다.
- 실제 수령ZIP과 기존 비교ZIP으로 정상128/169·시험109·별도정상256 명단,
  기존 Q90 성적53/55·3/54·14/256, 고정12장, 경고 기준2.0253641229135124 연결을 확인했다.
  이 연결 검사는 Mac에 없는 GPU 모델 폴더 판독만 대체했으며 모델 파일 검증의 증거로 주장하지 않는다.
- 수령 계획의 모든 기존 학습 소스 해시는 변경되지 않았다. 새 평가 파일은 별도 실험 identity에 포함한다.
