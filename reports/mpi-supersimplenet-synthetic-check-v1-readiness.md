# SuperSimpleNet 합성 이상 점검 실행 준비

2026-10-05. [실행 안내](../docs/mpi-supersimplenet-synthetic-check-v1.md)에 따른 정상 전용
48개 고정 묶음 검사를 준비했다. 가중치 업데이트·시험 이미지 접근·서비스 변경은 없다.

## 확인한 내용

- 전체 테스트880개와52개 subtest가119.91초에 통과했다. 이후 상태 확인과 CLI 경로 검사를
  추가한 신규 테스트16개가 별도로 통과했다. 전체881개를 한 번에 실행한 결과로 표현하지 않는다.
- 신규 검사는 부호 있는 출력, 결측 클래스, 배열 오염, 고정 명단, 정상 전용 CLI 경로,
  버퍼·모드 예외 복원, 결과 내보내기, 재개와 변조 차단, 자원 실패 후 자동 재시작 차단을 다룬다.
- 전달받은 정식 학습 ZIP의 메타데이터로48묶음을 계산했다. 학습·개발 입력은 각각8사진96타일이며
  두 그룹의 파일 경로 겹침이 없다. 기존 학습 소스 지문은 모두 그대로다.
- 공식 Anomalib2.2.0 모델·합성 생성기·손실 코드를 읽고 기존 고정 SHA256과 일치함을 확인했다.
- 로컬 import와 CLI 도움말에는 torch가 필요하지 않음을 확인했다.

## 아직 검증하지 않은 부분

로컬은 CUDA·torch가 없는 환경이다. 실제1536채널 특징의 공식 합성 forward, BatchNorm 통계
복원, GPU 메모리와 실행시간, Windows PowerShell 자체는 연구실에서 확인해야 한다.
CPU 테스트는 대역 runtime과 수치 fixture를 사용했으며 실제 모델 반응을 확인한 것이 아니다.

실행기는 source·checkpoint·정상 예측 재현·전처리·공식 추론 경로·전후 상태를 검사한다.
성공 결과를 받기 전 합성 이상 구분 성공이나 미탐 원인, 성능 개선을 주장하지 않는다.
원본·모델은 그대로 두고 별도 분석 폴더에 기록한다.
