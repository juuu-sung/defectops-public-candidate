# MPI 특징 정규화 실험 실행 준비 검증

2026-10-03. **설계·구현·CPU 검증 완료, Windows GPU 결과 대기**다.
기존 모델·정상 bank의 행을 유지하면서 모든 패치 벡터를 단위 길이로 바꾸는 후보 하나를 준비했다.
미탐 감소나 오경보 개선 결과는 아직 없으며 서비스 교체도 하지 않았다.

## 확인한 내용

- 전체 테스트646개와52개 subtest 통과,91.01초. 기존 경고3개 유지.
- 이후 전달 ZIP에 런타임 검증 기록과 사진별 receipt를 추가하고 관련15개 테스트 재실행 통과,7.76초.
  해당 마지막 포장 변경 뒤 전체646개를 다시 실행한 것으로 표현하지 않는다.
- 실제 수령 ZIP을 읽는 기존 입력 경로를 실행해 정상 개발128·보정169·시험109·추가 정상256장,
  checkpoint 환경 연결을 검증했다. 원본 MPI 압축파일·실물 checkpoint의 GPU 실행은 Mac에서 하지 않았다.
- 벡터 길이 정규화·양쪽 동일 변환·원본 배열 보존·제로/비유한/잘못된 dtype 차단 확인.
- 합성 실행959장, 보정→재로딩→관찰 시험 순서, 완료 재실행 시 GPU 작업 없음 확인.
- 3장 뒤 예외를 낸 후 완료 사진을 재계산하지 않고 재개, 캐시 손상 차단 확인.
- 재로딩 점수 불일치 시 시험 전 중단, 자원 초과 시 자동 재시도 금지,
  강제 종료의 비용 기록 누락 시 중단 확인.
- 고정 성적 실패 시 bootstrap 생략, 합성 통과 분기에서도 서비스 승격 금지 확인.

합성 runtime과 NumPy 기반 tensor 대역 검사는 실제 torch/CUDA 성능 증거가 아니다.
실제 라이브러리 경로는 Windows에서 원 모델 점수 재현·변환 bank 지문·후보 정상297장 전체
재로딩 검증을 수행한다. GPU 지연시간·메모리와 불량 성능은 이 실행 결과를 받아 확인한다.
원래 대표 벡터를 새 거리로 재선정하지 않았다는 제한도 유지한다.
