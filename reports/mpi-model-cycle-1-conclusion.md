# MPI 모델 개발 사이클 1 — E단계 결론과 다음 연구 진입 조건

기준일: 2026-10-02. 상태: **사이클 1 종료, 채택 후보 없음. 모델 개선 목표 달성이나 서비스 승인이 아님.**
사용자의 “응 그렇게 진행하자”에 따라 D단계 결과 이후 결론과 다음 방향을 정리했다.
이번 작업은 문서·노션 갱신이다. 새 학습·추론·임곗값 변경·데이터 다운로드는 하지 않았다.

후속 업데이트: 같은 날 사용자 진행 동의로 [365장 저장 점수 분리 진단](mpi-diversity-score-decomposition-v1-review.md)을
완료했다. 아래5–6절은 진단 실행 전 설계·인계 기록이며 최신 결과와 다음 결정은 후속 보고서를 따른다.

## 1. 무엇을 결정했는가

사전 한도 2개 후보를 모두 비교했지만 기존 기준선보다 나은 후보는 확보하지 못했다.
MPI-C1-01과 MPI-C1-02는 비채택하고 모델·점수·실패 기록은 보존한다.
기존 top1%+Q90은 다음 비교를 위한 연구 기준선으로만 남긴다. 기존도 정상 오경보 목표와
보정 안정성 조건을 충족하지 못했으므로 “가장 좋았으니 사용 승인”으로 처리하지 않는다.
transistor 서비스 모델에는 변경이 없다.

109장과 정상256장은 이미 관찰한 자료다. 이 표는 탐색·회귀 성적이며 독립 일반화 성능이 아니다.

정상 기준 사진을 바꿔 뽑았을 때 검출 수가 얼마나 달라지는지도 비교했다.

## 3. 무엇이 문제인지 어디까지 알았는가

검사 과정은 정상 특징 모음(bank)에서 원점수를 얻고, 영역별 정상 중앙값·폭으로 보정한 뒤,
12영역 중 가장 큰 점수를 사진 경고 기준과 비교한다. 따라서 bank만 바꾸어도 원점수뿐 아니라
그 bank로 계산한 정상 분포와 최종 경고 기준이 함께 변한다. 후보2는 설계상 선정 방식 하나를
바꾼 실험이지만, 내부 점수 변화 경로가 하나라는 뜻은 아니다.

| 확인한 사실 | 설명 가능한 범위 | 아직 확정할 수 없는 것 |
| --- | --- | --- |
| 후보1의 추가 미탐11장은 최고 영역이 grid3-2이며 이 영역의 정상 폭이 3.2781→3.9033으로 증가 | 같은 편차를 더 큰 폭으로 나눠 불량 점수를 낮추는 경로가 존재 | 이 영역을 별도 예외 처리하면 새 자료에서도 개선된다는 주장 |
| 후보2 추가 미탐3장은 불량 원점수 하락과 정상 중앙값 상승이 함께 발생 | 최종 임곗값을 올려서만 생긴 미탐이 아님. 임곗값은 오히려 2.3170→2.2973으로 낮아짐 | 결함 패치가 어떤 정상 패치와 잘못 매칭됐는지 |
| 후보2 정상256장 오경보19장 중9장은 grid2-3이 최고 영역. 이 영역 정상 폭은 4.5938→2.3413 | 정상 편차가 크게 증폭될 수 있는 경로가 존재 | 폭 감소만이 모든 새 오경보의 원인이라는 결론 |
| 과거 정상 영향 분석에서 다른 영역의 정상 반응이 사진 임곗값을 높이는 경우 확인 | 사진 최댓값 집계에서 영역 사이 영향이 존재 | 특정 정상 사진이 잘못된 라벨이므로 지워야 한다는 결론 |
| 사진 특징 다양성 선정은 최대 특징 거리를 줄였지만 실제 성적은 악화 | 선정 지표 개선이 불량 구분 개선을 보장하지 않음 | 모든 다양성 선정·정상 증량이 무효라는 일반화 |

가장 중요한 미해결 질문은 **정상과 불량의 원점수 구분이 부족한 부분과, 정상 보정 과정이
구분을 약화하거나 불안정하게 만드는 부분을 얼마나 분리해 설명할 수 있는가**다.
“학습량 부족”이나 “임곗값이 높다” 하나로 확정하지 않는다.
이미 완료한 정상 영향·원본·지도 진단을 이름만 바꿔 반복하지 않는다.

## 4. 속도와 자원은 별도 판단한다

- 후보1의 3.103초는 저장 점수 CPU 분석 시간이다. GPU 추론 시간으로 비교하지 않는다.
- 후보2 D단계에서 기존/새 모델의 사진당 warm p95는 각각1.1599/1.1643초다.
  정상32장×3회, 모델마다 새 프로세스에서 측정했다. 읽기·전처리·추론·지도전송·사진 집계까지이며
  모델 로드·파일 저장·HTTP·대기열은 제외한다. 서비스 응답시간 보증이 아니다.
- 후보2 D단계 계산은742.058초, GPU reserved 최대2.916GiB로 해당 단계 예산 안이다.
- 후보2 C단계 첫 시도는 GPU reserved7.715GiB로7GiB 제한을 넘었다. 저장 모델로 재개해
  완료했어도 이 위반은 유지한다. 두 시도 계산 합계는1,391.605초다.

이번 비채택의 직접 이유는 성적·안정성 실패다. 메모리 실행 경로를 고쳐도 정확도 실패가
해결되는 것은 아니다. 이후 새 학습이 승인될 경우 학습→보정 프로세스 분리와 자원 감시를
별도로 검증해야 하며, 과거 실패를 통과로 다시 쓰지 않는다.

## 5. 다음 연구 방향 — 실행 승인 전 설계

**다음 우선 제안은 추가 학습이 아니라 저장 점수의 원점수 변화와 보정 변화 분리 분석이다.**
새 후보의 점수를 좋게 만드는 수식을 찾는 작업이 아니라, 다음에 무엇을 바꿔야 할지 구분하는
한 번의 CPU 진단이다. 이 문서는 그 설계이며 이번에 진단 코드나 계산을 실행하지 않았다.

| 단계 | 작업 | 산출물·종료 조건 |
| --- | --- | --- |
| A: 진단 계약 | 기존/후보2의 고정 원점수와 정상128/169장 보정값으로 대상·계산·예산 고정 | 비교365장 전수, 추가 미탐3장과 정상256장의 제거8/추가13 오경보를 필수 설명 대상으로 잠금 |
| B: 한 번의 CPU 진단 | 원점수, 정상 중앙값, 정상 폭, 사진 임곗값의 변화가 경고 여유에 미치는 영향 분리 | 실제 양끝 점수·판정 정확히 재현, 합계와 잔차 보고. max영역 전환과 요인 상호작용 포함 |
| C: 연구 방향 선택 | 보정 영향/원점수 영향/혼합·미확정을 구분 | 근거가 구별되면 변경1개를 제안. 구별되지 않으면 미확정으로 종결하고 자동 추가 진단 없음 |
| D: 새 사이클 카드 승인 | 데이터 역할·한 요인·성공/중단 조건·비용 사전 확정 | 사용자 승인 전에는 학습·새 후보 평가 없음. 사이클1 한도를 이름만 바꿔 연장하지 않음 |
| E: 승인 시에만 비교 | 고정 성적·재표집 안정성·비용을 함께 비교 | 실패 시 비채택. 통과해도 관찰 자료의 연구 후보이며 독립 시험·서비스 승인은 별도 |

### 다음 진단의 제한과 성공 기준

- 두 모델의 저장 점수·고정 명단·계약만 사용한다. 원본 다운로드·GPU 추론·정답 지도 열람은 없다.
- 임의의 요인 변경 순서 하나로 원인을 확정하지 않는다. 대칭적 분해 등 상호작용을 처리할 계산법을
  A단계에서 고정한다. 서로 다른 모델의 원점수/보정값을 섞은 중간값은 산술 설명일 뿐 유효한 새 모델이 아니다.
- 중간 조합을 성적 순으로 골라 세 번째 후보로 발표하지 않는다. 임곗값 최적화·비율 탐색도 없다.
- 기존·후보2 실제 결과의 계수/명단이 완전히 같고 점수 오차가1e-10 이내여야 한다.
  분해 합계의 허용오차도1e-10으로 제안한다. 불일치하면 진단 중단, 결과 수정이나 표본 제외 금지.
- CPU 계산30분·RSS2GiB를 제안 상한으로 둔다. 초과 시 자동 축소·재선정하지 않는다.
- 성공은 “성적 향상”이 아니라 재현 가능한 수치 설명이다. 인과관계나 미래 개선 효과를 입증하지 않는다.
- 원점수 쪽 영향이 커도 곧바로 bank 증량으로 가지 않는다. 공간/최근접 패치 설명이 없으면
  특징 부족·패치 매칭·정상 다양성 중 무엇인지 미확정으로 남긴다.

새 사이클의 초기 성적 조건은 기존 검출53장 보존, 정상 오경보≤2/54 및≤12/256을 유지하는
방향으로 제안한다. 안정성 조건을 이번 실패 때문에 낮추지 않는다. 실행 전 기존 카드 조건의
적합성을 다시 검토·잠그며, 새 생산 목표나 결함군 보증으로 확대하지 않는다.

## 6. 인계와 지금 하지 않을 일

E단계 문서 정리는 완료했다. 연구실 Windows에서 추가로 실행할 명령은 없다.
기존 모델·ZIP·실패 시도·점수는 그대로 보관한다. 새 진단을 진행하려면 위 A/B 범위에 대한
진행 동의 후 실행기와 검증을 준비한다. 새 학습은 그 이후 별도 판단이다.
독립 불량 자료는 아직 미확보이며, 이미 본109/256장을 새 final이라고 하지 않는다.
자동 PASS·서비스 모델 교체·정상 사진 임의 삭제·추가 데이터셋 확보는 이번 범위에 없다.
