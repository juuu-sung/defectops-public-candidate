# SuperSimpleNet 학습 신호 진단 실행 준비

2026년 10월 6일. 정상·합성 이상별 여섯 손실과 공식 전체 손실의 gradient를 부위별로 비교하는 읽기 전용 실행기를 추가했다. [실험 조건과 연구실 명령](../docs/mpi-supersimplenet-gradient-audit-v1.md)에 24회 입력과 자원 상한을 고정했다. 검출부 초기화나 학습량 확대는 자동 실행하지 않는다.

검증 결과는 전용 15개 테스트 통과, 전체 942개 및 52 subtest 통과, 기존 3개 테스트 skip이다. skip 조건은 기존 검토 자료의 로컬 존재 여부이며 신규 진단 테스트를 생략한 것이 아니다. Python 구문 검사와 Git 공백 검사도 통과했다. 이전 잡음 강도 ZIP의 동결 소스·문서 21개는 모두 hash가 일치한다.

CPU 테스트는 신호 내적·방향·상쇄 계산, 0 신호 처리, 잘못된 행렬 거부, 업데이트 금지, 원본 보존, 완료 단계 재사용, 정상 중단 후 재개, 실패·자원·시도 상한·강제 종료 차단, 변경된 원본 및 결과 거부, ZIP checksum과 가중치 미포함, 이전 모델 provenance를 검사했다.

Mac에는 실험용 torch/CUDA 환경이 없어 실제 공식 모델의 반복 역전파나 Windows PowerShell 실행을 검증하지 않았다. 가짜 runtime 제어 테스트를 실제 GPU 검증으로 해석하지 않는다. 연구실에서는 저장된 학습 forward 재현, 여섯 손실 합과 gradient 합의 공식 결과 재현, 가중치·buffer 보존을 먼저 확인한다. 원본과 결과 파일을 유지하며 실패 시 재학습하지 않고 검토한다.
