# MPI 최근접 3개 소규모 회귀 검사 실행 준비

2026-10-03. 사용자의 특징 크기 보존·고정 회귀 검사 진행 동의에 따라
[설계](../docs/mpi-knn3-screen-v1.md)와 실행기를 준비했다. 실제 GPU 결과는 아직 없다.

## 준비된 범위

기존 원래 bank·CNN·전처리·특징 크기를 유지하며 지도 패치 거리만 최근접 3개 평균으로 바꾼다.
같은 정상128/169장으로 보정하고, 미리 고정한 기존 검출12장 중 손실0을 요구한다.
통과 때만 정상8장·같은 불량12장 재로딩을 확인한다. 전체 시험·정상256장·재표집은 실행하지 않는다.
실패309장·통과329장에 시작/재로딩 원 모델 정상 확인이 별도로 추가된다.
후보 전체 비교나 모델 채택은 이 작은 검사 통과와 별개다.

## 로컬 검증 결과

- 관련 테스트18개 통과, 2.66초. 이어 마지막 실행기 수정까지 포함한 전체 테스트664개·52개 subtest 통과, 91.95초.
- 기존 경고3개: AnyIO 별칭 폐기 예정1개, 의도적 중복 ZIP fixture 경고2개. 새 실패는 없다.
- 실제 수령 ZIP을 읽어 원래 정상128/169장과 고정회귀12장, 재로딩20장의 ID·원본 경로 연결을 확인했다. 현재 실행 소스·설계 해시133개를 고정한다.
- 작은 거리 배열에서 mean3 산술·특징 크기 변화 보존·nearest1 동률 인덱스 보존을 확인했다.
- 검색 가로채기는 패치 nearest1에만 적용되며 native weighted9는 그대로 호출한다. 예외에도 원래 함수를 복구한다.
- 합성 실행으로 12/12 통과329장, 1장 상실 시309장에서 종료, 완료 결과 재실행 시GPU 생략, 일반 중단 후캐시 재사용을 확인했다.
- 실행 환경·원 모델 점수·작은 재로딩 변화, 캐시/런타임 근거 손상, 자원 상한 초과를 차단한다.
- 결과 ZIP의 모든 JSON 체크섬과 목록을 확인했다. 마스크 읽기는 테스트에서 금지했다.
- CLI 도움말·Python import·Git 공백 검사를 확인했다. PowerShell과 실제 PyTorch/Anomalib/CUDA 실행은 Mac에서 검증하지 못했다.
