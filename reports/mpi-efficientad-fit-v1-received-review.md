# EfficientAD 정식 학습 결과 수령 검토

2026-10-04. **D3 학습·정상 보정·저장 복원 단계 완료. 고정12장 불량 회귀검사를 준비할 수 있다.**
실제 불량 검출률·독립 정상 오경보율·서비스 적용 가능성은 아직 평가하지 않았다.
학습을 임의로 연장하거나 임곗값을 변경하지 않고70,000회 최종 모델을 보존한다.

메모리 scope에 남아 있는 공통 모니터의 “CPU bootstrap” 문구는 이번에 bootstrap을 했다는 뜻이 아니다.

## 학습 과정 해석

| 업데이트 구간 | 세 학습 손실 합의 평균 |
| --- | ---: |
| 1~10,000 | 7.3417 |
| 10,001~20,000 | 3.7507 |
| 20,001~30,000 | 3.0013 |
| 30,001~40,000 | 2.5955 |
| 40,001~50,000 | 2.3718 |
| 50,001~60,000 | 2.2160 |
| 60,001~70,000 | 1.9760 |

처음1,000회 평균16.8683에서 마지막1,000회1.7597로 약89.57% 감소했다.
단순히 오류 없이 실행된 것뿐 아니라 학습 목적 함수가 전반적으로 낮아진 근거다.
하지만 서로 다른 입력·증강의 학습 손실이므로 정확도89.57% 개선이나 충분한 일반화·수렴을 뜻하지 않는다.
학습률0.0001은66,500회,0.00001은3,500회로 고정 일정과 정확히 일치한다.

손실·gradient는70,000회 모두 유한했고 gradient norm도 양수였다. 손실 최대541.029는2회째,
전체 gradient norm 최대7187.012는61,523회째였다. 마지막1,000회에서도 최대손실15.973이 있었다.
따라서 매step 매끄럽게 감소한 것은 아니다. 최대gradient 한 번만으로 발산을 확정하거나
임의의 clipping·재학습을 추가하지 않는다. 현재는 정한 최종 모델을 실제 불량 회귀검사로 확인할 단계다.

## 정상 보정에서 남은 주의점

개발128사진은 지도 보정과 영역 보정에 함께 사용했다. 별도169사진은 경고 임곗값을 계산했다.

| 자료 | 고정 기준에서 경고 | 해석 |
| --- | ---: | --- |
| 개발 정상128사진 | 10/128,7.81% | 보정에 이미 사용한 자료, 독립 오경보율 아님 |
| 기준 설정 정상169사진 | 9/169,5.33% | Q95 higher와 ≥ 판정에서 경계1장을 포함한 결과, 독립 검증 아님 |

임곗값은 오름차순161번째 사진0217의 grid1-2에서 정해졌다. 경계 영역 보정 전 타일 점수는
0.7069045931433035이며 사진 보정 점수5.148672653130029와 구분한다.
개발 정상 최고는1554/grid1-1의56.0919, 보정 정상 최고는1283/grid3-1의33.4021이다.
일부 정상 사진의 높은 반응이 남았다는 관측이며, 왜 높은지는 원본·지도 없이 판단할 수 없다.
이를 근거로 정상 사진을 삭제하거나 경고 기준을 낮추지 않는다. 정상256사진의 독립적인 추가
오경보 성적은 이번에 계산하지 않았고, 그 자료 자체도 과거 관찰된 회귀 자료다.

새 임곗값5.1487과 이전 Q90·PatchCore 임곗값의 숫자를 직접 비교해 성능을 판정할 수 없다.
새 checkpoint는 원시 ST/AE 지도 모델이고, `calibrated/value.json`의 보정 계약을 함께 사용해야 한다.

## 무엇을 직접 검산했는가

- ZIP9개 JSON, 중복 없음, CRC 정상, payload8개 SHA256 일치.
- 고정 준비 ZIP과 개발 manifest로64/128/169사진 명단·경로·픽셀 분리를 재구성해 일치.
- 실행 소스137개 해시·정책·환경·계획 지문 일치. 보조9,469개 train 명단과 teacher 지문 연결 확인.
- 70,000개 업데이트의 연속 번호·학습률·제품 및 보조 이미지 순서를 전체 재계산해 일치.
- checkpoint receipt71개와 정상 지도 receipt297개의 지문·계획 연결·사진 행 지문 일치.
- 최종 progress 파일 해시는70,000회 checkpoint receipt와 일치.
- 전달 타일 점수로 영역 중앙값·Q90 폭·사진 Q95를 재계산해 기록과 정확히 일치.
  같은 함수 호출 외에 정렬 배열의64/65번째·116번째·161번째 값으로도 독립 대조했다.
- 누적 시도·시간·자원 제한·8번 checkpoint 재로딩 기록·최종297사진 재로딩 기록의 내부 일관성 확인.

ZIP에는 모델 가중치·원시 지도·원본 이미지가 없다. 따라서 지도 Q90/Q99.5를 픽셀에서 다시
계산하거나 Windows 재로딩을 Mac에서 독립 재실행한 것은 아니다. 지도 분위수는 전달된
고정 계약값으로 받아들이고 그 이후 산술을 검산했다. checkpoint·지도 지문은 receipt 연결
검증이며 실물 파일과의 재대조가 아니다. 이러한 한계를 “전체 실물 검증 완료”로 표현하지 않는다.

ZIP SHA256: `2a60c4f4818a4c7927ff8ac7fed3d28b5bc9e163f3e878bb1e77a1e6f8d0e5a0`.
계획 SHA256: `5b24b630232bae5568bd5f2fbdb066a0fb61815b29b3babc7d0863c9987b981c`.
실행 코드: `9fdcb65`. 이번 검토에서 코드·학습 조건·모델·서비스는 바꾸지 않았다.

## 다음 단계

1. 학습을 더 늘리지 않고 최종 모델·보정 계약을 잠근 채 고정12장 회귀검사 실행기를 준비한다.
2. 연구실에서 기존에 검출하던12장 모두 계속 검출하는지 확인한다. 이미 관찰한 표본의 검출 보존
   검사이지 전체 불량 검출률 추정이 아니다. 사례 교체·임곗값 수정 없이12/12 통과를 요구한다.
3. 통과하면 사전 고정한 전체 불량55장·정상54/256장 비교와 비용·보정 민감도 검사로 진행한다.
   실패하면 원인을 검토하고 자동 전체 평가나 추가 학습을 하지 않는다.

현재 추가 Windows 명령은 없다. 기존 학습 산출물을 보존한다. 이번 수령 검토는 새 불량 평가를
실행했다는 뜻이 아니며, 독립 성능 확인이나 서비스 채택도 아니다.
