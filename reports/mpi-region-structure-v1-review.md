# MPI 영역별 경고 구조 검토와 비교 결과

2026-10-03. **가능성 진단과 정상-only 구조 비교를 한 묶음으로 완료했다. 실제 후보는 검출40/55로
기존53/55보다 낮아 비채택했다. 이 결과는 모든 영역별 판정 방식이 불가능하다는 증거가 아니다.**
기존 Q90은 연구 기준선으로만 유지한다. 새 학습·GPU 작업·서비스 교체는 없었다.

## 이번에 속도를 높인 방식

사용자의 요청에 따라 설계→구현→합성 검증→계산→검산→결론을 한 작업으로 묶었다.
이미 완료한 원본/지도 진단을 반복하지 않았다. 고정 검출 조건 실패 시 재표집 반복을 하지 않는
조기 종료를 성적 확인 전에 정했다. 기존 실험의 실패나안정성 조건은 소급 변경하지 않았다.

앞으로 같은 승인 범위의 구현·검증은 묶어서 진행하고, 자료 확보·학습 예산·독립 시험 개봉·서비스
전환처럼 범위가 달라질 때 확인한다. 빨리 진행하기 위해 관찰 자료를 독립 시험으로 바꾸거나
실패 후보를 성공으로 표시하지는 않는다.

## 가능성 진단과 실제 후보를 구분한다

### 정답을 사용한 경계 존재 여부

모든 영역의 경계를 자유롭게 바꾸는 낙관적 경우에 기존 검출53장과 오경보≤2/54·≤12/256이
가능한지 확인했다. 양의 척도 정규화 후 max를 쓰는 Q90/Qn은 이 구조에 포함된다.
진단은 [실행 전 설계](../docs/mpi-region-threshold-feasibility-v1.md)대로 수행했다.

찾은 해는 grid3-2 원점수41.8514569503505만 비교하고 다른11영역을 비활성화했다.
이 해에서는 보존 대상53장을 모두 경고하고 정상54/256장 중1/2장을 경고한다.
**정답으로 경계를 맞춘 진단 결과이며 정확도 개선 결과나배포 가능한 모델이 아니다.**
다른11영역의 결함을 볼 능력을 확보하지 못하고, 보존할 불량들의 반응 영역을 활용한 낙관적 결과다.
최적 성능이나상한 검출률도 산출하지 않았으며 조건을 만족하는 해1개를 찾고 종료했다.

이 해 하나만으로 모든 실제 결함이grid3-2에 있다고 단정할 수 없다. 이상 점수의 경고 여부와
물리적 결함의 위치는 다르다. 모든 영역이 활성화된 다른 해가 없다고 증명한 것도 아니다.
다만 현재 관찰 표에서 높은 수치만 좇으면 검사 범위를 좁히는 답을 얻을 위험을 직접 확인했다.

CPU 탐색0.0053초·상태1개에서 끝났다. 작은 합성 자료20개에서는 별도 완전 열거와 가능/불가능 판정이 일치했다.
시간 제한은 미확정으로 처리하고 불가능이라고 보고하지 않도록 검증했다.

### 정상 자료만 사용한 실제 비교

정답으로 찾은 경계는 사용하지 않았다. 실제 후보는12영역을 모두 활성화하고 영역마다 동일한
정상 순위 규칙을 적용했다. 개발128장과 보정169장을 후보에서만297장으로 합쳤다.
기존 Q90은 원래128/169 역할과 계약을 유지했다. bank64장과 평가 자료는 보정에 넣지 않았다.

각 영역 점수가 정상297개와 비교해 얼마나 드문지 p=(1+같거나큰 정상 점수 수)/298로 계산하고,
어느 영역이든 p≤0.05/12면 경고했다. 이 표본 수에서는 각 영역의 정상 최댓값을 엄격히 초과해야 한다.
순위 p값 정의는 [Royal Holloway 연구팀 설명](https://cml.rhul.ac.uk/CP/)을 참고했고,12영역 위험 배분과
297장에 대한 해상도는 [새 계약](../docs/mpi-region-rank-v1.md)에 명시했다.
실물/세션의 교환가능성이 미확인이라 현장 오경보5% 보장은 주장하지 않는다.

| 항목 | 기존 Q90 | 정상 순위 영역별 후보 |
| --- | ---: | ---: |
| 불량55장 검출 | 53 | 40 |
| 놓친 불량 | 2 | 15 |
| 정상54장 오경보 | 3 | 1 |
| 정상256장 오경보 | 14 | 10 |
| 기존 검출 상실 | — | 13 |
| 새 불량 검출 | — | 0 |

새 미탐13장은0017·0021·0022·0023·0025·0027·0028·0034·0035·0041·0043·0044·0047이다.
원래 놓친0019·0024도 남는다. 사전에 고정한 검출 조건 실패로 **비채택, bootstrap 미실행**이다.
안정성 검증 완료나안정성 실패로 바꾸어 적지 않는다. CPU 비교0.042초, peak RSS약43.36MiB였다.

정상 오경보를 보수적으로 통제하는 동안 불량도 정상 상한 아래에 남았다. grid3-2의 정상 최댓값은
43.3986으로 기존 경고 경계41.6959보다 높다. 이 후보에서는 다른 영역의 정규화 폭을 바꾸지 않아도
해당 영역 자체의 정상 고득점이 검출을 막을 수 있다. 영역을 나누는 것만으로 해결됐다고 할 수 없다.

## 검증과 보존

실행 전 로컬 커밋: 가능성 진단7b9912e, 실제 후보8f87fab. 입력 ZIP·payload·원래662장 계약을 검증했고
기존 점수 차이0·판정 변경0을 확인했다. 후보662장 판정을 별도의 정수 p값식으로 모두 재계산해 일치했다.
진단 해의53장 보존과 정상1/2장 경고도 별도로 확인했다.

가능성 진단 포함 전체 테스트626개·52 subtest 통과 후, 마지막 실제 후보 추가를 포함한
관련 테스트31개를 통과했다. 실제 후보 추가 후 전체 suite를 다시 실행한 것은 아니다.
이전 파일과 사용자 건강 검토 보고서는 보존했으며 원격 업로드는 수행하지 않았다.

전수 결과는 `artifacts/analyses/mpi-region-threshold-feasibility-v1/`와
`artifacts/analyses/mpi-region-rank-v1/`, 영구 요약은 [결과·검산 JSON](mpi-region-structure-v1-results.json)에 있다.
진단 경계는 `DO_NOT_DEPLOY`로 표시하고 서비스/모델 계약으로 내보내지 않았다.

## 다음 작업 방향

이번 묶음은 종료한다. **같은 top1 원점수의 보정 공식·영역 경계만 계속 바꾸는 작업은 추가하지 않는다.**
기존 점수로 가능한 분리는 있지만 정답과 특정 영역에 의존하는 해였고, 정상-only 단일 후보는 실패했다.
현재 원점수의 절대 한계가 증명된 것은 아니므로 ‘어떤 방법도 안 된다’고 결론내리지 않는다.

다음 모델 작업은 특징/지도에서 정상 외관과 결함을 구분하는 정보를 개선할 변경안1개를 골라
설계·구현·검증·GPU 실행 준비까지 묶는 방향으로 제안한다. 앞서 실패한 동일 영역 검색·공간26×26
집계·정상64장 재선정의 이름만 바꾼 반복은 제외한다. 원래 실험의 한도와 실패는 그대로 보존한다.
새 표현을 만들지 않고현재 점수만으로 성적을 계속 맞추는 것은 이번 증거로 우선순위가 낮아졌다.

아직 구체적인 새 특징/학습 방식·실행 예산은 선정하지 않았고 새 학습은 시작하지 않았다.
그 선정은 새 작업 범위이며, 장시간 실행이 필요하면 예상 자원과 Windows 명령을 한 번에 안내한다.
현재 사용자에게 필요한 연구실 실행은 없다.
