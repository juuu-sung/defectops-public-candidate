# SuperSimpleNet 합성 위치 변경 학습 수령 검토

2026년 10월 5일 검토. 500회 실행은 완료했지만 새 합성 난수에서 정상과 이상 위치를 확실하게 구분하지 못했다. **학습량 확대의 근거는 아직 부족하다.** 잡음 크기만 바꾸는 작은 비교로 원인을 좁히기로 했다.

입력은 `mpi-supersimplenet-varying-synthetic-v1.zip`, SHA256 `109090f6e97d8759ceb5bc7658fa742aff46a97be7559451099614b3ea9ebc1c`다. 이전 고정500 결과와 같은 원본 정상 한 사진의 8타일을 사용했다.

## 검증 범위

ZIP의 중복 없는 28개 항목과 27개 payload checksum, 8개 phase receipt, 40개 평가 묶음과 80개 손실 분해를 검산했다. 500개 학습 step은 seed 10000부터 10499까지이며 서로 다른 합성 target hash 500개가 기록됐다. 코드 원본 16개 hash도 일치했다.

원본 정식 모델과 고정500의 참고 seed42 결과는 이전 ZIP과 각각 원시 배열 최대차 0이었다. 전달 ZIP에는 가중치가 없으므로 연구실의 최종 재로딩 차이 0과 checkpoint 원본 보존은 기록으로 확인했으며 Mac에서 GPU 재추론한 것은 아니다.

## 동일한 네 평가 난수에서 비교

| 조건 | 사진 AUROC | 픽셀 AUROC | 같은 위치 정상 대비 합성 구분 AUROC |
| --- | ---: | ---: | ---: |
| 원본 정식 모델 | 0.5565 | 0.5450 | 0.5000 |
| 고정 합성500 모델 | 0.5148 | 0.4822 | 0.5004 |
| 위치 변경500 모델 | 0.6303 | 0.5035 | 0.4999 |

900001부터 900004까지의 정의 가능한 지표 평균이다. 참고 seed42는 평균에서 제외했다. 네 번의 합성 난수 반복을 독립 제품 표본으로 취급하지 않는다.

사진 AUROC 0.6303만 보면 개선처럼 보이지만, 합성을 넣지 않은 정상 대조 점수에 같은 합성 label을 붙인 진단 AUROC가 0.6369였다. 같은 원본의 정상/합성 사진 점수 구분 AUROC는 0.4903이다. 합성 이상에 반응하는 능력을 배웠다고 결론 낼 근거가 부족하다.

정상 지도에 합성 위치만 대입한 대조 픽셀 AUROC 0.5036은 실제 합성 지도 0.5035와 거의 같다. 합성 위치의 평균 지도 변화는 -0.00001485이며 전체 다섯 평가에서 최종 지도 logit은 음수였다. 음수라는 사실 자체가 서비스 합격 판정은 아니다.

첫 50회와 마지막 50회 평균 손실은 1.06030에서 1.05739로 약 0.275% 낮아졌다. adaptor·분류·위치 head의 유한 gradient와 가중치 변화는 기록됐고 backbone은 보존됐다. 코드가 실행되지 않았다는 문제와 학습 구분력이 약한 문제를 구분해야 한다.

## 비용과 해석

실행 191.73초, RAM 최고 2.447 GiB, GPU allocated 3.270 GiB, reserved 5.119 GiB다. 표본화된 전체 device 사용량은 6.914 GiB로 PyTorch reserved와 다른 범위다. 실제 불량·시험 mask 접근 및 경고 기준 변경은 없었다.

현재 결과는 위치를 바꾸면 기존 고정 문제에서의 높은 성적이 유지되지 않는다는 근거다. SuperSimpleNet 자체가 불가능하거나 작은 잡음만이 원인이라고 확정하지 않는다. [잡음 강도 제한 비교](../docs/mpi-supersimplenet-noise-strength-v1.md)에서는 0.03·0.06을 각각 학습하되 모든 후보를 공통 0.015·0.03·0.06으로 검사한다. 실제 결함 시험과 서비스는 그대로 둔다.
