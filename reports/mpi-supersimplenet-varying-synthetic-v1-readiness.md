# SuperSimpleNet 합성 이상 변경 실험 실행 준비

사용자가 승인한 후속 실험을 별도 실행기로 준비했다. 이전 실험의 정상 타일 8개·시작 모델·
학습률·최적화기·500회 업데이트·잡음 크기는 유지하고, 합성 이상 난수만 업데이트마다 바꾼다.
원래 300 epoch 모델에서 시작하며 고정500 모델을 이어 학습하지 않는다.

## 고정된 비교

학습 난수 10000–10499와 평가 난수 900001–900004는 서로 겹치지 않는다.
이전 난수 42는 재현 확인용으로 별도 보고하며 공통 새 난수 평균에 넣지 않는다.
이전 고정500 모델을 동일한 평가 문제에 읽기 전용으로 실행한다. 코드가 그 모델에
업데이트를 시도하면 즉시 오류를 낸다. 중간 최고 성적에 따른 모델 선택·난수 재추출·학습 연장은 없다.

각 평가에는 원래 정상과 합성 이상 특징의 지도·분류 점수, 동일 위치 대조, 같은 원본끼리의
점수 비교를 포함한다. 위치 AUROC만 높아지는 현상을 실제 이상 구분력 개선으로 오해하지 않도록 했다.
기존 결과와 모델 파일은 수정하지 않는다. 새 원본 이미지나 실제 불량 시험 자료를 열지 않는다.

## 검증한 범위

- 전체 CPU 검사 909개 및 52개 하위 검사가 통과했다. 기존 경고 3건만 남았다.
- 이후 추가한 읽기 전용 보호·실행 경로·학습 조건 동일성 검사를 포함해 전용 17개 검사도 통과했다.
- 정상 중단 후 체크포인트 재개, 재실행 업데이트 누적, 고정 대조 재사용을 모의 runtime으로 확인했다.
- 원본 변경·결과 변조·평가 위치 불일치·재로딩 차이·자원 실패·강제 종료 기록 누락은 자동 통과하지 않는다.
- 실제 수령한 고정 실험 ZIP의 원본 모델·입력·계약·과거 소스와 새 준비 코드가 요구하는 값이 일치했다.
- 원본 Python 실행 파일은 변경하지 않았다. 새 실험 파일과 안내 문서만 추가하고 현재 계획을 갱신했다.

Mac에는 실제 torch/CUDA 학습 환경이 없어 새500 학습과 공통 GPU 평가의 성공은 아직 확인하지 않았다.
CPU 테스트를 GPU 통과나 성능 개선으로 해석하지 않는다. 계산 시간 30분·RAM 20 GiB·
GPU reserved 6 GiB·디스크 여유 8 GiB 제한을 유지한다. 두 모델은 차례로 올린다.

## 실행과 결과 전달

[Windows 실행 안내](../docs/mpi-supersimplenet-varying-synthetic-v1.md)를 따른다.
출력은 `mpi-supersimplenet-varying-synthetic-v1.zip`이다. 원본 이미지·특징·가중치는 ZIP에 넣지 않는다.
결과 수령 후 공통 새 난수의 구분력과 정상 대조 차이를 비교한다. 같은 정상 사진의 합성 문제이므로
새 제품이나 실제 불량에 대한 성능 주장은 하지 않는다.
