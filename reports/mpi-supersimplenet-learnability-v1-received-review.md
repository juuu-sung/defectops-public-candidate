# SuperSimpleNet 고정 문제 학습 결과 검토

500회 학습은 정상 완료됐고 손실과 같은 문제의 구분력은 개선됐다. 다만 정상 대조에서도
학습 때 이상이 있었던 위치에 강하게 반응했다. 위치 암기 영향을 배제하지 못하므로 실제 불량 성능
개선으로 해석하지 않는다. 후속 실험은 같은 타일에서 합성 이상 위치·잡음을 바꾸는 제한 비교다.

## 수령과 검산

수령 파일은 `mpi-supersimplenet-learnability-v1.zip`, 크기 5,084,333바이트,
SHA256 `cd4c0dad237ccddc28717a9293def9f96eb2b79d36335e89b2610ebba176a5a2`다.
24개 payload의 해시, 7개 체크포인트 영수증과 수치, 500개 업데이트 기록을 검산했다.
수령 당시 소스 해시 11개가 일치했다. 초기 배열은 이전 합성 점검 seed42의 배열과 차이 0이다.
원시 배열로 AUROC와 손실 구성요소를 다시 계산해 허용 수치 오차 내 일치를 확인했다.

실행 시간은 151.22초, RAM peak 2.398 GiB, GPU allocated peak 3.270 GiB,
reserved peak 5.098 GiB다. 설정된 계산·자원 예산 이내이며 오류가 없다.
재로딩 최대 차이 0과 원본 모델 불변은 Windows 실행기의 보고다.
가중치가 ZIP에 없으므로 Mac에서 실제 체크포인트 바이트와 재추론까지 독립 확인한 것은 아니다.

## 같은 고정 문제에서의 변화

| 업데이트 | 학습 모드 손실 | 추론 타일 분류 AUROC | 추론 위치 AUROC |
| --- | --- | --- | --- |
| 0 | 1.0401 | 0.4364 | 0.5972 |
| 100 | 0.3180 | 0.8182 | 0.9472 |
| 300 | 0.1174 | 1.0000 | 0.9862 |
| 500 | 0.0839 | 0.9455 | 0.9899 |

기울기가 기록되고 변환부·분류부·위치 검출부가 모두 변경됐다. 작은 문제의 학습은 가능하지만
분류 성적은 단조 증가하지 않는다. 중간 최고 성적 체크포인트를 선택하지 않았다.
정상 사진 1073의 8타일을 두 번 복제한 16개 특징 중 5개에 이상이 있고 11개에는 없었다.
독립적인 정상/불량 제품 16개를 검사한 결과가 아니다.

## 정상 대조에서 드러난 한계

500회 모델의 합성 이상 위치 642픽셀에서 평균 지도 출력은 이상을 넣었을 때 0.8427,
원래 정상 특징에서는 0.8099였다. 두 경우 모두 해당 위치의 642픽셀 전체가 원시 출력 0보다 컸다.
정상 지도에 같은 합성 위치를 대입한 대조 AUROC는 0.9887로, 합성 지도 AUROC 0.9899에 가깝다.
이 대조 AUROC는 정상 이미지의 정확도가 아니라 위치 암기 가능성을 점검하는 계산이다.

한편 합성 양성 5개 모두 정상 대비 분류 점수가 올랐고 그 평균 차이는 0.1812였다.
동일 위치의 정상·합성 출력만 비교한 픽셀 AUROC는 0.5406이다.
즉 반응 자체가 전혀 없지는 않지만, 높은 위치 순위 대부분을 이상 존재 여부의 구분으로 해석할 수는 없다.
원시 출력 0은 서비스 임곗값이 아니다.

합성 잡음 RMS는 약 0.015로 유지됐다. 잡음을 넣은 위치의 정상 특징 RMS 대비 비율은
3.63%에서 3.89%로 변했다. 이 비율만으로 학습 가능성이나 이전 실패 원인을 확정하지 않는다.

## 후속 결정

사용자 승인에 따라 [합성 이상 변경 실험](../docs/mpi-supersimplenet-varying-synthetic-v1.md)을 준비한다.
기존 고정500 모델과 새로운 변경500 모델을 같은 학습 미사용 난수에서 평가하고 정상 대조를 함께 본다.
기존 원본·고정 모델·Q90·서비스는 보존한다. 실제 불량 시험·자동 모델 선택·대규모 학습 확대는 하지 않는다.
