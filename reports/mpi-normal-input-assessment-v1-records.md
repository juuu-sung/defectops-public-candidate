# MPI 정상 입력 점검 기록 기반 실행 결과

2026-10-14. 고정 정상 512사진을 입력 상태로 분류하고 기존 모델 경고와 대조했다. 검증 정상 256사진에서 입력 확인 대상은 13장, 기존 모델 경고는 15장, 두 조건의 중복은 4장이다. 합집합 24장은 검토 우선순위 대상이지 결함 검출 수가 아니다. 기존 모델의 15건 오경보와 불량 55/55 검출, 시험 정상 0/54 오경보는 그대로 보존했다.

## 입력 상태와 기존 모델 경고

| 자료 | 필수 타일 정보 없음 | 부분 검은 영역으로 입력 검토 필요 | 제한 점검 이상 없음 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 학습 정상 | 0 | 19 | 237 | 256 |
| 검증 정상 | 1 | 12 | 243 | 256 |

학습자료는 기존 모델 결과가 제공되지 않아 null로 기록했다. 미채점 결과를 0점이나 정상으로 바꾸지 않았다. 전체 검은 필수 타일을 포함한 검증사진은 0274다. 작은 부분 검은 영역은 정보 없음이 아니라 사람의 입력 검토가 필요한 관찰로 남겼다.

| 검증 입력 상태 | 기존 모델 경고 | 기존 경고선 미만 | 합계 |
| --- | ---: | ---: | ---: |
| 필수 타일 정보 없음 | 1 | 0 | 1 |
| 부분 검은 영역으로 입력 검토 필요 | 3 | 9 | 12 |
| 제한 점검 이상 없음 | 11 | 232 | 243 |
| 합계 | 15 | 241 | 256 |

경고선 미만이지만 입력 확인 대상으로 분류된 9사진은 0350·0390·0853·0912·1058·1100·1139·1185·1199다. 이들은 정상 라벨이며 새로운 미탐 발견이나 실제 검사 불가 확정이 아니다. 필요한 부위가 가려졌는지 사람 판단이 아직 없다. 입력 확인을 추가하면 경고 목록만 볼 때보다 우선 확인 부담이 늘어날 수 있다는 결과다. 나머지 사진도 자동 합격시키지 않는다.

## 구현과 검증 범위

[점검기](../scripts/assess_mpi_normal_inputs.py)는 서비스·DB와 분리되어 동작한다. [설계 및 실행 안내](../docs/inspection-input-assessability-v1.md)에 따라 입력 상태와 모델 결과를 분리하고, 모델 결과는 입력 목록과 다른 페이지에 표시한다. 사람이 보는 화면은 읽기 전용이며 의견 저장·승인·티켓 기능은 없다.

고정 외관 점검 ZIP 및 원특징 모델 ZIP의 해시·소스·명단·원본 행을 확인했다. 기존 저장 점수에서 판정을 다시 계산해 부모 결과와 정확히 일치함을 확인했다. 모델 실행이나 경고선 재보정은 없다. 512사진 상태는 새 분류 함수를 사용하지 않은 별도 집계로도 일치했다.

6,144타일 중 첨부된 고유 원본 529타일의 픽셀·검은 영역 통계를 직접 검산했다. 외관 ZIP의 원본 파일 530개 중 한 개는 같은 타일의 중복 역할이므로 고유 개수는 529다. 다른 타일의 분류는 고정된 연구실 통계 기록에 기반한다. 입력 확인 대상 타일 중 37개는 원본이 없어 기록과 원본 검증 범위를 화면에서 구분했다.

읽기 전용 HTML 514페이지의 로컬 링크가 모두 유효했고, 브라우저에서 목록·0274의 전체 검은 타일 원본 표시를 확인했다. 동일 입력 재실행은 기존 ZIP을 변경하지 않고 일치 여부를 검산했다. 기술 오류·통계 오류·필수 영역 누락·원본 변조·시험 이미지 미열람·미채점 null·중복 집계 방지·기존 경고 유지·결과 변조 보존에 대한 회귀 테스트를 포함했다.

관련 테스트 42개가 통과했고, 전체 테스트는 1,371개 통과·13개 건너뜀·52개 하위 테스트 통과였다. 경고 3개는 Starlette 의존성의 폐기 예정 API 안내와 기존 중복 ZIP 검사 테스트에서 발생했다. 연구실 Windows PowerShell 실행과 실제 전체 아카이브 모드는 이 로컬 테스트 결과와 구분한다.

전달물 `artifacts/handoff/mpi-normal-input-assessment-v1-records.zip`의 SHA256은 `262a8a9185c674a7b46004cf6a408a07cc520bd5dbaad31b27020c036f758e0a`이다. 내용 파일 1,045개의 해시와 ZIP 무결성을 검산했다. HTML의 원본은 비공개 검토용이며 GitHub에 올리지 않는다.

## 남은 단계

기록 기반 실행은 완료했다. 전체 원본 모드는 연구실의 `extracted.zip`으로 6,144정상타일을 다시 확인하고 입력 사유가 있는 원본들을 검토 목록에 추가한다. 현재 실물 아카이브에서 이 옵션을 실행한 결과는 없다. 합성 아카이브 테스트에서 정상 명단만 읽고 시험 경로를 읽지 않는 것은 검증했다.

원본 확보 뒤에는 입력 사유가 있는 사진의 필요한 검사 부위가 실제로 가려졌는지 검토한다. 검토가 완료되기 전 영상 부적합 확정, 입력 거부 정책 도입, 성능 향상을 주장하지 않는다. 내부 부품 오경보와 보정 불안정은 해결되지 않았으며, 이번 결과를 재학습·서비스 교체의 승인으로 사용하지 않는다.
