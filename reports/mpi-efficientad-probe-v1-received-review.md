# EfficientAD-S 정상 이미지 사전 점검 수령 검토

2026-10-04. **D2 자원·호환성 점검 통과. 정식 학습 준비로 넘어갈 근거를 확보했다.**
정확도·수렴·서비스 사용 승인은 아니다. 기존 Q90과 transistor 서비스는 변경하지 않는다.

## 무엇을 실행했는가

기존 정상 학습64사진 중 고정8사진×12영역=96타일과 Imagenette train 보조96장을 사용했다.
고정 teacher의 특징을 student와 autoencoder가 학습하도록 실제 optimizer100회 업데이트했다.
정상128/169장 보정·불량 이미지·마스크는 사용하지 않았다. 기존 PatchCore에 자료를 추가한 것이
아니라 별도 EfficientAD-S의 작동·자원·저장 복원을 짧게 확인한 것이다.

900초·RAM20GiB·GPU reserved6GiB 제한 안에서 완료했다. 모델·optimizer·난수 상태 복원 검사도
통과했다. 메모리 샘플530개는100ms 주기와 명시적 경계 측정을 합친 수라서53초 실행을 뜻하지 않는다.
실제 환경은 Windows/Python3.12.0, torch2.8.0+cu128, torchvision0.23.0+cu128,
anomalib2.2.0, RTX5060이다. 정식 학습의 메모리·시간은 별도로 감시해야 한다.

## 학습이 잘됐다고 말할 수 있는가

아직 아니다. 세 손실의 합은 최소6.908, 최대474.302였고 처음10회 평균20.048,
마지막10회 평균24.152였다. 손실과 gradient는 모두 유한했고 gradient norm은3.667~903.391이다.
입력 타일과 증강이 바뀌므로 처음·마지막 평균만으로 발산 또는 수렴을 판단하지 않는다.

가장 큰 손실은49회째 정상0195의 grid1-1에서 발생했다. student-teacher 항460.275가
주된 비중이지만 이 항에는 보조 이미지 penalty도 함께 들어 있다. 현재 기록만으로0195의
외관, 보조 이미지, 초기 학습 상태 중 무엇이 원인인지 분리할 수 없다. 이 사진을 삭제하거나
불량으로 재분류할 근거는 없다. 같은 이유로 임의의 학습률 하향·gradient clipping을 추가하지 않는다.

이번 통과의 의미는 **실제 학습 연산·추론·저장 복원이 정해진 자원 안에서 작동했다**는 것이다.
불량 검출률·오경보율은 아직 계산하지 않았으며 PatchCore보다 정확하거나 빠르다는 결론도 아니다.

## 전달 파일 검증

- ZIP6개 JSON: 중복 파일 없음, CRC 정상, manifest의 payload5개 SHA256 일치.
- 원래 준비 ZIP으로 고정8사진·96타일 계획을 재구성해 일치. 현재 소스134개 해시 일치.
- 계획 지문·정책·공식 보조 자료 출처·환경·보조 train96개 목록 연결 확인.
- 0/25/50/75/100회 checkpoint receipt5개 지문·파일 구성 일치. 마지막 progress 해시 일치.
- 100개 step·손실·gradient·완료 시도·시간·메모리·두 재로딩 기록의 내부 일관성 확인.

  대조하거나 Mac에서 CUDA 학습을 재실행한 것은 아니다. receipt 검증과 실물 검증을 구분한다.

## 다음 단계

1. D3 정식 학습 실행 카드와 실행기를 준비한다. 학습 step·학습률 일정·최종 checkpoint 선택,
   시간·메모리 중단 기준, 정상화 방식과 보정 안정성 허용폭을 불량 결과를 보기 전에 확정한다.
2. 기존 정상64사진×12영역으로 teacher 통계를 다시 계산하고 새 초기값에서 학습한다.
   이번100회 checkpoint를 정식 모델의 시작점으로 재사용하지 않는다. 고정 seed의 입력 순서와
   정상 모니터 표본, 손실·gradient·자원·저장 복원을 기록한다.
3. 분리된 정상128사진으로 지도·영역 척도를, 정상169사진으로 사진 경고 기준을 계산한다.
   128사진의 두 보정 용도 공유를 명시하고, 지도 보정까지 포함한 재표집 검사를 사전 설계한다.
4. 정식 모델·보정·복원 검증 후에만 기존 검출12장 회귀검사를 먼저 수행한다. 이후 전체 관찰
   회귀 자료와 비교하되 독립 신규 성능으로 표현하지 않는다. 서비스 전환·자동 PASS는 없다.

현재 추가 Windows 실행 명령은 없다. 점검을 반복할 필요 없이 기존 산출물을 보존한다.
이번 기록은 D3 실행 승인이나 장시간 학습을 시작했다는 뜻이 아니다.
