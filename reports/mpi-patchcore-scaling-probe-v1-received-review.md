# PatchCore 확대 계산 점검 결과

2026-10-07. 합성 특징으로 전체 후보 규모의 분할 계산을 점검했고, 실제 정상256장 실행기를 준비할 근거를 확보했다. 이것은 모델 학습이나 성능 평가 결과가 아니다.

수령 파일 `mpi-patchcore-scaling-probe-v1.zip`의 SHA256은 `a4665ce927610f63641169be6a3e3749502a4777fa9244df89688dfc87bb1a89`다. 6개 payload와 내부 manifest, 고정 계획, 201개 소스 지문, 기존64장을 포함하는256장 명단을 대조했다. 한 번의 완료 시도이며 기록 오류는 없다.

## 다음 실행에서 유지할 조건

작은 합성 문제의 일치가 실제 수백만 특징 전체의 선택을 비트 단위로 보장하지는 않는다. 실제 실행은 후보 전체를 보존하고 분할 행렬 곱·행별거리·첫 최댓값 선택을 명시한다. 원특징과 투영 결과를 디스크에 저장하고, 특징 추출 모델과 전체 투영 배열을 GPU에 동시에 두지 않는다.

실제 실행기는 [정상256장 확대 계획](../docs/mpi-patchcore-scaling-v1.md)을 따른다. 최종 bank78,643개, 기존 특징 추출기, 별도 정상128/169 보정, 관찰된55불량·정상54/256 전체 비교를 고정한다. 검사 시간 상한은 없지만 RAM20GiB·GPU reserved6GiB·무결성 조건은 유지한다. 성능 미달은 평가 중단 조건이 아니며, 파일 손상·재현 실패·자원 초과는 중단한다.

기존 모델·서비스·주 경고선은 바꾸지 않는다. 합성 점검 성공을 결함 검출 향상이나 실제 GPU 전체 학습 성공으로 해석하지 않는다.
