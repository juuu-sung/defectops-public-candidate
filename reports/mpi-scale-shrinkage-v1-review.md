# MPI 정상 보정 부분 공유 실험 결과

2026-10-01 실행 결과입니다. **50% 부분 공유 후보는 비채택입니다. 정상 오경보는 줄었지만
불량 검출이 53장에서 42장으로 떨어졌고, 보정 표본 변화에 대한 안정성도 개선 조건을 통과하지 못했습니다.**
기존 Q90을 연구 비교 기준으로 보존합니다. 기존 Q90 자체의 정상 오경보·보정 안정성 문제는 해결되지 않았으며
서비스 사용이나 자동 합격을 승인하지 않습니다.

## 이번에 확인한 질문

12영역의 정상 변동 폭을 개별 값50%와 전체 대표 값50%로 섞으면 정상 기준을 안정화할 수 있는지
확인했습니다. 모델·정상 패치 bank·입력·원점수·top1 집계는 유지했습니다. 새 학습이나 GPU 추론은 없습니다.
후보 경고 기준만 정상169장에서 해당 계산법에 맞게 산출했으며 서비스 설정은 변경하지 않았습니다.

[사전 카드](../docs/mpi-scale-shrinkage-v1.md)와 [고정 config](../configs/mpi-scale-shrinkage-v1.json)는
결과 계산 전에 `f432f4b`로 공유됐습니다. config는 수정하지 않았습니다. 사용자의 후속 실행 동의에 따라
CPU 실행기를 구현하고 합성 테스트 후 이 단일 후보를 실행했습니다. 다른 혼합 비율은 계산하지 않았습니다.

정상64장은 기존 bank 출처, 정상128장은 변동 폭 추정, 정상169장은 경고 기준 산출용입니다.
기존 test109장과 후속 정상256장은 이미 관찰한 개발·회귀 자료이며 독립 성능 시험이 아닙니다.

## 검출을 잃은 계산상 이유

추가 미탐11장 모두 기존·후보에서 최고 반응 영역은 `grid3-2`였습니다. 이 영역의 정상 변동 폭은
`3.278092 → 3.903321`로 커졌습니다. 같은 이상 반응을 더 큰 분모로 나누므로 정규화 점수가 작아졌습니다.
사진 경고 임곗값도 `2.316961 → 2.385100`으로 바뀌었습니다. 서로 다른 척도의 임곗값 크기만으로
민감도를 비교하면 안 되므로, 원래 점수 단위의 영역 경계도 확인했습니다.

| 항목 | 기존 Q90 | 부분 공유 |
| --- | ---: | ---: |
| grid3-2 원점수 경고 경계 | 41.695899 | 43.410501 |
| 경고 기준 경계에 놓인 정상 사진 | calibration/1365 | calibration/1365 |
| 그 정상 사진의 최고 영역 | grid1-1 | grid1-1 |

즉 다른 영역의 정상 점수를 포함해 계산된 사진 기준을 넘기 위해 grid3-2가 요구받는 반응이
더 커졌습니다. 그 사이에 있던11장의 검출이 사라진 것이 **관찰된 계산상 설명**입니다.
정상 사진1365가 잘못된 사진이거나 라벨 오류라는 뜻은 아닙니다. 재표집에서 어떤 정상 사진과
영역이 불안정성을 주도하는지, 정상 모집단이 적절한지는 아직 확정하지 않았습니다.

## 정상 표본 변화에 대한 안정성

기준선과 후보에 동일한 원본사진 행을 복원추출했습니다. 12영역의 관계를 유지하고,
개발 표본이 바뀔 때 공유 대표 폭도 다시 계산했습니다. 각 상황1,000회, 총3,000회입니다.
실패 반복은0회이며 전부 저장했습니다.

아래 범위는 고정된 불량55장에 대한 검출 수의2.5~97.5 분위 범위입니다.
**미래 제품 검출률의 신뢰구간이나 최소·최대값이 아닙니다.**

| 바꿔 뽑은 정상 자료 | 기존 Q90 검출 수 | 부분 공유 검출 수 | 변동 폭 기존→후보 |
| --- | --- | --- | --- |
| 개발128장만 | 4~55, 중앙52 | 7~52, 중앙42 | 51→45 |
| 보정169장만 | 45~55, 중앙53 | 18~55, 중앙42 | 10→37 |
| 개발과 보정 모두 | 3~55, 중앙52 | 2~55, 중앙43 | 52→53 |

어느 상황에서도 변동 폭 절반 이하·검출 하단50장 이상 조건을 충족하지 못했습니다.
특히 보정 자료만 바꿔도 기존보다 훨씬 흔들렸습니다. 개발만 바꾼 경우의 폭 감소만 골라서
안정성 개선으로 해석하지 않습니다. 보정만/둘 다 상황에서는 정상 오경보 상단 조건도 실패했습니다.
세부 분위수와 조건별 판정은 [수치 결과](mpi-scale-shrinkage-v1-results.json)에 보존했습니다.

## 실행과 검증

- 이전 원점수662장으로부터 Q90 파라미터·영역 점수·판정을 대조했습니다. 최대 차이0, 판정 변화0입니다.
- ZIP CRC와 전체 payload 해시, 고정 원점수·계약 해시, 명단·라벨·12영역 순서를 확인했습니다.
- NumPy 구현과 별도로 Python 표준 라이브러리의 중앙값·정렬 분위수 계산으로 고정 성적과 경고 기준을 대조했습니다.
- 전체3,000회 반복의 표본 인덱스·파라미터·계수를 저장하고, 완료 후 재실행으로 동일 증거와 요약의 재현을 확인했습니다.
- 합성 테스트14개, 전체 pytest426개와52개 subtest 통과. 기존 경고3개는 의존성 deprecated alias 및 중복 ZIP 거부 시험입니다.
- Mac arm64, 논리 CPU8개, Python3.11.9, NumPy2.3.3. 최초 실행 분석 구간3.103초, peak RSS53,280,768bytes 약50.81MiB입니다.

30분·2GiB CPU 분석 예산은 통과했습니다. 이 시간은 입력 검증부터 반복 저장·요약까지이며
마지막 보고서/시도 영수증 직렬화는 제외합니다. **GPU 추론 속도나 서비스 응답 시간이 아닙니다.**
프로세스 강제 종료로 시도 비용이 누락되면 비용 통과를 허용하지 않도록 실행기에 기록했습니다.

저장 위치는 `artifacts/analyses/mpi-scale-shrinkage-v1/`이며 약9.3MB입니다. 기존 결과를 덮어쓰지 않고
동일 입력·설정·코드·환경으로 재개할 때 이전 반복을 재계산해 일치 여부를 확인합니다.
입력 ZIP SHA256은 `8429a970864c1116d5f52b786057fc84c3e48f465b5c502715ab7f61d35e13dc`,
실행기 SHA256은 `26126dfe8ea98d2ac90231dbc9cff2f1f05214ad135f8cab005b046dd4582530`입니다.
Git에는 집계 JSON·보고서·실행기·시험을 보관하며 대량 반복 자료는 로컬 산출물로 보존합니다.

## 결정과 다음 단계

**MPI-C1-01은 성능·안정성 조건 실패로 비채택합니다.** 기존 Q90은 연구 기준선일 뿐이며
현장 사용 승인이나 독립 일반화 검증을 받은 것이 아닙니다. 새 학습·모델 교체·자동 PASS는 하지 않았습니다.

이 결과는 모든 보정 안정화 방법이 실패한다는 증거가 아니라, 사전에 정한50% 부분 공유 후보가
이 자료에서 실패했다는 근거입니다. 25%·75%로 비율을 바꿔 성적을 다시 찾지 않습니다.
사이클 새 후보 한도2개 중1개를 사용했고, 남은1개는 자동 실행하지 않습니다.

다음 제안은 **저장된 재표집 결과를 이용한 정상 표본 영향 분석**입니다. 성능이 무너진 반복에서
어떤 정상 사진·영역이 경고 경계와 변동 폭에 영향을 줬는지 좁히되, 해당 사진을 제거하거나
새 수식을 평가하지 않는 진단으로 제한합니다. 기준선의 보정 불안정 원인이 미확정인 상태에서
다른 공식을 바로 추가하는 것보다 다음 변경의 근거를 만들기 위한 작업입니다.
현재 연구실 Windows에서 실행할 작업은 없습니다.
