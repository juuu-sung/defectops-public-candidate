# SuperSimpleNet 고정 합성 이상 제한 학습

기존 모델이 작은 정상·합성 이상 문제를 학습할 수 있는지 확인한다. 전체 학습량을 늘리기 전에
특징과 잡음의 크기, 손실, 실제 구분력이 함께 개선되는지 점검하는 진단이다.
기존 300 epoch 모델의 복사본만 업데이트하며 원본 체크포인트·경고 기준·Q90·서비스는 유지한다.

## 이번 실험에서 바꾸는 것

기존 학습 정상 목록의 첫 사진에서 앞쪽 8영역 타일을 순서대로 사용한다. **정상 사진 8장이 아니라
한 사진의 타일 8개**다. 공식 생성기가 이를 16개 특징으로 복제하고 seed 42로 합성 이상을 만든다.
매번 동일한 타일·잡음 난수·이상 위치를 반복한다. 매 업데이트에서 이진 정답의 해시가 동일한지 검사한다.
잡음은 현재 특징 변환부 출력에 더하므로 변환부가 학습되면 잡음 대비 특징의 크기는 달라질 수 있다.
실제 더해진 잡음에는 부동소수점 덧셈 오차가 포함되며, 원시 난수와 이를 구분한다.

| 항목 | 고정 조건 |
| --- | --- |
| 시작점 | 검증된 300 epoch 최종 모델 복사본 |
| 학습 대상 | 특징 변환부 adaptor와 위치·사진 검출부 segdec |
| 고정 대상 | 사전 학습 특징 추출기와 그 통계 |
| 업데이트 | 500회, 조기 성공 종료·자동 연장 없음 |
| 최적화 | 새 AdamW, adaptor 학습률 0.0001·감쇠 0.01, segdec 0.0002·감쇠 0.00001 |
| 잡음 | 공식 anomalib 2.2.0, 표준편차 0.015, Perlin 기준 0.6 |
| 기록 시점 | 0·50·100·200·300·400·500회 |
| 자원 제한 | 시도 누적 계산 30분, RAM 20 GiB, GPU reserved 6 GiB, 디스크 여유 8 GiB |

기존 종료 시점의 작은 학습률과 최적화 이력을 그대로 잇는 실험은 아니다. 작은 문제의 학습 가능성을
확인하기 위해 원래 시작 학습률로 새 최적화기를 만든다. 따라서 성공해도 과거 실패 원인이
학습률인지·데이터 다양성인지·다른 조건인지 이 실험 하나로 구분할 수 없다.

## 무엇을 측정하는가

시작과 종료 시 특징 변환 전후의 평균·표준편차·RMS를 기록한다. RMS는 값의 전반적인 크기다.
합성 이상이 들어간 위치에서 실제 잡음 RMS와 같은 위치의 정상 특징 RMS를 비교한다.
특징 표준편차는 이번 8타일 내부 통계이지, 전체 정상 제품의 변동 추정치가 아니다.
잡음 비율이 작다는 사실만으로 학습 불가능하다고 단정하지 않는다.

각 업데이트에서 위치 focal 손실, 위치 분리 손실, 사진 분류 손실 및 각 학습 부분의 기울기를 남긴다.
기록 시점에는 **동일한 합성 특징**을 학습 모드와 추론 모드에 넣고 사진·픽셀 AUROC와
원래 정상 대비 점수 변화를 함께 기록한다. 진단 중 변경되는 BatchNorm 통계는 복원한다.
실제 학습 업데이트에서 누적된 통계는 새 실험 모델의 일부로 보존한다.

## 결과를 해석하는 방법

학습한 바로 그 작은 묶음에서 측정하므로 결과는 암기 가능성 검사다. 새 불량을 찾는 능력이나
독립적인 정확도 검증이 아니다. 중간 성적을 보고 가장 좋은 체크포인트를 골라 서비스에 넣지 않는다.
수치 기준으로 자동 합격시키지 않고 전체 궤적과 두 모드의 차이를 검토한다.

- 손실 감소와 정상·합성 이상 구분 개선이 함께 나타나면 작은 문제를 배울 수 있다는 근거다.
  이후 별도로 고정된 정상 자료에서 다양성·학습량 확대 실험을 설계한다. 확대는 자동 실행하지 않는다.
- 학습 모드만 좋아지면 통계와 추론 모드 차이를 먼저 조사한다.
- 손실만 줄고 구분력이 개선되지 않으면 손실 구성·특징/잡음 비율·출력 방향 등 학습 조건을 검토한다.
- 500회로 분리가 안 되더라도 모델 자체가 영원히 학습할 수 없다는 결론은 아니다.

개발 128장·보정 169장의 기존 결과 파일은 원본 모델 검증에만 사용한다.
해당 이미지나 불량 시험 이미지·마스크를 이번 학습에 열지 않으며 경고 기준도 다시 계산하지 않는다.

## Windows 실행과 복구

다른 GPU 작업을 정상 종료한 뒤 실행한다. 기본 원본 압축 파일은 `Downloads\extracted.zip`이다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed. Stop and send the error.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_learnability.ps1'
```

결과는 `artifacts\analyses\mpi-supersimplenet-learnability-v1`에 별도로 저장한다.
각 기록 시점에 모델·최적화기·진단 배열·진행 기록을 원자적으로 저장하고 해시로 검증한다.
최종 저장 모델을 다시 불러와 점수와 지도의 최대 차이 0.0001 이하 및 모든 모델 지문의 일치를 확인한다.

정상적인 Ctrl+C 중단은 같은 명령으로 마지막 완료 체크포인트부터 이어간다. 아직 저장하지 못한
작업은 재실행되며 시도 횟수·시간은 누적한다. 총 시도 업데이트 650회를 넘기지 않는다.
강제 종료로 종료 기록이 없거나 자원·데이터 오류가 나면 자동 재시도를 막는다. 파일을 지우지 말고
오류를 전달한다. GPU/RAM 부족 시 타일 수·잡음·학습량을 몰래 줄이지 않는다.

완료 후 `artifacts\handoff\mpi-supersimplenet-learnability-v1.zip`을 전달한다.
ZIP에는 수치·지도 배열·학습 기록·체크섬만 포함하며 원본 이미지·특징 텐서·모델 가중치는 포함하지 않는다.
Mac의 CPU 모의 테스트는 기록·재개·검증 로직을 확인할 뿐 실제 GPU 학습 성공을 보증하지 않는다.
