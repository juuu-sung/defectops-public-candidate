# MPI PatchCore 동일20타일 전체지도 비교

이 문서는 중단된 v1의 이력이다. 수치 진단을 검토한 뒤 [지도 정밀도 검증과 전체 후보 비교 v2](mpi-patchcore-full-map-comparison-v2.md)로 진행한다. 아래 v1 명령을 다시 실행하지 않는다.

## 이번에 확인할 것

이전 진단은 고정53위치의 거리를 비교했다. 정상0706의 한 위치는 크게 개선됐지만 다른 위치가 최고점이 될 수 있다. 이번에는 **같은20타일의 모든 특징 위치를 비교해 영역 전체의 높은 점수와 실제 결함 반응이 어떻게 변하는지** 확인한다. 새 모델 학습이나 운영 채택 작업이 아니다.

정상14장의 기존 점수 결정 타일과 불량0024의 정답이 있는6타일을 그대로 사용한다. 결과를 보고 사례를 빼거나 늘리지 않는다. 전체 비교 후0706·0335·0024를 포함한20타일 모두 보고한다. GT는 위치 진단에만 사용한다.

## 고정 조건

| 항목 | 내용 |
| --- | --- |
| 질의 | 20타일 × 64×64위치 = 81,920개, 768차원 원특징 |
| 기준 A | 현재 대표 기준표78,643개 |
| 기준 B | 학습256사진의 보관후보3,145,728개 전부 |
| 후보의 범위 | 기존 stride2 캐시 전체. 원래 학습64×64의 모든 위치를 복구하는 것이 아님 |
| 거리 | 양쪽 같은 float64 유클리드 거리, 설치된 Anomalib euclidean_dist 재사용 |
| 분할 조회 | 질의512개 × 후보4,096개씩, 전체 학습사진256개 순회 |
| 지도 | 거리64×64 → 설치된 기존 anomaly_map_generator → 256×256, 기존 보간·평활화 유지 |
| 영역 점수 | 큰 지도값656개 평균. 256×256의 상위 약1% |
| 위치 지표 | GT 평균·최대, 배경 평균, 타일 내 AUROC, 상위656/GT 교집합·포함률과 동점 범위 |
| 추가 지표 | 최대위치 이동, 기존 최대위치의 새 값, 영역 점수 감소율 |
| 표시 | 20타일의 대표 지도 최대값을 공통 색 범위로 사용. 녹색은 GT 윤곽 |

공식 weighted image score와 지도 top1% 점수는 다르다. 이번 전체후보 비교에서 weighted image score를 새로 만들지 않는다. 영역별 정상 중심·폭·사진 경고선을 재산출하지 않고, 바뀐 지도에 기존 경고선을 적용하지도 않는다. **사진의 경고 해제·검출 유지 여부는 이번 산출물이 아니다.**

## 실행 순서와 검증

1. 원본·기존 학습/개발/중첩/압축진단 ZIP, 모델, 실행 소스와 환경을 검증한다. 기존 정상8사진의 저장 지도·점수 차이는1e-4 이내, 판정 변경은0이어야 한다.
2. 작은 고정 난수 질의517개·후보4,103개에서 실제 GPU 분할 거리와 CPU 직접 차이의 norm을 비교한다. 양쪽 분할 경계·동점·동일 특징을 포함한다. 거리 atol1e-4/rtol1e-8 및 근접 인덱스 일치를 요구한다.
3. 공식 추론에서20타일의 특징과 patch 거리를 관찰한다. 저장 지도·점수와 지도 재생성 차이는1e-4 이내여야 한다. float64 대표 지도 대 기존float32 지도는 별도 atol0.001/rtol0.0001 계약으로 점검한다. 이는 공식 출력 재현 허용오차를 늘리는 것이 아니다.
4. 두 기준표로 전체 위치를 조회한다. 대표78,643개 전부가 원후보의 기록된 위치와 바이트 단위로 같은지 확인한다. 각 질의 최종 근접 벡터와의 거리를 CPU float64 직접 norm으로 재검산한다. 전체후보 거리가 대표보다 커지면 중단한다.
5. 이전53질의의 특징은 정확히 같아야 하고 양쪽 거리는1e-4/1e-8 이내여야 한다. GPU 계산 변경 자체가 결과를 바꾸는지 별도로 확인한다.
6. 두 지도·점수·위치 통계·비공개 카드를 내보낸다. 모델·대표 bank·주 경고선·서비스는 변경하지 않는다.

분할 행렬곱은 더 빠른 조회를 위한 구현이며 근사 최근접 탐색·특징 정규화·저차원 투영을 사용하지 않는다. 부동소수점 동점은 계산된 거리와 원후보 첫 인덱스로 결정한다. 매우 가까운 비동점의 출처까지 수학적 유일성을 주장하지 않는다. 설치된 공식 코드의 거리·지도 함수가 기준이다:

- [Anomalib2.2.0 PatchCore 거리와 forward](https://github.com/open-edge-platform/anomalib/blob/v2.2.0/src/anomalib/models/image/patchcore/torch_model.py)
- [Anomalib2.2.0 지도 생성](https://github.com/open-edge-platform/anomalib/blob/v2.2.0/src/anomalib/models/image/patchcore/anomaly_map.py)

## 시간·메모리·재개

총 비교는 약2,577억 쌍의768차원 거리다. 이전53위치보다 질의 수가 약1,546배 많으나 계산 구현도 바뀌므로 단순 시간 배율로 예측하지 않는다. 실제 RTX5060 실행시간은 미측정이다. 첫 학습사진 블록의 계산시간과256블록 선형 추정치를 표시한다. 이것은 파일검증·대표 조회·카드·내보내기·중단 재계산 시간을 제외한 참고값이지 완료 시각 보장이 아니다.

시간 상한은 없다. RAM20GiB·PyTorch GPU reserved6GiB 및 기존 환경/무결성 제한을 유지한다. 전체후보 약9GiB를 GPU에 한꺼번에 올리지 않는다. 완료 블록 거리·인덱스 저장은 약320MiB, 질의 특징은 약240MiB이며 추가 여유 공간이 필요하다. 중단된 임시 파일도 보존한다.

Ctrl+C가 정상적으로 전달되면 완료된 학습사진 블록부터 재개한다. 진행 중인 블록만 다시 계산하며, 재개 시 기존 정상 재현과 대표 조회는 다시 수행한다. 강제 종료·실패한 시도·환경 변화는 자동 우회하지 않는다. 오류시 전체 메시지를 전달하고 출력 삭제·새 폴더 우회·재학습을 하지 않는다. 기존 모델·특징 캐시·결과ZIP을 보존한다.

## 연구실 실행

로컬 검증: 전체1,148개·하위검사52개 통과,8개 건너뜀. 신규10개 검사는 거리·지도 집계·최대위치 이동·고정질의 재현·분할/동점·중단재개·출력 재사용·변조 거부를 다룬다. 명령 진입점과 실제 수령ZIP의20타일/256특징파일/동결 소스 연결도 확인했다. Mac의 가짜 runtime 검사와 실제 CUDA 수치 검증은 다르며, CUDA 비교는 연구실 첫 단계에서 수행한다. 아직 전체조회 시간이나 성능 개선은 확인하지 않았다.

다른 GPU 작업을 정상 종료하고 다음을 실행한다. 기본 원본은 Downloads의 extracted.zip이다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_patchcore_full_maps.ps1'
```

완료 후 다음 파일을 전달한다:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-patchcore-full-map-comparison-v1.zip
```

ZIP에는20개 카드·원본20개·GT6개, 공식/일치정밀도 대표/전체후보 지도, 두 거리/근접 인덱스, 통계·무결성 영수증·자원 기록이 들어간다. 전체 원후보·가중치는 포함하지 않는다. 이미지·mask는 비공개 검토용이고 노션이나 공개 저장소에 올리지 않는다. 완료 블록 계산 합계는 중단된 블록·검증·내보내기를 포함한 전체 벽시계 시간과 다르다.

## 결과에 따른 다음 결정

- 정상의 상위656 점수가 줄고 결함 위치 반응은 상대적으로 유지된다면, 대표 압축 개선 후보를 설계할 근거다. 전체후보의 자동 서비스 적용은 아니다.
- 정상과 결함 점수 모두 크게 줄면 구분력이 개선됐는지 확정할 수 없다. 거리 감소 자체를 성공으로 보고하지 않는다.
- 0335 등 정상 고점수가 그대로면 해당 사례는 대표 압축만으로 설명하기 어렵다.
- 유망하더라도 실제 판정 개선 주장은 정상 개발·보정과 고정 전체평가를 별도 설계한 뒤 확인한다.

현재 검출55/55·정상오경보1/54와15/256은 기존 대표 모델의 결과로 유지한다. 이번은 관찰한 사례의 제한 원인 진단이며 독립 성능평가가 아니다.
