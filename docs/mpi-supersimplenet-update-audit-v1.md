# SuperSimpleNet 첫 업데이트 차이 점검

이 검사는 같은 답을 낸 두 구현이 왜 첫 학습에서 다른 가중치 변화를 만드는지 확인한다.
기존 모델을 더 학습하거나 불량 성적을 측정하는 단계가 아니다. 저장된 정식 학습 시작 전
모델의 복사본만 사용하며 결과를 검토하기 전 다음 학습은 시작하지 않는다.

## 앞선 검사 결과

구현 대조 v1은 네 조합을 완료했다. 지도·사진 점수는 정확히 일치했고 손실은 허용 오차 내였다.
학습 완료 모델은 두 난수 모두 통과했지만 시작 전 모델은 기울기와 가중치 변화가 일부 달랐다.
난수42/900001의 기울기 초과는23/3개, 가중치 변화 초과는1493/1310개였다.
작은 기울기 차이가 AdamW 첫 업데이트에서 확대되는지는 아직 가설이다.
앞선 ZIP의 SHA256은 `c9f344f58def1df7eaaefecda93b1aa8b36fd6bf443a788fb89a08f2b9fd2518`이다.

## 같은 조건에서 네 경로 비교

입력은 앞선 검사와 같은 정상 사진1073의 첫8영역이며 난수42와900001을 사용한다.
같은 시작 전 가중치·BatchNorm 통계·학습률·빈 AdamW 상태에서 각 경로를 따로 시작한다.
합성 잡음과 마스크는 한 번 생성해 공유하고 앞선 ZIP의 잡음·마스크·업데이트 전 출력과 재현을 확인한다.

| 경로 | 검출부 | 손실 | 확인 목적 |
| --- | --- | --- | --- |
| official_a | Anomalib | Anomalib logits BCE focal | 기준 |
| official_b | Anomalib | 같은 손실 | 동일 구현의 반복 계산 차이 |
| reference_logits | 독립 대조 구현 | 같은 Anomalib 손실 | 손실 표현을 고정한 계산 경로 비교 |
| reference_author | 독립 대조 구현 | 저자의 sigmoid 후 BCE focal | 손실 표현 차이의 영향 |

독립 구현의 두 경로도 직접 비교해 같은 계산 경로에서 손실만 달라질 때의 영향을 따로 기록한다.

각 경로는 AdamW를 딱 한 번 적용한다. 두 난수×네 경로의 총8회이며 업데이트 모델은 저장하지 않는다.
기울기·실제 가중치 변화·BatchNorm 통계를 비교하고, 차이가 있는 파라미터에서 큰 기울기 오차32개와
큰 업데이트 오차32개의 합집합을 선택해 인덱스와 양쪽 원시 값을 남긴다. 전체 기울기 벡터는 ZIP에 넣지 않는다.

업데이트 전후에 같은 정상 입력과 합성 입력의 원시 지도·사진 점수를 평가 모드로 기록한다.
업데이트 후 학습 모드 출력도 기록하며 정상/합성 간에는 BatchNorm 버퍼를 복원한다.
출력 점검 자체는 가중치를 바꾸지 않는다. 이는 공유 특징에서 계산한 검출부 원시 출력이며
서비스의 확대·평활화된 지도나 사진 단위 경고 판정과는 구분한다.

## 시간 제한과 보존 조건

사용자 요청에 따라 이 검사에는 경과 시간 상한을 두지 않는다. 실제 시간은 계속 기록한다.
기존 실행의 고정 계획은 수정하지 않는다. 이번 조건도 결과를 보고 반복 횟수를 늘리지 않는다.

- 메모리 상한은 RAM20GiB, PyTorch reserved6GiB다. 시작 시 GPU 여유6GiB가 필요하다.
- 정상 완료한 난수 조합은 검증 후 재사용한다. 사용자 중단 후 재개는 최대3개 조합 시도까지다.
  중간 경로만 끝난 조합은 처음부터 재현하므로 시간·시도 기록을 보존한다.
- 오류·메모리 제한 실패·종료 기록이 없는 강제 종료는 자동 재시도하지 않는다.
- 원본 체크포인트·보정 기준·이전 ZIP은 수정하지 않는다. 새 시험 이미지와 마스크도 열지 않는다.
- 비교 결과가 다르더라도 완료된 진단 ZIP을 내보낸다. 허용 오차는 앞선 검사와 같고 자동 완화하지 않는다.

## 연구실 실행

다른 GPU 작업을 정상 종료하고 기존 정식 학습 폴더 및 구현 대조 ZIP을 그대로 둔다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'git pull failed; stop here' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_update_audit.ps1'
```

원본 기본 위치는 사용자 Downloads의 `extracted.zip`이다. 다른 경로면 실행 명령 뒤에
`-Archive 'D:\데이터\extracted.zip'`을 추가한다.
완료 후 `C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-update-audit-v1.zip`을 전달한다.
`update_audit_completed_requires_interpretation`은 실행 실패가 아니라 결과 해석 대기 상태다.
오류가 발생하면 파일을 삭제하거나 학습을 다시 하지 말고 전체 오류를 전달한다.
