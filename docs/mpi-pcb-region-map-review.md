# MPI-PCB 두 검색 방식의 저장 지도 비교

기준일: 2026-09-28. **실행기 준비 단계. 실제 연구실 지도 비교 결과는 아직 없다.**

## 왜 이 단계를 하나요?

[동일 영역 검색 결과](../reports/mpi-pcb-region-search-v1.md)에서 후보는 빨랐지만
미탐이 22→33장, 정상 오경보가 3→7장으로 늘었다. 이 결과만으로 원인을 하나로
확정할 수 없다. 기존 A를 유지하고, 이미 저장된 지도로 다음을 구분한다.

1. 실제 결함 위치 자체에 반응이 약한가?
2. 결함에도 반응하지만 정상 부분의 반응이 강해 이미지 점수를 주도하는가?
3. 원점수는 올랐지만 정상 보정의 경고 경계가 더 올라 경고가 사라졌는가?

세 번째는 두 방식의 **각 영역 원점수와 원점수 환산 경계**를 함께 본다.
환산 경계 = 정상 중앙값 + 정상 MAD × 사진 경고 기준이다. 이미지 경고를 설명하는
경계이지 픽셀 불량 임곗값이 아니다. 최종 사진 점수는 12개 영역 정상화 점수의 최대다.

## 무엇을 만들어요?

| 대상 | 수 | 역할 |
| --- | ---: | --- |
| 새로 놓친 불량 | 15 | 기존 A 경고 → 후보 기준 미만 |
| 새 정상 오경보 | 4 | 기존 A 기준 미만 → 후보 경고 |
| 새로 잡은 불량 | 4 | 기존 A 기준 미만 → 후보 경고 |
| 계속 미탐인 대조 | 4 | defect/0024, 0041, 0020, 0034 |
| 나머지 대조 | 3 | 검출 defect/0010, 오경보 good/0012, 정상 good/0020 |

총 **30개 원본 × 12개 영역**을 두 방식으로 비교한다. 각 원본은 6개 영역씩
두 장의 검토 그림으로 만든다. 판정 변화 23장은 모두 포함하며 보기 좋은 일부만 고르지 않는다.
대조는 과거 진단의 고정 사례다. 이 사후 선택 사례의 통계를 전체 성능처럼 해석하지 않는다.

그림의 5열은 **원본+정답 / 기존 지도 / 후보 지도 / 기존 상위 1% / 후보 상위 1%**다.
초록 선은 공식 결함 정답이다. 두 지도는 같은 고정 원점수 색상 범위
`1.5 × 46.839376955497556`을 쓴다. 각 그림을 최대값에 맞춰 진하게 만드는 작업은 하지 않는다.
상한을 넘으면 색이 포화될 수 있으며 포화 비율도 기록한다.
빨간 반응은 65,536픽셀 중 상위 656픽셀의 평균 점수에 기여한 위치다.
경계 동점은 그림에 모두 표시하므로 빨간 영역이 656픽셀보다 클 수 있다.
실제 기여 수치에는 동점의 최소·최대 겹침과 점수 기여 범위를 제공한다.

JSON에는 결함 위치 평균·최대, 결함 아닌 부분 평균, 영역 안의 결함/배경 순위 AUC,
상위 1%와 정답 겹침 범위, 정상화 점수·경계·변화량을 보관한다.
**영역 안 순위 AUC는 전체 Pixel AUROC가 아니다.** 모델 반응과 공정 원인도 구분한다.
`defect/0006`은 정답 손상으로 전체 사진을 위치 통계에서 제외한다. 정답을 추정·복구하지 않는다.
선정된 `defect/0054`는 이전에 검증한 복구 이미지 한 개를 그대로 사용하고 명시한다.

### 정상 0411은 별도 참고입니다

두 방식 모두 정상 보정 0411/grid2-3이 95% higher 경고 기준을 결정했다.
그러나 **후보의 정상 개발·보정 지도는 저장되지 않았다.** 새 추론을 하지 않으므로
0411은 두 방식의 숫자·최대 영역·순위와 과거 공유 방식 참고 그림만 제공한다.
후보 정상 지도를 새로 만든 것처럼 표시하지 않는다. 고득점만으로 정상 사진을 제외하거나
라벨을 바꾸지 않는다. 그림과 숫자는 정상 정의·외관 변화 검토의 참고이며 자동 원인 판정이 아니다.

## 바뀌지 않는 것과 무결성

- CPU로 ZIP 해시·원본·공식 마스크·기존 NPZ·사진별 완결 기록을 확인한다. 모델 파일도 필요 없다.
- 기존 A와 후보의 저장 점수·정상 보정 계약·판정·기여한 정상 gate를 검증한다.
- 전수 109장 성적은 앞서 고정된 값 그대로 제시하며 다시 선택하거나 임곗값을 조정하지 않는다.
- 새 모델 호출, 특징 추출, 재학습, coreset 선정, 기준 변경, 서비스 교체, 자동 PASS, 티켓 발행은 없다.
- 원본과 이전 결과는 읽기만 한다. 새 결과는 별도 폴더에서 사진별로 완결하고 중단 후 재사용한다.
- 자료·완결 기록이 없거나 달라졌으면 멈춘다. 자동 재추론·재다운로드·삭제·복구는 하지 않는다.
- 기존 실행의 코드 해시를 유지하도록 동결된 Python 파일을 수정하지 않고 별도 실행기를 추가했다.
- 기존 A 지도는 전용 모델 평가 캐시, 후보 지도는 동일 영역 실험 캐시에서 읽는다.
  `photo-NNN`은 고정 109장 명단의 **순번**이지 파일의 사진 ID가 아니다.

## 연구실 Windows에서 하실 일

기존 가상환경·원본 ZIP·결과·로컬 저장 맵을 그대로 둔다. GPU 작업을 종료할 필요는 없고
새 데이터 다운로드나 설치도 필요 없다. `git pull`이 실패하면 다음 실행을 하지 않는다.

```powershell
Set-Location "C:\개인 프로젝트\defectops"
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw "git pull failed. Stop and share the error." }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_mpi_region_map_review.ps1"
```

완료하면 다음 파일을 첨부한다.

`C:\개인 프로젝트\defectops\artifacts\handoff\mpi-pcb-region-map-review-v1.zip`

이 ZIP에는 JSON·HTML·검토 JPG만 넣는다. 모델·원본 이미지·NPZ 전체는 보내지 않는다.
MPI-PCB v1.0의 출처(Oliveira, Nassu, Wehrmeister), DOI `10.5281/zenodo.8213098`,
CC BY 4.0 및 파생 검토 그림임을 표시한다.

직접 결과를 보려면 완료 후 아래 명령을 실행한다.

```powershell
Start-Process ".\artifacts\analyses\mpi-pcb-region-map-review-v1\result\index.html"
```
