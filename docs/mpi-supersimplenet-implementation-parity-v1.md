# SuperSimpleNet 구현 대조 실행 안내

장시간 재학습 전에 현재 실행기의 계산이 독립 대조 구현과 일치하는지 확인한다.
저장된 정식 학습 시작 전 모델과 300 epoch 완료 모델을 각각 복사하여 검사한다.
이 검사는 불량 검출 성적이나 원 논문 전체 재현이 아니다. 기존 모델과 경고 기준은 유지한다.

## 이번 검사에서 하는 일

정식 학습 명단의 첫 정상 사진에서 8개 영역을 사용한다. 시작 전·완료 모델에 각각
고정 난수 42와 900001을 적용하여 총 4개 조합을 비교한다. 새 사진 일반화 검사가 아니다.
두 경로는 실제 가중치, BatchNorm 통계, AdamW의 저장된 상태, 입력, 합성 마스크와 잡음을 공유한다.

1. RGB 전처리와 현재 특징 보간 경로를 대조한다.
2. Anomalib 공식 전체 학습 forward와 독립적으로 작성한 특징 변환부·검출부를 비교한다.
3. 위치·분류 출력, 손실 성분, 각 파라미터의 기울기를 비교한다.
4. 양쪽에서 복사본에 AdamW 업데이트를 한 번 적용하고 실제 가중치 변화량·BatchNorm 버퍼를 비교한다.
5. 메모리의 모델 상태를 복원하고 원본 체크포인트·경고 기준 파일이 바뀌지 않았는지 확인한다.

업데이트는 계산 대조용이다. 총 4조합×2경로의 완료 업데이트만 수행하며 새 모델을 저장하지 않는다.
학습·시험 자료 추가, 시험 이미지·마스크 열람, 임곗값 수정, 자동 서비스 전환은 없다.
실패 없이 완료된 조합은 검증 후 재사용한다. 사용자 중단은 누적 시간·시도 수를 포함하여 재개할 수 있다.
오류나 자원 제한 실패 후에는 자동 재시도를 막으므로 결과를 삭제하지 말고 전체 오류를 전달한다.

## 대조 범위와 알려진 차이

독립 검출부·손실은 [저자 ICPR 코드](https://github.com/blaz-r/SuperSimpleNet/tree/9c6867c3e1ef36d9e9fa7722a7dfdc8f9e41e301)를
현재 파라미터 이름으로 옮긴 것이다. 저자의 MIT 고지를 소스에 포함한다.
독립 경로에서 Anomalib 검출부·SSNLoss를 다시 호출하지 않는다.
단, 고정 backbone은 공유하므로 torchvision과 timm의 backbone 수치 동등성까지 입증하지 않는다.

- 특징 확대는 Anomalib의 `align_corners=False`를 주 비교에 사용한다.
  원 논문의 `True` 결과와의 차이는 별도로 측정하며 의도된 차이를 자동 실패로 취급하지 않는다.
- 합성 생성기는 Anomalib 2.2.0을 한 번 호출하고 결과 잡음과 마스크를 양쪽에 주입한다.
  원 저자와 Anomalib의 Perlin 분포가 같다는 검사는 아니다.
- 손실의 독립 구현은 저자의 sigmoid 후 BCE를 유지한다. Anomalib는 logits BCE를 쓴다.
  포화 구간 등에서 수치 차이가 발생하면 기록하고 검토하며 임의로 공식을 바꾸지 않는다.
- 입력8개·실효16개 조건을 고정한다. 원 논문의 입력32개 조건을 재현한다고 주장하지 않는다.

허용 오차는 배열의 모든 원소에 `abs(a-b) <= atol + rtol*abs(b)`로 적용한다.

| 항목 | 절대 오차 | 상대 오차 |
| --- | ---: | ---: |
| 출력·전처리·특징 | 0.0001 | 0.0001 |
| 손실 | 0.00001 | 0.0001 |
| 기울기 | 0.00001 | 0.001 |
| 실제 가중치 변화량 | 0.000001 | 0.001 |
| BatchNorm 버퍼 | 0.00001 | 0.0001 |

이 기준은 계산 대조용 사전 기준이며 불량 검출 합격 기준이 아니다. 차이가 나도 자동 완화하지 않는다.
기울기·변화량은 파라미터별 오차 통계를 기록한다. ZIP에는 원시 출력 배열을 포함하지만
전체 기울기 벡터나 모델은 포함하지 않으므로 수령 측에서 모든 GPU 연산을 독립 재실행할 수는 없다.

## 연구실 Windows 실행

다른 GPU 작업을 정상 종료한 뒤 프로젝트 폴더에서 실행한다. 기존 정식 학습 폴더의
`step-000000`과 `step-028800`, 정식 학습 ZIP, 정상 예측 기록을 그대로 보존해야 한다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'git pull failed; stop here' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_parity.ps1'
```

기본 원본은 `C:\Users\user\Downloads\extracted.zip`이며 실제 사용자 프로필 경로를 자동 사용한다.
다른 위치라면 `-Archive 'D:\데이터\extracted.zip'`을 뒤에 붙인다.
GPU 검사 시간 상한은 누적15분, RAM20GiB, PyTorch reserved6GiB다.
준비 단계의 파일 무결성 검사 시간은 별도이며 실제 소요시간은 아직 측정하지 않았다.

전달 파일은 `C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-implementation-parity-v1.zip`이다.
`implementation_parity_needs_review`도 유효한 진단 결과이므로 그대로 전달한다.
통과하더라도 다음 실험은 자동으로 시작하지 않는다.
