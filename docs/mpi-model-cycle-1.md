# MPI 모델 개발 사이클 1 — 기준선 원장과 Phase2 진단 카드

작성일: 2026-09-30. 상위 계획: [모델 개발 통합 계획](model-development-plan-v1.md).
상태: **연구 방향 진행 동의 수령 / 기준선 기록 검증 완료 / Phase2 제한 진단 수령 검산 완료**.
결과: [미탐6장 진단 보고서](../reports/mpi-spatial-miss-review-v1-received-review.md).
26×26 후보는 비채택 유지. 2026-10-01 [MPI-C1-01 정상 변동 폭 부분 공유 카드](mpi-scale-shrinkage-v1.md)를
작성한 뒤 사용자 실행 동의로 CPU 비교를 완료했다. 후보1/2는 검출53→42장 및 안정성 실패로
**비채택**이다. [결과 보고서](../reports/mpi-scale-shrinkage-v1-review.md)를 참고한다.
Phase3 통과나 사용 승인은 아니며 남은 후보1개는 자동 실행하지 않는다.

후속 [정상 표본 영향 분석](../reports/mpi-normal-influence-v1-review.md)은3,000회 저장 반복을
검증·추적한 진단이다. grid3-2 폭 추정과 다른 영역의 정상 반응이 사진 기준을 결정하는 두 경로를
확인했다. 정상10장 원본 검토 후에도 외관 차이와 모델 반응의 직접 연결은 미확정이다.
추가 후보로 세지 않으며 사진은 제거하지 않는다.
사용자 진행 동의에 따라 [정상 원본 검토 실행기](mpi-normal-visual-review-v1.md)를 준비했다.
연구실에서 추출한 [정상120타일 수령 검토](../reports/mpi-normal-visual-review-v1-received-review.md)를 완료했다.
원본 외관 차이와 저장 점수를 대조했지만 직접 반응 위치·인과관계는 미확정이다.
보정 정상5장의 지도 대조를 다음 제한 진단으로 제안하며 새 학습·사진 제외는 하지 않는다.

## 1. 결정과 승인 범위

사용자는 통합 계획 설명 뒤 “응 진행해보자”라고 답했다. 이를 MPI-PCB 미탐 개선을 우선해
기존 자료를 정리하고 준비된 진단을 진행하는 동의로 기록한다. 새 모델 학습·독립 final 개봉·
서비스 모델 교체·자동 합격까지 승인된 것으로 확대하지 않는다.

- 연구의 작업 목표: 원본사진 단위 검출률95% 이상, 정상 오경보5% 이하, warm p95 2초 이내.
  이는 앞서 제시한 초기 연구 목표이며 현장 품질 보증이나 생산 SLA가 아니다.
- 한 사이클 새 후보 최대2개를 계획 상한으로 둔다. 이번 읽기 전용 진단은 새 후보가 아니다.
- 세부 메모리/학습 시간 예산, 결함군별 조건, 최소 표본, 보정 민감도 허용 폭은
  새 후보 실행 전 확인한다. Phase0 전체 완료나 Phase3 실행 승인으로 표시하지 않는다.
- 서비스의 transistor 모델은 별도 트랙으로 보존한다.

## 2. Phase1 데이터 원장

기존 준비·학습·점수 검증·공간 비교 전달물의 해시와 내부 계약을 현재 코드로 재검산했다.
아래 명단은 기존 전달물의 명단을 유지한다. 이번에 새로 표본을 뽑거나 분할을 바꾸지 않았다.

| 집합 | 원본사진 수 | 역할 | 앞으로의 해석 |
| --- | ---: | --- | --- |
| 정상 fit | 64 | 공용 정상 bank 구축 | 정상 학습 자료 |
| 정상 development | 128 | 영역별 median/Q90 척도 계산 | 이미 사용한 정상 개발 자료 |
| 정상 calibration | 169 | 사진 경고 임곗값 계산 | 이미 사용한 정상 보정 자료 |
| 기존 test | 109 = 불량55 + 정상54 | 후보 비교·오류 분석 | 이미 관찰된 탐색/회귀 자료 |
| 후속 정상 validation | 256 | 최초 미사용 정상 고정 검증 완료 | 현재는 관찰된 회귀 자료 |

정상 네 집합의 사진ID 교집합은 모든 조합에서0이다. test의 good/defect 번호는 별도 이름공간이므로
번호만으로 정상 풀과 중복 여부를 판단하지 않는다. 기존 픽셀 중복 감사와 손상·복구 예외를 유지한다.
같은 데이터셋의 ID/RGB 비중복이 서로 다른 실물·세션의 독립성을 증명하지는 않는다.
새 독립 불량 자료는 미확보다. Phase2 진단은 가능하지만 Phase5 독립 평가는 아직 불가하다.

## 3. 고정 비교 기준선

- Wide ResNet-50-2, layer1+layer2, 입력256, 학습 패치 stride2, seed42.
- 정상64장 × 12영역, 공용 bank78,643×768. 학습/입력 설정은
  [기존 config](../configs/mpi-pcb-normal-bank-pilot-v1.toml)를 그대로 사용한다.
- 현재 연구 기준선: top1% 지도 평균 → 영역별 median/Q90 척도 보정 → 12영역 최댓값.
- Q90 경고 기준: `2.3169610768645974`, 비교 연산 `>=`.
- 공간26×26 비교 대상: 기준 `2.123865555187808`, 비채택 상태 유지.
- Q90: TP53/FN2/FP3/TN51, 후속 정상 오경보14/256.
- 공간 후보: TP49/FN6/FP5/TN49, 후속 정상 오경보15/256.
- 모델 파일만 아니라 전처리·bank·점수·영역 보정·사진 집계·임곗값까지 비교 단위다.

| 증거 | SHA256 |
| --- | --- |
| 원본 ZIP 기록 | `0fa9b20fae64142a418487a1d898ee2ee824eee0bd564896a245f4d991112607` |
| checkpoint 기록 | `3d1635bdeefe89d9f8a677aa1c7fcf4966d085c4b1de9ca6d4f4382455d56a73` |
| 수령 공간 비교 ZIP | `8429a970864c1116d5f52b786057fc84c3e48f465b5c502715ab7f61d35e13dc` |
| 수령 점수 검증 ZIP | `4f995562c08b3c768ff591025a5f22db01daad5d52020b2d296912f4814bd73a` |

Mac에서는 전달물과 기록을 검증했다. Windows 원본 ZIP·checkpoint 실물 검증은 실행기가
연구실에서 다시 수행한다. 이번 문서 검산으로 GPU 추론을 재현했다고 하지 않는다.

## 4. Phase2 실행 카드: MPI-DIAG-001

### 질문과 범위

공간 평균이 기존 Q90에서 잡던 불량4장을 놓친 이유는 결함 반응의 희석인가, 결함보다 강한
배경 반응인가, 혹은 복합/다른 양상인가? 기존부터 놓친2장과 함께 제한적으로 확인한다.

| 구분 | 고정 사례 |
| --- | --- |
| 기존 미탐 | defect/0019, defect/0024 |
| 공간 평균의 추가 미탐 | defect/0021, defect/0027, defect/0028, defect/0047 |

- 6장 × 12영역 =72타일. 실행 점검은 기존 정상8장으로 수행한다.
- 모델·bank·입력·정규화·두 임곗값·선정 명단을 변경하지 않는다.
- 추가하는 것은 지도/정답 중첩 설명 자료뿐이다. 정상128/169장을 재학습·재보정하지 않는다.
- 정답 mask는 점수·최고 창 재현 검증 뒤에만 읽는다. 점수나 위치 선택에 사용하지 않는다.
- 원점수 재현 차이1e-4 초과, 고정 판정 변화, 최고 창 좌표 변화, 입력/환경 불일치면 중단한다.
- 정상 실행 점검의 기존 타일 시간 상한은 심각한 실행 회귀를 막는 용도다.
  새 연구 목표인 사진 p95 2초의 통과 검사와 혼동하지 않는다.

### 산출물·재개

사진별 12영역 지도와 mask, 18개 카드, 전체 통계 JSON, 읽기 전용 HTML, handoff ZIP을 만든다.
완료 사례는 입력·출력·실행 점검 기록을 검증해 재사용한다. 전체 완료 후 재실행은 GPU 없이
결과를 검증·재전달한다. 오류 시 기존 출력은 삭제하지 않는다. 새 후보 채택·모델 변경은 하지 않는다.

실행 명령·필수 입력·결과 경로는 [기존 진단 안내](mpi-spatial-miss-review-v1.md#연구실-실행)를 따른다.
기존에 완료했다면 재실행보다 해당 ZIP을 먼저 전달한다. 코드 변경은 없이 동일 실행기를 사용한다.

### 수령 후 판단 규칙

1. 해시·점수·판정·72영역 중첩 통계를 검산한다.
2. 6장 각각을 관찰된 사실 / 가능한 설명 / 반대 근거 / 미확정으로 정리한다.
3. 기존 정상 오경보0970·0998·1415 및 정상 보정 재표집 결과와 함께 해석한다.
4. 집계 손실·약한 특징 반응·정상 보정 불안정을 구분하되 최근접 패치 오매칭은 이 자료만으로 단정하지 않는다.
5. 변경이 필요한 근거가 있으면 우선 후보1개와 실험 카드를 제안한다.
   근거가 부족하면 진단 한계로 종결하고 새 후보를 자동 생성하지 않는다.

6개 선택 사례에 대한 진단이므로 전체 검출률·독립 성능·생산 승인 근거가 아니다.
성능 개선이 발생해야 성공하는 실행도 아니다. 제대로 된 원인 근거를 얻거나 미확정을 남기는 것이 목적이다.

## 5. 이번 Mac 확인과 다음 단계

- `review_mpi_spatial_misses.prepare`로 실제 수령 전달물 계약 검산 통과.
- 고정6개 사례·각12영역·두 임곗값·정상 명단 비중복 재확인.
- 관련 합성/회귀 테스트15개 통과. 이번 변경은 문서뿐이며 전체 테스트 재실행은 하지 않았다.
- 실제 Windows/CUDA·원본/모델 파일 검증은 연구실 실행에서 확인한다.
- 이후 수령 확인: **Phase2 진단 검산 완료**. Phase3 신규 개선 실행과 Phase5 final 개봉은 승인하지 않는다.
