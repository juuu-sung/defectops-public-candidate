# MPI 영역별 경고 기준의 가능성 점검

2026-10-03. 사용자는 구조 변경 검토 진행과 작업 속도 개선을 요청했다. 반복 사진 진단이나
정상 폭 공식 추가에 앞서, 기존 원점수를 사용하는 영역별 경고 기준 구조의 가능성을 한 번에 점검한다.
설계·구현·합성 검증·실행·결론을 한 작업으로 묶는다. 새 학습·데이터·서비스 변경은 포함하지 않는다.

## 질문과 범위

관찰한 원점수에서 영역마다 임의의 경계를 허용해도 기존 검출53장을 모두 보존하면서
정상54장 오경보≤2, 정상256장 오경보≤12를 동시에 달성할 수 있는가?

판정은 `어느 영역이라도 raw_top1 >= 그 영역 경계`다. 정상 폭과 사진 공통 임곗값을 결합한
기존 Q90·Qn도 양의 분모이므로 이 구조의 특수한 경우다. 영역별 임의 경계를 허용한 구조는
그 두 방법보다 자유도가 높다. 그러나 여러 영역의 결합 특징·비단조 규칙·위치 지도 정보·다른 bank는 포함하지 않는다.

**정답을 보고 가능한 경계를 찾는 낙관적 적합 가능성 진단이지 모델 후보 평가가 아니다.**
독립 성능·정상만 학습한 방법의 성적·최대 달성 검출률로 발표하지 않는다. 필요한53장 보존의
존재 여부만 묻고 최적 성능은 탐색하지 않는다. 해가 있으면 가능성만 확인한 것이며 정상만으로
그 경계를 추정하는 방법과 독립 검증은 별도다. 해가 없으면 현재 점수/구조/자료/예산에 한정한 불가능이다.

## 입력과 정한 계산

- `mpi-score-validation-v1.zip`과 고정 Q90 원점수·계약, 동일662장. 입력 해시는 Qn 고정 설정을 재사용한다.
- 기존 점수·판정 재현 후, 관찰 불량55장 중 기존 검출53장만 보존 대상이다. 기존 미탐2장을 결과 선택에 쓰지 않는다.
- 관찰 정상54/256장은 제약 계산에 사용하므로 이번 결과의 평가/검증 자료가 아니다.
- 경계 후보는 각 보존 대상의 각 영역 원점수다. 그보다 높은 경계는 그 사진을 검출하지 못하고,
  낮은 경계는 정상 경고를 더 늘리므로 대상 점수로 경계를 올려도 보존 능력을 잃지 않는다.
  따라서 이 유한 후보 집합으로 존재 여부를 완전하게 탐색할 수 있다. 동점은 `>=`로 함께 경고한다.
- 같은 영역의 여러 후보 선택은 가장 낮은 경계 하나와 같으며 영역별 OR를 그대로 나타낸다.
- 부분 상태는 검출한 대상·두 정상 집합에서 경고한 사진의 비트 집합이다. 같은 상태는 한 번만 탐색한다.
  정상 예산 초과 선택은 어떤 후속 OR 선택으로도 회복할 수 없으므로 가지치기한다.
- 남은 대상 중 선택 가능한 후보가 가장 적은 사진부터 탐색한다. 후보 순서는 추가 정상 경고 수,
  새 대상 검출 수의 내림차순, 영역 순서, 경계 값으로 고정한다. 데이터 추가·재선정은 없다.
- 탐색30초·100,000개 상태·RSS2GiB를 상한으로 둔다. 한도를 만나면 **미확정**이며 불가능으로 표시하지 않는다.
- 가능한 해1개면 즉시 종료한다. 경계는 비배포 진단 증거로만 기록하며 서비스 계약을 생성하지 않는다.
  해를 찾지 못하고 모든 상태를 소진했을 때만 제한된 구조의 불가능으로 기록한다.
- 별도 단순 전수 탐색과의 작은 합성 사례 비교, 동점·OR 중복·정상 예산·자원 중단 테스트 후 실행한다.

## 다음 분기

해가 없으면 같은 원점수의 영역 경계만 바꾸는 실험은 추가하지 않는다. 점수 표현/모델 또는
지원 목표를 바꾸는 설계가 필요하며, 사용자 동의 없이 학습·목표 완화는 하지 않는다.
해가 있으면 이것을 정상-only 모델로 채택하지 않는다. 정상 자료만으로 추정할 실제 구조 변경안 하나의
필요 데이터·검증 규칙을 설계한다. 미확정이면 시간 제한을 자동 늘리거나재시도하지 않는다.

진행 방식은 앞으로 설계→구현→검증→결론을 묶되, 독립 평가·서비스 승격과 증거 보존은 생략하지 않는다.
