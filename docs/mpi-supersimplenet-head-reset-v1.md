# SuperSimpleNet 검출부 초기화 대조 실험

기존 검출부의 학습 상태가 새로운 합성 이상을 배우는 데 영향을 주는지 확인한다.
기존 잡음 0.015 모델을 읽기 전용 기준으로 두고, 정식 모델의 새 복사본에서 위치·분류 검출부만
초기화한 후보를 같은 조건으로 500회 학습한다. 실제 불량 정확도 시험이나 서비스 모델 교체가 아니다.

## 비교 조건

| 항목 | 기존 기준 | 새 후보 |
| --- | --- | --- |
| 출발점 | 정식 300 epoch 모델에서 이어 학습 | 같은 정식 모델에서 검출부만 초기화 |
| 정상 입력 | 원래 고정 정상 사진 한 장의 8개 영역 타일 | 동일 |
| 합성 이상 잡음 | 표준편차 0.015, 평균 0, Perlin 기준 0.6 | 동일 |
| 학습 | 500회, 난수 10000부터 10499 | 동일 |
| 변환부 | 원래 값에서 시작해 학습 | 동일 |
| 특징 추출부 | 고정 | 동일 |
| 학습률 | 변환부 0.0001, 검출부 0.0002 | 동일 |
| 최적화 | 새 AdamW, 가중치 감쇠 0.01 / 0.00001, 스케줄러·AMP 없음 | 동일 |

검출부 초기화 난수는 결과를 보기 전에 **20261006** 하나로 고정한다. Anomalib 2.2.0의
공식 `SegmentationDetectionModule(channel_dim=1536, stop_grad=True)`를 CPU에서 새로 생성해 GPU로 옮긴다.
공식 생성자의 가중치·편향 초기화를 사용하고 두 BatchNorm의 평균·분산·누적 횟수도 새 상태로 만든다.
기존 검출부에 `apply(init_weights)`만 호출하면 편향과 누적 통계가 남으므로 사용하지 않는다.
초기화 전후 특징 추출부·변환부 해시가 같은지, 위치·분류 검출부 해시가 달라졌는지 검사한다.
재개할 때는 저장 모델과 AdamW 상태를 복원하며 다시 초기화하지 않는다.

공식 소스: https://github.com/openvinotoolkit/anomalib/blob/v2.2.0/src/anomalib/models/image/supersimplenet/torch_model.py
설치된 공식 소스 해시는 기존 정식 학습 환경과 일치해야 한다.

## 한 번 실행할 때 하는 일

1. 원본 ZIP·정식 학습·기존 고정500·변경 합성500의 증거와 로컬 체크포인트를 검증한다.
2. 기존 변경 합성500 모델을 학습 없이 평가하고, 이전 ZIP의 다섯 난수 원시 출력과 비교한다.
3. 정식 원본 출력도 재현한 뒤 검출부만 초기화하고 초기 상태를 기록한다.
4. 500회 학습한다. 모든 학습 마스크·라벨 해시가 기존 500회 기록과 일치해야 한다.
5. 0·50·100·200·300·400·500회에 저장하고 동일 합성 이상·정상 대조를 평가한다.
6. 최종 모델을 다시 불러와 다섯 난수 출력·파라미터·통계 해시를 재현하고 결과 ZIP을 만든다.

평가 난수는 참조42와 900001부터 900004다. 주 비교는 뒤의 네 난수 평균이며 참조42는 제외한다.
이 네 난수는 제한 학습에 쓰지 않지만 이전 진단에서 이미 관찰했다. 새 사진의 일반화 성능을 뜻하지 않는다.
동일 난수는 같은 합성 위치와 잡음 생성 순서를 뜻한다. 학습 중 변환부가 서로 달라지므로
최종 합성 특징 텐서까지 동일하다는 뜻은 아니다.

## 결과 해석과 다음 결정

최종500회와 초기 상태를 기존 기준과 함께 보고, 중간 최고 성적 모델을 자동 선택하지 않는다.
사진·픽셀 AUROC뿐 아니라 동일 원본·동일 위치의 정상 대조 구분, 합성 위치의 점수 증가,
이상을 넣지 않은 정상에 같은 가상 라벨을 붙였을 때의 성적을 함께 기록한다.
정상 대조에서도 높다면 합성 이상을 배운 것이 아니라 원래 위치·외관 차이를 읽었을 수 있다.

구분력이 여러 평가 난수에서 일관되게 개선되고 정상 대조가 이를 설명하지 못하는 경우에만
별도 후속 정상 사진 다양성 실험을 검토한다. 개선이 없으면 같은 조건의 장시간 연장을 자동 진행하지 않는다.
한 초기화 난수의 대조이므로 개선되어도 초기화 효과의 재현성·실제 결함 검출을 확정하지 않는다.
이 실험은 검출부의 가중치·편향·정규화 통계를 묶어서 초기화하는 개입이며 이들 각각의 원인을 분리하지 않는다.

## 자원 상한과 보존

누적 측정 시간 30분, RAM 20GiB, PyTorch GPU reserved 6GiB, 사전 여유 디스크 8GiB를 적용한다.
시간에는 평가·저장·재개 재현이 포함되며 입력 사전 검증과 최종 ZIP 포장 시간은 제외된다.
완료 업데이트500회, 재개 시 반복 작업까지 시도650회 상한이다. 파일·타일·잡음·반복 수를 자동 축소하지 않는다.
Ctrl+C로 정상 중단된 실행은 같은 명령으로 마지막 봉인 저장점에서 재개할 수 있다.
강제 종료로 종료 기록이 없거나 자원 오류가 발생한 경우 자동 재개하지 않고 검토한다.
기존 원본·모델·결과 ZIP·경고 기준·서비스는 변경하지 않는다. 실제 시험 이미지·마스크는 열지 않는다.

## 연구실 실행

다른 GPU 작업을 정상 종료하고 기존 폴더와 ZIP을 그대로 둔다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_mpi_supersimplenet_head_reset.ps1
```

기본 원본은 `Downloads\extracted.zip`이다. 결과는
`artifacts\handoff\mpi-supersimplenet-head-reset-v1.zip`으로 전달한다.
모델은 별도 `artifacts\analyses\mpi-supersimplenet-head-reset-v1`에 보존하며 전달 ZIP에는 모델·원본 사진을 넣지 않는다.
Mac의 대체 실행기 테스트는 저장·재개·검증 흐름의 검사이지 실제 CUDA 학습의 증명이 아니다.
