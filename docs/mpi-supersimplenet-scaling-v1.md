# MPI SuperSimpleNet 정상 자료 확대 학습

정상 원본 64장만 반복한 학습과, 기존 64장을 포함하는 256장 학습을 비교한다.
자료의 다양성과 계산량을 구분해 확인하는 탐색 연구이며, 기존 Q90 모델과 서비스는 변경하지 않는다.
2026년 10월 6일 사용자 승인에 따라 명단 등록과 중단 후 재개 가능한 학습 실행을 준비했다.

## 비교 조건

| 실행 이름 | 정상 원본 | 타일 | epoch | 업데이트 | 학습률 감소 시점 |
| --- | ---: | ---: | ---: | ---: | --- |
| a64-e300 | 64 | 768 | 300 | 28,800 | 23,040 및 25,920회 완료 후 |
| c256-e75 | 256 | 3,072 | 75 | 28,800 | 23,040 및 25,920회 완료 후 |
| d256-e300 | 256 | 3,072 | 300 | 115,200 | 92,160 및 103,680회 완료 후 |

각 조건은 독립적으로 새 초기 상태에서 시작한다. 학습 완료 모델이나 최근 500회 진단 모델을 이어 쓰지 않는다.
A도 같은 실행기로 새로 학습하여 비교 기준을 맞춘다. 사전학습 특징 추출기와 seed42 초기 가중치는
검토한 정식 학습의 초기 지문과 대조한다. 내부 특징 복제 후 16개가 되지만 입력 배치는 서로 다른 타일 8개다.

Anomalib 2.2.0 공식 학습 forward와 SSNLoss를 그대로 사용한다. 배치 8, FP32, 잡음 0.015,
Perlin 0.6, stop_grad, AdamW, 학습률 0.0001/0.0002, 가중치 감쇠 0.01/0.00001을 유지한다.
특징 추출기는 동결하며 epoch별 순서는 이전 정식 학습과 같은 해시 규칙이다.
학습률은 각 실행의 80%, 90% 업데이트를 완료한 후 0.4배가 된다.

A와 C는 계산량이 같지만 사진당 반복 수가 다르다. D는 A보다 자료와 업데이트가 모두 4배이므로
개선이 있어도 자료 다양성만의 효과라고 단정하지 않는다. C의 실패로 D를 자동 취소하지 않는다.
D의 75 epoch 중간 저장은 학습률 경로가 다르므로 C의 대체물이 아니다.
64장 600 epoch 조건은 이번 실행에 포함하지 않는다.

## 학습 명단 고정과 자료 보호

검토한 `mpi-supersimplenet-fit-v1.zip`에서 기존 64장과 개발128/보정169 명단을 읽고,
`mpi-normal-diversity-preparation-v1.zip`의 검토된 적격 정상 풀 1,086장을 사용한다.
두 ZIP의 전체 SHA256과 풀 명단·타일 지문 SHA256은 실행 코드에 고정되어 있다.
이 풀은 개발128, 보정169, 정상 검증256, 기존 시험과 동일한 RGB를 갖는 타일 및 중복·손상 사진을 제외했다.
이전 특징 기반 64장 선정 결과나 결함 성적은 이번 추가 명단 선정에 사용하지 않는다.

1. 기존 64장은 원래 순서로 모두 유지한다.
2. 나머지 후보를 `SHA256(mpi-supersimplenet-scaling-v1 + NUL + additional-normal + NUL + photo_id)`로 정렬한다.
3. 앞의 192장을 추가한다. 성적을 보고 재선정하지 않는다.
4. 원본 ZIP의 전체 해시와 선정256/개발128/보정169의 6,636타일을 검증한다.
5. 명단과 실행 조건을 `artifacts/mpi-supersimplenet-scaling-v1/identity/value.json`에 고정한다.

한 원본의 12영역을 분리해 서로 다른 데이터 그룹에 넣지 않는다. 정상 원본256장은 새로운 물리적 기판이나
독립 촬영 세션256개를 뜻하지 않는다. 정확한 픽셀 중복 배제만으로 근접 중복까지 배제됐다고 주장하지 않는다.
등록·학습은 시험 이미지와 마스크를 열지 않는다.

## 저장과 중단 후 재개

각 조건은 별도 GPU 프로세스에서 순차 실행한다. 10 epoch마다 그리고 최종 epoch에 저장한다.
가중치, AdamW 상태, Python/NumPy/CPU/CUDA 난수 상태와 학습 기록을 함께 저장한다.
단계별 해시를 검증하며 최종 epoch만 결과로 사용한다. 좋은 점수가 나온 중간 모델을 선택하지 않는다.

Ctrl+C를 한 번 누른 뒤 자식 프로세스가 중단 기록을 저장할 때까지 기다린다.
같은 명령을 실행하면 마지막 완전한 저장부터 이어간다. 미저장 업데이트는 같은 상태에서 재실행되며 시도 횟수에 기록된다.
강제 종료·정전·손상 파일·메모리 오류는 자동으로 무시하지 않고 보존 후 검토한다.
누적 업데이트 재시도 여유는 실행별 30 epoch이며, 정식 완료 업데이트 수는 늘리지 않는다.
작업 중 코드 변경이나 git pull은 재개 지문을 바꾸므로 하지 않는다.

경과 시간 상한은 없다. RAM20 GiB와 GPU reserved6 GiB 상한은 유지한다.
시작 전 다른 GPU 작업을 정상 종료하고 GPU 여유6 GiB를 확보한다.
세 조건의 모든 체크포인트를 보존하므로 최초 학습 전 디스크100 GiB 여유를 요구한다.
진행 중 실제 체크포인트 크기로 남은 공간을 추가 확인한다. 공간 부족 시 자동 삭제하지 않는다.

## 정상 보정과 이후 평가

조건마다 최종 모델의 개발128장 원시 분류 점수로 영역별 중앙값과 Q90 폭을 정한다.
보정169장의 표준화된 12영역 최대 점수에서 Q95 higher 경고 기준을 계산한다.
이 자료는 가중치 학습에 넣지 않는다. 경고 기준의 숫자는 모델별 척도가 달라 직접 비교하지 않는다.
최종 모델 재로딩 후 정상297장 전체의 지도·분류 점수·경고 판단을 재현하는지 검증한다.

이번 명령은 학습과 정상 보정까지만 수행한다. 합성 구분력의 별도 사진 일반화, 기존 불량12장 및 전체 불량55장,
정상54/256장의 오경보, 속도·보정 안정성은 결과 검토 후 별도 평가 계획으로 고정한다.
기존12장을 전부 유지하지 못했다는 이유만으로 나머지 조건의 학습을 자동 중단하지 않는다.
이 자료는 이미 관찰했으므로 모든 후속 성능 비교는 탐색·회귀검증이며 새로운 일반화 성능의 증명이 아니다.

## 연구실 실행

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_mpi_supersimplenet_scaling.ps1
```

기본 원본은 `Downloads\extracted.zip`이다. 원본이 다르면 `-Archive`로 지정한다.
명단과 무결성만 먼저 확인하려면 `-PrepareOnly`를 추가한다. 이 모드는 GPU 학습을 실행하지 않는다.
검토된 두 입력 ZIP은 `artifacts\handoff`에 있어야 한다. 패키지를 업그레이드하거나 과거 출력을 삭제하지 않는다.

완료 후 `artifacts\handoff\mpi-supersimplenet-scaling-v1.zip`을 전달한다.
명단·학습 기록·보정·재로딩·체크섬 JSON만 포함하며 원본 이미지와 모델 파일을 외부로 전달하지 않는다.
준비 결과는 `mpi-supersimplenet-scaling-v1-preparation.zip`, 조건별 결과는 같은 이름에 조건 접미사를 붙여 보존한다.

## 확인 범위

Mac에서는 명단 선정·격리 규칙, 일정, 경고 기준과 중단·재개 흐름을 CPU 및 가짜 runtime 테스트로 확인한다.
실제256장 무결성, RTX5060 학습, 실제 checkpoint/RNG 재현과 최종 성능은 Windows 실행 결과로 확인해야 한다.

2026년 10월 6일 로컬 전체 검사 결과는 1,046 passed, 5 skipped, 52 subtests passed다.
확대/기존 학습 관련 검사는 30 passed, 2 skipped이며 생략된 로컬 검사는 과거 입력 ZIP 부재 때문이다.
PowerShell과 CUDA는 이 Mac에서 실행하지 않았다. 실제256장 명단 생성·원본 검증은 연구실 준비 단계에서 완료된다.
