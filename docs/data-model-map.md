# 데이터와 모델 연결 관계

기준일: 2026-10-04. 검증된 연구실 결과와 현재 구현 상태를 구분했다.
사이클1의 정상 폭 공유 후보와 다양성64장 후보는 모두 비채택했다.
[종료 결정·비교표](../reports/mpi-model-cycle-1-conclusion.md)에 현재 상태를 정리했다.
이후 기존 bank의 정상 폭만 바꾼 [Qn 후보](../reports/mpi-qn-scale-v1-review.md)도 검출43/55·
오경보2/54와12/256, 기존 검출10장 상실·안정성 실패로 비채택했다. 새 모델 학습은 없었다.
**현재 MPI 연구 기준선은 top1%+Q90: 검출53/55·미탐2/55·정상 오경보3/54,
별도 정상256장 오경보14/256이다. 공간26×26 후보는 검출49/55·오경보5/54와15/256으로 비채택이다.**
아래 과거 A·동일 영역 검색은 연구 이력이다. 새 단계의 기준은
[모델 개발 통합 계획](model-development-plan-v1.md)이며 서비스 transistor 모델과 분리한다.

[최근접 3개 사전 검사](../reports/mpi-knn3-screen-v1-received-review.md)는 기존 MPI 원래 bank에서
지도 점수 계산만 바꾼 파생 규칙이었다. 새 학습·데이터셋 병합은 없었다.
정상297장 보정 후 고정 기존 검출12장 중10장만 유지해 종료했다. 후보 재로딩·전체 평가는 하지 않았다.

[다음 모델 설계](../reports/mpi-model-redesign-2026-10-03.md)는 EfficientAD-S 실행 가능성 점검 제안이다.
기존 정상64장은 신경망 학습,128장은 지도·영역 보정,169장은 사진 경고 기준에 사용하도록 설계한다.
외부 Imagenette 보조 자료는 제품 정상 자료와 별개다. 연구실에서 취득해 사전 점검에 사용했지만
기존 PatchCore나 서비스에 연결한 것은 아니다. 기존 시험109장·정상256장은 관찰된 회귀 자료로 유지한다.
[사전 점검 결과](../reports/mpi-efficientad-probe-v1-received-review.md)는 정상64장 중 고정8장·96타일과
보조 Imagenette96장으로100회 업데이트를 완료했다. 자원·저장 복원은 통과했고 정확도는 미측정이다.
정식64장 학습과 정상128/169장 보정·불량 평가는 미실행이다.
[정식 실행기](mpi-efficientad-fit-v1.md)는70,000회 학습·정상 보정·재로딩까지 준비 완료다.
보조 Imagenette는 같은 다운로드의 train9,469장 전체를 사용한다. 기존 probe100회 모델은 재사용하지 않는다.

## 먼저 세 가지를 구분한다

| 데이터 역할 | 쉬운 설명 | 모델과의 관계 |
| --- | --- | --- |
| 정상 학습 | 정상 제품의 생김새를 기준으로 만든다 | PatchCore는 정상 특징의 대표 모음인 memory bank를 만든다. PaDiM은 정상 특징의 통계 분포를 만든다 |
| 정상 보정 | 어느 점수부터 사람에게 경고할지 정한다 | 학습에 쓰지 않은 정상 사진으로 임곗값을 계산한다. 기존 bank에 새 특징을 넣는 작업은 아니다 |
| 평가 | 불량을 얼마나 놓치고, 정상을 얼마나 경고하는지 확인한다 | 정상·불량 시험 사진과 위치 정답을 사용한다. 결과로 설정을 고치면 해당 시험은 이후 탐색·회귀용이다 |

**같은 PatchCore는 같은 알고리즘이라는 뜻이지 같은 모델 파일이라는 뜻이 아니다.**
현재 PatchCore는 ImageNet 사전학습 특징 추출기를 고정해 사용하고, 데이터별 정상
기준표를 따로 만든다. 여러 데이터셋을 하나의 모델에 계속 누적 학습한 구조가 아니다.
PaDiM도 이번 프로젝트에서는 사전학습 특징을 사용하며 정상 특징의 통계를 적합한다.

MPI-C1-02는 정상64장을 다시 골라 같은 크기의 **별도 bank**를 만든 후보이며 기존과3장 겹친다.

`transistor`와 `transistor1`, `metal_nut`과 `plastic_nut`, 다른 데이터셋의 `pcb`는

seed 반복은 무작위 선택의 영향을 확인하는 반복 실험이지, 새 품목이거나 누적 학습 횟수가 아니다.

## 지금 MPI-PCB 실험을 확대해서 보면

세 모델 모두 PatchCore이지만 **어느 기판의 정상 패턴을 참조하는지**가 다르다.

| MPI-PCB에 적용하는 모델 | 정상 기준표의 출처 | MPI 정상 169장의 역할 | MPI 시험 109장 결과 |
| --- | --- | --- | --- |
| 기존 Real-IAD PCB 모델 | Real-IAD PCB 정상 학습 자료 | 기준표 고정, MPI용 경고 임곗값만 계산 | 불량 55장 중 검출 2 / 미탐 53, 정상 54장 중 오경보 2 |
| 기존 VisA PCB3 v2 모델 | VisA PCB3 정상 849장 | 기준표 고정, MPI용 경고 임곗값만 계산 | 검출 3 / 미탐 52, 정상 오경보 4 |
| **새 MPI-PCB 전용 모델** | MPI 정상 원본 **64장 × 12영역 = 768개** | 기존 명단 169장으로 **새 모델의** 임곗값 계산 | **검출 1 / 미탐 54, 정상 오경보 1, AUROC 0.9118** |

이 평가의 질문은 “같은 제품의 정상 패턴을 참조하면 나아지는가?”였다. 임곗값만 낮춘 작업도,
Real-IAD/VisA 기존 모델을 덮어쓰는 작업도 아니다. 고정 특징층은 layer1 + layer2,
입력 256×256, 공간 패치 간격 2다. 후보 786,432개에서 10%인 78,643개를 선택한다.
VisA와 학습량·bank 크기도 달라지므로 개선을 데이터 출처 하나의 인과 효과로 주장하지 않는다.

사진 하나가 12영역으로 나뉘므로 **768개 학습 영역은 독립된 기판 768장이 아니다.**
영역별 맵 상위 1% 평균을 계산한 뒤 12영역 중 가장 높은 점수를 원본 사진 점수로 쓴다.
정상 원본 169장의 사진 점수에서 95% 분위수(higher)를 경고 기준으로 정한다.
기준 이하라고 자동 합격하는 것은 아니다. 이번에는 이진 픽셀 판정 임곗값을 만들지 않는다.

기존 시험을 이미 본 뒤 설계한 실험이므로 성적이 좋아져도 사후 탐색 결과다.
기존 예외(정상 중복 제외, 복구 사진 제외 108장 보조 분석, 위치 불량 54장)를 유지한다.
자동 PASS와 현장 생산 성능 보장은 허용하지 않는다.

## 완료된 점수 비교에서 추가된 연결

| 자료 | 연결되는 계산 | 바뀌지 않는 것 |
| --- | --- | --- |
| 별도 정상 128장 | A의 12영역별 정상 중앙값·MAD | 기존 bank에 특징을 추가하지 않음 |
| 기존 보정 정상 169장 | A/B 각각 사진 단위 경고 임곗값 | 기존 기준선 46.8394 보존 |
| 기존 시험 109장 | 기존 점수 / A(영역 정상화) / B(모델 원시 점수) 비교 | 같은 사진, 예외·보조 분석 유지 |

새 모델 세 개를 학습하는 것이 아니라 **같은 저장 모델의 결과를 세 방법으로 읽는 비교**다.
별도 정상 128장은 기존 학습·보정·시험과 정확한 타일 픽셀 중복을 배제해 선정한다.
이미 본 시험을 다시 쓰므로 탐색 결과이며 운영 검증이 아니다.

후속 [정상 패치 출처 진단](mpi-pcb-patch-trace.md)은 A 계산을 그대로 유지한다.
선정12장 → 실제 최근접 bank index → 기존 정상 학습64장의 동일 특징 값/원본 위치를 연결한다.
출처만 재구성하며 bank를 새로 학습하거나 128장·169장의 역할을 바꾸지 않는다.

출처 진단의 선택 bank 벡터369개는 모두 연결됐다. 대표 미탐과 다른 영역 매칭의 관계를
시험하기 위해 [동일 영역 검색](mpi-pcb-region-search.md)을 준비했다. 같은 checkpoint를
읽되 입력 영역에 해당하는 bank 행만 검색한다. 영역마다 새 모델을 학습하는 작업이 아니다.
기존 A 중앙값·MAD·기준은 유지하고, 후보용 수치만 같은 정상128장·169장으로 다시 계산한다.

같은 checkpoint의 출처 전체를 확인한 결과 bank 78,643행을 12영역에 연결했다.
후보의 영역별 벡터는4,961–9,362개다. 영역마다 별도 모델을 학습한 것은 아니다.

### 비교를 완료한 특징 거리 후보

기존 MPI 정상64장 → 원래 bank 78,643×768 → **각 벡터 길이1 변환** → 입력 특징도 같은 변환 →
최근접 거리 지도 → 기존 top1/Q90 집계 순서다. 정상128/169장은 새 거리 단위에 맞춰 다시 보정하고,
이미 본109/256장은 비교에만 쓴다. 새 backbone·bank 행 재선정·서비스 연결은 없다.
[실행 전 설계](mpi-unit-feature-v1.md). [수령 결과](../reports/mpi-unit-feature-v1-received-review.md)는
검출8/55로 기존 검출45장을 잃어 비채택이다. 정상 오경보4/54·13/256, 재로딩297장 차이0이며
기존 Q90을 대체하지 않는다. 실행 명령은 재현용 과거 기록이며 지금 다시 실행할 필요는 없다.

현재 실제로 확인한 운영 시연은 **MVTec transistor PatchCore → Windows 검사 API →
저장된 검사 결과를 Mac에 전달 → 검토 화면·사람 의견·모의 SOP·승인·모의 티켓**이다.
단일 장비의 자동 연결 흐름이나 다품목 모델 선택 기능까지 완성한 상태는 아니다.

Real-IAD·VisA·MPI 모델은 연구 실험용이다. 새 MPI 학습을 실행해도 검사 서버의 모델,
기존 검토 이력, SOP, 티켓은 변경되지 않는다. 같은 PatchCore라고 실험 모델을 서비스에
자동 교체하지 않는다. 별도의 품목 연결·입력 조건·검증·승인이 필요하다.
