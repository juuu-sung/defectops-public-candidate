# SuperSimpleNet 초기화 모델의 출력 검사 수정과 재실행

v1은 검출부 초기화 후 첫 평가에서 중단됐다. 연구실 기록은 초기화 저장 완료, 0회 체크포인트 없음,
학습 시도 0회, 실패 시간 10.998531100107357초다. 학습 성능 실패가 아니라 계산 경로 일치 검사의 실패다.
기존 v1 결과는 보존하고 v2에 같은 초기 상태를 재현해 다시 진행한다.

## 확인한 문제와 아직 확인할 부분

기존 검사는 분리 경로의 검출부를 16개 묶음으로 실행한 뒤 앞의8개를 공식 경로의8개 출력과 비교했다.
코드 주석의 동일 배치 설명과 실제 비교가 달랐다. GPU 계산에서 묶음 크기 차이가 수치 차이를 만들 수 있지만,
이번 중단의 실제 차이 값은 v1 오류에 기록되지 않았다. 따라서 원인을 단순 반올림 차이로 확정하지 않는다.

v2에서는 분리 경로도8개로 계산해 공식 경로8개와 비교한다. 절대 허용오차 **0.0001은 유지**한다.
이전 방식의16개와8개 차이도 지도·사진 점수별로 기록해 가설을 확인한다.
같은 묶음의 차이도 상한을 넘거나 어느 출력 차이든 유한하지 않으면 학습 전에 중단하며,
평가 난수·지도 차이·점수 차이를 오류와 실패 기록에 남긴다.

실험 지표를 산출하는 합성 이상16개와 정상 대조16개의 계산·배열·손실은 바꾸지 않는다.
바뀌는 것은 공식 경로와 분리 경로의 동등성 검사뿐이다.
기존 정식 모델과0.015 기준 모델에도 같은 검증을 적용하며 기존 ZIP의 원시 출력 재현을 계속 요구한다.

참고: [PyTorch 2.8 수치 정확도 문서](https://docs.pytorch.org/docs/2.8/notes/numerical_accuracy.html#batched-computations-or-slice-computations).

## 유지하는 학습 조건

[v1의 실험 설계](mpi-supersimplenet-head-reset-v1.md)를 유지한다.
정식 모델에서 검출부만 초기화하고 정상 한 사진의8타일·잡음0.015·500회·학습률·학습 난수를 그대로 사용한다.
초기화 난수20261006도 바꾸지 않는다. 새 초기화 해시가 v1에 저장된 해시와 같아야 학습을 허용한다.
원래 정식 모델에서 가중치를 다시 읽고 동일 초기화를 재현하는 것이며 다른 초기화 후보를 탐색하는 것이 아니다.
기존 정상 개발·보정 자료와 실제 불량 시험은 열지 않는다. 경고 기준·Q90·서비스도 변경하지 않는다.

## 실패 보존과 시간 제한

v1의 계획·소스 해시·초기화·기준 모델 재현·실패 기록을 확인한다.
정확히 이번 오류로 학습 시도0회에서 중단된 한 번의 실행만 재실행 대상으로 인정한다.
학습이 진행됐거나 다른 오류·불완전한 기록이면 자동으로 우회하지 않는다.
v1 파일은 수정·삭제하지 않으며 해시를 기록하고 v2 완료 때 다시 확인한다.

30분 누적 시간 상한에 v1의 실패 시간도 포함한다. RAM20GiB·GPU reserved6GiB·디스크 여유8GiB와
학습500회·재개 포함 시도650회 상한은 같다. v2의 정상 Ctrl+C 중단은 마지막 봉인 저장점에서 재개하며,
실패·강제 종료·자원 초과는 보존하고 검토한다. v2가 실패해도 새 폴더를 임의 생성하거나 난수를 바꾸지 않는다.

## 연구실 명령

기존 모든 폴더와 ZIP을 그대로 두고 다른 GPU 작업을 정상 종료한다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_mpi_supersimplenet_head_reset.ps1
```

같은 실행 파일이 v2로 연결된다. 원본 기본 경로는 `Downloads\extracted.zip`이다.
정식 모델·기존0.015 모델 재현 → 같은 초기화 재현 → 초기 검증 →500회 학습·중간 저장 →최종 재로딩을 실행한다.
완료하면 `artifacts\handoff\mpi-supersimplenet-head-reset-v2.zip`을 전달한다.
학습 모델은 `artifacts\analyses\mpi-supersimplenet-head-reset-v2`에 별도로 보존한다.

## 결과를 읽는 순서

먼저 초기화 동일성, 같은 묶음 출력 차이, 학습 목표 해시와 최종 재로딩을 확인한다.
그다음 최종500회의 합성 구분력을 기존 기준과 비교하고 정상 대조에서 같은 위치에 반응하는지 확인한다.
수치 검사가 통과했다는 것과 모델이 합성 이상을 배웠다는 것은 별개다.
Mac의 대체 실행기 테스트는 분기·기록·재개 검사이며 실제 GPU 통과는 연구실 결과 수령 전까지 미확인이다.
