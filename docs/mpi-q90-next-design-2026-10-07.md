# Q90 잔여 문제와 후속 실험 설계 기준

2026-10-07. **SuperSimpleNet A·C·D 확대 비교는 종료하고 Q90의 남은 문제를 개선 대상으로 고정한다.** Q90으로 되돌아가는 것은 완성이나 배포 선언이 아니라, 가장 많은 기존 불량을 검출한 연구 기준선에서 출발한다는 뜻이다.

후속 동의에 따라 **PatchCore 정상64→256장 확대·bank 크기 유지**를 우선 방향으로 선정하고
[합성 특징 분할 계산 점검](../reports/mpi-patchcore-scaling-probe-v1-received-review.md)을 통과했다.
[실제256장 후보 실행기](mpi-patchcore-scaling-v1.md)는 디스크 특징 저장·전체 후보 대표 선택·
정상 보정·재로딩과 전체 비교를 한 흐름으로 연결한다. 아래 두 방향 비교는 선정 근거다.

## 무엇을 해결해야 하는가

| 문제 | 확인된 사실 | 다음 비교에서 필요한 증거 |
| --- | --- | --- |
| 미탐2장 | 0019·0024의 주요 grid3-2에는 결함 반응이 있지만 사진 경고선 미달 | 기존 검출53장을 잃지 않고 적어도1장 추가 검출 |
| 정상 오경보 | 3/54·14/256, 정상 커넥터 핀·콘덴서 옆면·일부 검은 경계에도 높은 반응 | 정상 두 집합의 오경보를 각각 확인하고 새 오경보/해소 목록 제시 |
| 보정 불안정 | 최근 양쪽 재표집 검출 수 2.5–97.5백분위 3–55 | 같은 사진 묶음·난수로 보정 민감도를 재계산하고 하방 검출 저하 확인 |

0019·0024의 주요 결함을 담는 상위656픽셀의 GT 포함률은 각각69.57%,75.52%였다. 다른 결함 부위에도 충분히 반응한다는 뜻은 아니다. 두 미탐을 모두 잡도록 경고선만 낮추면 정상 오경보가7/54·19/256으로 늘어난다는 기존 사후 진단이 있다. 이 값을 새 설정으로 사용하지 않는다.

근거: [잔여 미탐 지도](../reports/mpi-spatial-miss-review-v1-received-review.md), [정상 반응 위치](../reports/mpi-normal-map-review-v1-received-review.md), [최신 전체 비교](../reports/mpi-supersimplenet-scaling-evaluation-v1-received-review.md).

## 이미 끝낸 실험을 다시 시작하지 않는다

공간26×26 평균, 정상 폭 부분 공유, Qn, 영역 순위, 정상64장 다양성 재선정, 특징 L2 정규화, 최근접3 평균은 기존 조건에서 개선 근거를 확보하지 못했다. 같은 파라미터를 조금씩 바꾸는 후속 탐색은 자동 추가하지 않는다. [누적 비교 원장](../reports/mpi-model-redesign-2026-10-03.md)의 수치와 각 실험의 분모를 유지한다.

특히 아래 서로 다른 실험을 혼동하지 않는다.

- 정상64장을 다른64장으로 **재선정**한 것은 PatchCore가 서로 다른 정상256장을 **추가 학습**한 시험이 아니다.
- SuperSimpleNet의256장 확대 실패가 PatchCore의256장 정상 참조 확대도 실패한다는 뜻은 아니다.
- 과거 동일 영역 검색은 이미 만든 공용 bank를 잘라 검색한 시험이다. 영역마다 대표 패치를 별도 선정한 시험이 아니다. 다만 과거 실패가 새 방식의 성공 근거가 되지도 않는다.
- 검사 시간 상한은 두지 않는다. 속도는 보고하되 정확도·안정성 검사를 생략하는 조건으로 쓰지 않는다. 메모리·무결성 제한은 유지한다.

기존 자료만으로 이미 확인한 원점수·경고선 문제를 다시 설명하기 위해 GPU 지도 진단을 반복하지 않는다. 새로운 측정은 아래 설계 결정에 실제로 필요한 경우에만 추가한다.

## 다음 후보의 질문과 선택 범위

다음 설계 질문은 **정상 참조의 구성을 바꾸면 정상 외관에 대한 과한 반응을 줄이면서 결함 반응은 유지할 수 있는가**다. 특징 추출기·입력 해상도·상위1% 집계·Q90 보정 규칙은 먼저 유지하는 방향을 검토한다. 더 많은 정상 참조가 불량 거리까지 낮춰 미탐을 늘릴 수 있으므로 성능 향상을 전제하지 않는다.

두 방향을 비교해 고정된256장 명단을 사용할 수 있는 실제 정상 확대를 우선했다. 영역별 대표 수의 새 배분 근거가 필요한 두 번째 방향은 보류한다. 정식 학습에 앞서 원특징9GiB를 GPU에 한 번에 올리지 않는 분할 계산 점검을 진행한다.

| 검토할 방향 | 기존 시험과 다른 점 | 실행 전 확인할 점 |
| --- | --- | --- |
| 기존64장을 포함하는256장으로 PatchCore 정상 참조 구성 | 사진 재선정이 아닌 실제 학습 정상 확대. SSN과 다른 학습 방식 | 고정 bank 예산에서 대표 선정 비용·메모리, 원본 패치 누락 없는 처리 가능성 |
| 같은64장으로 영역별 대표 선정 후 공용 bank 결합 | 검색 영역을 제한하지 않고 대표 선정만 분리 | 영역별 예산 근거, 기존 총 bank 크기 유지, 특정 영역의 정상 다양성을 과하게 줄이지 않는지 |

두 방향을 함께 바꾸거나 bank 크기·특징층·임곗값까지 동시에 바꾸지 않는다. 영역별 벡터 수가4,961–9,362개라는 사실만으로 정상 표현의 부족을 확정할 수 없고, 균등 할당이 더 좋다는 보장도 없다. 따라서 지금 임의의 영역별 할당량을 정해 실행하지 않는다.

정상 참조 설계에 필요한 후보 수·벡터 차원·저장량·정확한 선정 연산을 먼저 산정한다. 8GiB GPU에서 처리할 수 없으면 처리 분할과 원래 계산의 동등성을 검증하거나 비용 한계를 보고한다. 후보 패치 수를 조용히 줄이거나 임의 재표본으로 대체하지 않는다. 실행 가능성과 기존 실험 대비 새 질문이 명확하지 않으면 후보 선정을 보류한다.

## 단계별 진행과 산출물

| 단계 | 작업 | 완료 조건 |
| --- | --- | --- |
| 1 비교 종결 | SSN 결과·비채택·Q90 잔여 문제를 저장소와 노션에 기록 | 이번 단계. 모델·서비스 불변 |
| 2 단일 후보 설계 | 위 두 방향의 비용·변경 요인을 비교해 하나만 선정 | 데이터·정상 선정·bank 예산·난수·보정·자원·재개 규칙이 명시된 실행 카드 |
| 3 실행기 준비 | 선택된 후보의 학습·보정·전체 평가·민감도·전달을 한 흐름으로 구현 | CPU 검사와 저장/재개/오류 보존 검증, 연구실 명령 제공 |
| 4 연구실 실행 | 사전 자원 점검 후 고정 후보1개 실행 | 정상 재로딩 확인 후 전체55불량·정상54/256·위치·속도·보정 민감도 완료 |
| 5 결론 | 개선/부분 개선/비채택과 다음 조건을 한 번에 보고 | 자동으로 다음 파라미터·seed·추가 모델을 실행하지 않음 |

별도의 승인 없이 모델을 서비스에 연결하지 않는다. 연구실에서 긴 작업을 시작할 때는 실행 명령과 입력·출력·재개 방법을 함께 제공한다. 현재 실행 지시는 [정상256장 확대 문서](mpi-patchcore-scaling-v1.md)이며, 완료한 합성 점검을 다시 실행하지 않는다.

## 판정 기준을 바꾸지 않는 비교

후속 실행 카드에서는 아래 기준을 후보 결과를 보기 전에 고정한다.

1. 기본 회귀 조건은 기존 검출53장 전부 보존이다. 검출 수만 같은데 다른 불량을 놓치면 손실을 따로 기록한다. 미탐 개선이라는 표현에는0019·0024 중 적어도1장의 추가 검출이 필요하다.
2. 정상 오경보 목표는≤2/54 및≤12/256이다. 단순히 Q90보다 조금 낮으면 전부 통과한 것으로 표시하지 않는다. 이 작은 관찰 표본의 차이는 독립 성능 입증이 아니다.
3. 기존12장 결과는 설명용 회귀 지표이며 전체 평가를 막지 않는다. 성능이 낮아도 전체 비교·정상 보정 민감도를 완료한다. 기술 오류·무결성·메모리 초과는 중단한다.
4. 최근600회와 같은 원본사진 재표집 인덱스, 개발만/보정만/양쪽 분리를 사용한다. 검출 분포 폭뿐 아니라 낮은 백분위 검출과 높은 백분위 오경보를 함께 평가한다. 수치 허용 범위는 기존 안정성 계약을 대조해 실행 카드에 명시하며 결과를 보고 완화하지 않는다.
5. GT는 위치 진단과 평가에만 사용한다. 사진별 맞춤 경고선·마스크 기반 점수·고득점 정상 삭제는 하지 않는다. 위치 진단에서0006 제외와 사진 평가 포함 규칙을 유지한다.
6. 재로딩은 같은 환경 점수 차이≤1e-4·판정 변화0을 확인한다. 추론 RAM20GiB·PyTorch reserved6GiB를 기본 검토 한도로 두되 학습/선정의 실제 한도와 여유는 실행 카드에서 명시한다. 실행 도중 자동 완화하지 않는다.

현재 자료는 전부 탐색·회귀 자료다. 새로 확보하지 않은 독립 시험 성능이나 실제 생산 품질을 주장하지 않는다. Q90의53/55도 운영 합격 기준은 아니며 자동 PASS는 계속 금지한다.
