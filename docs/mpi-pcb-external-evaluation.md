# MPI-PCB 두 동결 모델 외부 시험

상태: **코드·설정 준비, 연구실 GPU 실행 대기. 실제 시험 성능은 아직 없음** (2026-09-26).

## 무엇을 확인하나요?

이미 만든 Real-IAD PCB 모델과 VisA PCB3 정상 뱅크 v2 모델이, 새로운 MPI-PCB에서
얼마나 많은 변형 사진을 놓치는지 비교한다. 새 모델을 학습하는 작업이 아니다.
MPI-PCB 정상 사진 169장으로 이미 만든 판정 기준도 그대로 사용한다.
정상 데이터를 이용한 적응이 있으므로 zero-shot이라고 부르지 않는다.

| 항목 | Real-IAD PCB | VisA PCB3 v2 |
| --- | --- | --- |
| 모델 | 기존 seed42, layer1–layer2 | 기존 정상 뱅크 v2, seed42 |
| 고정 임곗값 | 67.42196179599297 | 66.18967593588481 |
| 평가 대상 | 정상 55장 + 수동 변형 55장 | 동일 사진 110장 |
| 우선 볼 결과 | 변형 55장 중 미탐, 정상 55장 중 오경보 | 동일 |

각 사진의 12영역에서 이상 맵 상위 1% 평균을 구한 후, **12영역의 최댓값**을
사진 한 장의 점수로 쓴다. 점수가 해당 모델 임곗값 이상이면 검토 대상이다.
임곗값 미만이어도 제품 자동 합격을 의미하지 않는다. 겹치는 영역 1,320장을
독립 시험 사진 1,320장으로 세지 않는다.

## 실행 순서와 중단 규칙

1. Git 코드 상태, 원본 ZIP, v4 정상 명단, 모델 사전 점검, 두 checkpoint,
   정상 보정 JSON과 설정의 해시를 대조한다. 입력 파일을 수정하지 않는다.
2. **정상 점수 재현:** 두 모델을 순서대로 불러와 정상 169장 × 12영역을 다시
   추론한다. 모델별 모든 영역·사진 점수를 이전 보정 기록과 비교한다.
   최대 절대 차이 `0.0001`을 초과하면 시험 개봉 없이 중단한다.
   임곗값을 새 점수로 다시 맞추거나 반올림하지 않는다.
3. **시험 무결성 감사:** 정상·수동 변형 110장의 12영역 이미지 1,320개와
   변형 위치 마스크 660개를 모두 읽는다. ZIP/PNG CRC, 완전한 디코딩, RGB
   256×256 이미지, native 256×256 불투명 회색조 마스크를 요구한다.
   마스크는 크기를 바꾸지 않고 0보다 큰 값을 표시 영역으로 해석한다.
   한 영역의 마스크가 비어 있어도 허용하지만, 변형 사진의 12영역 마스크가
   전부 비면 중단한다. 색 마스크나 다른 크기는 임의 변환하지 않고 검토한다.
4. **중복 기준:** 동일 위치의 12영역 RGB 해시가 모두 같은 시험 사진끼리,
   또는 시험 사진과 정상 보정 사진이 있으면 두 모델 평가를 모두 중단한다.
   반복 배경 등 단일 영역만 같은 경우는 건수만 기록한다. 유사 사진·근접 촬영
   중복을 찾는 검사는 아니다. 감사 문제가 있으면 표본을 제외·교체하지 않는다.
5. 감사가 통과하면 두 모델을 하나씩 불러 동일 시험 110장을 점수화한다.
   이미지 바이트·RGB 해시를 감사 기록과 다시 비교하고, 지역별 점수와 원시
   이상 맵을 보존한다. 두 모델이 모두 완료돼야 비교 결과를 만든다.

2단계까지 시험 내용은 봉인 상태다. **3단계부터 시험 내용은 개봉된 상태**다.
도중 문제가 생겼다고 다시 미관측 시험으로 취급하지 않는다. 예상 밖 예외도
부분 진행 여부와 실패 기록을 남기며, 유효한 비교 성적이라고 주장하지 않는다.

## 성적표에 포함되는 것과 한계

- 1차 지표: 미탐률 = 놓친 변형/55, 정상 오경보율 = 잘못 검토 대상으로 보낸 정상/55.
- 부가 지표: TP/FP/TN/FN, recall, precision, F1, 검토 비율, 사진 AUROC/AP.
  검토 비율·precision은 이 시험의 50% 변형 비율에 의존하며 공장 수치로 이전하지 않는다.
- 동일 사진에서 두 모델이 같이 잡은 수, 각각만 잡은 수, 함께 놓친 수를 기록한다.
  단순히 총 미탐 수의 차이를 '기존에 놓친 사진을 그만큼 모두 새로 잡음'으로 해석하지 않는다.
- 사진 단위 Wilson 95% 구간 및 정상/변형 클래스별 짝지은 bootstrap 5,000회
  (seed 20260926)로 VisA−Real-IAD 오류율 차이 구간을 산출한다. 이는 기술적 요약이다.
  한 기판의 반복 촬영이라 서로 독립적인 여러 기판·현장 모집단의 불확실성을 추정하지 못한다.
- 위치 마스크는 이번 실행에서 무결성만 검사한다. 겹치는 타일의 pixel AUROC/AUPRO,
  마스크 임곗값 성능은 이번 1차 비교에서 계산하지 않는다.
- 단일 물리 기판·수동 추가 변형 시험이다. 실제 생산 결함의 검출률 증명이나
  자동 PASS·설비 조치 근거가 아니다. 결과 관찰 후 모델·임곗값 변경은 별도 탐색 실험이다.

## 연구실 Windows에서 실행

GPU 검사 API 서버가 실행 중이라면 **그 서버 터미널에서** Ctrl+C로 종료한다.
다른 작업을 임의 종료하지 않는다. 기존 `.venv`·ZIP·모델을 사용하므로 재설치나
압축 해제는 필요 없다. 정상 재현 4,056영역 + 시험 2,640영역 추론으로 GPU를 사용한다.
실행 시간은 아직 실측하지 않았으므로 고정 시간을 보장하지 않는다.

```powershell
Set-Location "C:\개인 프로젝트\defectops"
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw "Git update failed. Stop and share the error." }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_mpi_pcb_external_evaluation.ps1"
```

정상 완료 상태는 `mpi_pcb_external_evaluated_after_normal_adaptation`이다.
완료 후 다음 **JSON 보고서 전용 ZIP 하나**를 첨부한다.

`C:\개인 프로젝트\defectops\artifacts\handoff\mpi-pcb-external-evaluation-v1.zip`

재현 불일치 또는 감사 중단 시에도 만들어진 같은 ZIP과 오류 메시지를 공유한다.
기존 출력이 있다는 오류는 자동 덮어쓰기 방지다. 파일을 지우거나 임곗값을 바꿔
재실행하지 않는다. 중단 원인을 검토한 뒤에만 별도 재실행 절차를 결정한다.

로컬 결과는 `artifacts/evaluations/mpi-pcb-external-evaluation-v1`에 저장한다.
정상 재현 점수, 시험 감사 기록, 모델별 영역/사진 점수, 최종 성적,
각 JSON의 checksum 목록을 ZIP에 포함한다. 원시 이상 맵은 연구실에만 저장하며
float32 비압축 배열 기준 총 약 **660 MiB**이고, 실제 압축 크기는 달라진다.
후속 오류 분석 시 같은 모델을 재추론하지 않고 이 맵을 사용할 수 있다.
사진·마스크·맵·checkpoint는 인계 ZIP, Git, Notion에 올리지 않는다.
