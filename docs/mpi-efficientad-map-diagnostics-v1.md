# EfficientAD 저장 지도 진단

2026-10-04.70,000회 모델은 고정12장 모두 놓쳤다. 이번 작업은 학습을 연장하거나 경고선을
낮추는 실험이 아니라, 이미 저장한 두 이상 지도에서 미탐과 정상 고반응의 위치를 확인하는 CPU 진단이다.
GPU 모델을 로드하지 않으며 원본·모델·지도·임곗값·서비스를 변경하지 않는다.

## 확인할 질문

1. 결함 위치에서 ST(teacher/student 차이)와 AE(autoencoder/student 차이)가 모두 약한가?
2. 한 경로는 반응하지만 다른 경로의 음수 기여나 상위픽셀 평균으로 사진 점수가 약해지는가?
3. 정상 사진의 특정 외관에 강하게 반응해 영역 보정 폭과 사진 경고 기준이 높아졌는가?

정답 마스크는 위치 반응 진단에만 사용한다. 정답 위치로 점수를 바꾸거나 임곗값을 다시 맞추지 않는다.
이번 작업만으로 모델 과적합·학습 부족·공정 원인을 자동 확정하지 않는다.

## 고정 대상과 표시

- 불량12사진: 직전 평가의 동일한12장·동일 순서.
- 정상 고반응6사진: 개발128·보정169에서 각각 점수가 가장 높은3장. 동점은 사진 ID순이다.
  개발1554/1531/1284, 보정1283/1275/1285다.
- 보정 대조2사진: 고정 Q95 경고 기준을 결정한0217,169장 중 점수순 중앙인0469.
- 총20사진·240타일, 사진마다6영역씩2페이지로40장의 비교 카드를 만든다.

각 카드는 원본+정답, 보정ST, 보정AE, 합성지도, 합성지도 상위656픽셀 위치 순서다.
공통 색상 범위는-0.05부터0.50까지, 음수 파랑·0 흰색·양수 빨강이다. 포화 비율과 최대값을
기록하며 사진마다 색상 범위를 맞추지 않는다. 표시만 포화되고 실제 점수는 자르지 않는다.
색과 빨간 상위영역은 불량 픽셀 판정이나 새 경고 기준이 아니다.

ST/AE 기여도는 **합성지도에서 선택된 동일656픽셀 위치**에서 각각 절반의 평균을 계산한다.
두 값을 더하면 기존 타일 점수와 일치해야 한다. ST·AE 각각 다른 위치의 최고평균을 더하지 않는다.
동점 기여도는 행 우선 순서로 고정하고, 그림은 동점을 모두 표시하며 GT 겹침 수치는 가능한 범위를 제공한다.

결함 내부·외부 평균, 영역 내부 순위 AUROC, 상위픽셀의 GT 겹침은 진단 수치다.
전체 Pixel AUROC·새 성능 평가로 해석하지 않는다.0006은 기존 손상 마스크 예외에 따라
사진 전체를 위치 통계에서 제외한다.0054의 기존 승인 복구 타일을 그대로 검증·사용한다.

## 무결성과 재개

수령한 평가 ZIP을SHA256으로 고정하고, 로컬 평가 identity·결과·receipt·지도에서 사진 점수를
재계산한다. 학습 ZIP과 최종 모델·정상 지도·보정 계약도 기존 검증기를 통해 확인한다.
과거 소스141개를 변경하지 않고 새 진단 파일만 추가한다. 새 파일을 기존 실행 identity에 끼워 넣지 않는다.

원본 ZIP을 통째로 풀지 않는다. 고정 대상의 원본·마스크만 읽고 해시를 확인한다. 기존 모델 가중치는
파일 지문 확인만 하며 torch.load나 GPU 추론을 호출하지 않는다. 전체 불량55장 평가로 확대하지 않는다.
최소 여유 디스크1GiB를 요구한다. 해시 확인은 디스크 속도에 따라 수분 걸릴 수 있다.

사진별 완성 카드를 원자적으로 저장한다. 동일 명령 재실행 시 원본·지도·receipt를 재검증하고
완료 사진을 재사용한다. 중간 파일을 삭제하지 않는다. 다른 작업이 같은 학습·평가 폴더에 쓰는 동안
실행하지 않는다. 무관한 GPU 작업을 종료할 필요는 없다.
