## 이번에 바꾸는 것

[다섯 사례 검토](../reports/mpi-score-case-review-v1-received-review.md)에서 남은 미탐0019·0024는
결함 위치에 반응하지만 사진 경고 기준에 못 미쳤다. 정상 오경보는 배선·부품 모서리·타일 경계에
반응했다. 이 관찰은 집계 방식을 비교할 근거이지 공간 집계가 더 좋다는 증거는 아니다.

| 항목 | 기존 Q90 | 이번 단일 후보 |
| --- | --- | --- |
| 모델·normal bank·전처리·지도 | 기존 저장 모델 그대로 | 동일 |
| 영역 원점수 | 떨어진 위치도 포함한 상위656픽셀 평균 | 연속26×26픽셀(676개) 평균의 최댓값 |
| 영역 정규화 | 기존 개발128장으로 만든 median/Q90 간격 | 같은 개발128장으로 후보 점수의 median/Q90 간격 계산 |
| 사진 점수 | 12영역 정규화 점수의 최댓값 | 동일 집계 규칙 |
| 사진 경고 기준 | 기존2.316961… 보존 | 별도 정상169장 후보 점수의95% 분위수로 새 보정 |

26×26은 기존656픽셀과 평균 면적이 비슷한676픽셀을 갖는 정수 정사각형이다. 두 미탐의 모양에
맞춘 최적 창 크기라고 주장하지 않는다. 지도의 다른 위치에서도 이동 간격1로 모든 유효 창을
계산하며 최대 평균을 선택한다. 테두리를 버리거나 padding하지 않고, 마지막 창은
좌상단(230,230)에서 시작해(256,256)까지 포함한다. 창은 타일 밖/인접 타일로 넘어가지 않는다.
최댓값 동점은 행 우선 첫 위치를 기록한다. 누적합·평균 계산은float64다.

**창 크기 탐색·복수 창 조합·원점수max와의 앙상블·정답mask 기반 ROI·새 해상도·재학습은 하지 않는다.**
영역 정규화는 median 및 `q90(higher)-median`이고 분모가1e-6 이하이면 중단한다.
후보 사진 threshold는 보정169장의 사진 최대점수에서 `quantile(.95, method='higher')`로 산출한다.
판정은 `>=`다. 기존 임곗값을 새 점수에 그대로 적용하지 않는다.

## 데이터와 순서

1. 원본ZIP·checkpoint·이전 전달물·기존 실행 코드·이번 고정 정책의 해시를 확인한다.
2. 정상8장으로 기존 모델 점수와 실행 환경을 먼저 확인한다.
3. 정상 개발128장으로 후보 영역별 척도를 만든다.
4. 정상 보정169장으로 후보 경고 기준을 계산하고 변경 불가능한 단계 기록을 저장한다.
5. **이미 관찰한** 시험109장(불량55+정상54), **이미 관찰한** 검증 정상256장을 순서대로 비교한다.

합계662장 ×12영역 =7,944타일(실행 점검 제외)을 같은 모델로 다시 추론한다. 개발·보정 중에는
모델 가중치나 정상bank를 수정하지 않는다. 매 사진에서 기존top1/native 점수를 이전 기록과
비교한다. 최대 절대 차이1e-4 초과 또는 기존 세 점수법의 경고 판정 변경 시 중단한다.
복구가 승인된defect/0054는 기존 복구PNG와 해시 계약을 그대로 사용한다. 공식mask를 읽거나
추론에 이용하지 않으며 새 pixel 성능을 계산하지 않는다.

현재 단일 후보를 정하는 데 기존 오류를 참고했으므로 전체 비교는 **탐색·회귀 검증**이다.
예전의 미사용 정상256장도 이제 점수와 일부 원본을 본 자료이며 새 독립 검증으로 부르지 않는다.
이 분리된 보정 절차는 직접적인 test 기반 수치 조정을 막지만, 연구 과정의 test 관찰 이력을 없애지는 않는다.

## 미리 정하는 판단 기준

다음 조건을 **모두** 충족할 때만 후속 확인 우선 후보로 분류한다. 서비스로 자동 채택하지 않는다.

- 기존 Q90이 검출한53장을 하나도 새로 놓치지 않으며, 기존 미탐2장 중1장 이상 추가 검출한다.
- 기존 정상54장의 오경보가3장을 넘지 않는다.
- 관찰된 정상256장의 오경보가14장을 넘지 않는다.
- 같은 실행에서 측정한 추가 공간 집계 계산시간이 전체 사진 점수 계산시간 합의10% 이하이다.
  이는 점수 연산의 비용 제한이지 현장 서비스 응답시간SLA가 아니다.

256장의 오경보5% 이하(12장 이하) 목표 충족 여부는 **별도로** 표시한다.14장 유지는 상대적 비악화일
뿐 이 목표 통과가 아니다. 표본의 촬영 상관과 사후 선택을 감안해 통계적 일반화나 생산 보증을 하지 않는다.

기준 미충족이면 결과를 보존하고 이 버전에서는 중단한다. 같은 시험에 맞춰 창 크기·q값·임곗값을
반복 조정하지 않는다. 성공하더라도 독립 자료 검증 없이 배포·자동PASS·생산성 개선을 주장하지 않는다.

## 시간·자원·저장

- 추론과 지도 전송은 두 점수 방법이 공유한다. 후보만을 위해 두 번째GPU 모델을 올리지 않는다.
- 실행은 한 장씩 처리한다. 전체 특징·map을 GPU에 계속 쌓거나 coreset을 다시 만들지 않는다.
- 타일별 공간 집계시간, 사진 점수 계산 평균/p95, 전체 중 추가 집계시간 비율을 기록한다.
  ZIP읽기·디코딩·추론·top1·공간 집계를 포함하고 모델로딩·정상점검·결과파일 저장은 제외한다.
- 중단·재개 시 여러 실행의 저장된 사진 시간을 합친 수치이다. 별도 정상점검의GPU peak와
  전체 실행의GPU/RAM peak를 혼동하지 않는다. 전체RAM peak는 이번에 측정하지 않는다.
- 결과ZIP은 점수·최고 창 위치·보정값·판정·시간·무결성 기록이다. 원본 이미지나 전체 지도는 복제하지 않는다.
- 완료된 사진은 무결성 확인 후 재사용한다. 실패한 임시 폴더와 기존 결과는 지우지 않는다.
  완료 후 재실행은 GPU 없이 기존 결과를 재검증한다.

## 연구실 실행

다른 GPU 작업이 끝난 뒤:

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_spatial_score.ps1'
```

원본은 기본 `Downloads\extracted.zip`, 모델은 기존
`artifacts\mpi-pcb-normal-bank-pilot-v1\fit\model.pt`다. 원본이 다른 곳에 있으면
PowerShell 명령 뒤에 `-Archive '원본ZIP의 실제 경로'`를 지정한다.

완료하면 다음 파일을 전달한다:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-spatial-score-v1.zip
```

오류가 나면 결과를 삭제하지 않고 오류 메시지를 전달한다. 같은 명령으로 완료된 사진부터 이어갈 수 있다.
