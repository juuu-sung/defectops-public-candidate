# MPI-PCB v2: 손상 이미지 재구성 후 두 모델 비교

상태: **연구실 실행 완료·첨부 결과 검증 완료** (2026-09-26).
Real-IAD PCB 모델은 TP 2 / FN 53 / FP 2 / TN 52,
VisA PCB3 모델은 TP 3 / FN 52 / FP 4 / TN 50이다.
AUROC는 각각 0.6212 / 0.5966으로, 두 모델 모두 이 외부 자료에서 대부분 놓쳤다.
복구 사진 제외 108장에서도 TP는 1 / 2장, FN은 53 / 52장이다.
v2 ZIP SHA-256은 `768714d947673b1b03f91782de802ce33f8796c21af582a5e5e078d172e2315e`.
JSON 해시·분모·판정·AUROC/AP·짝지은 비교·민감도 분석·정상 replay를 재검산했다.
정상 replay 차이는 0.0이며, 공식 원본에서 다시 만든 복구 픽셀과 PNG 해시도 일치했다.
**아래 실행 절차는 완료된 v2의 기록이다. 다시 실행하지 않는다.** 다음 작업은
[저장 맵 원인 진단](mpi-pcb-map-diagnostics.md)이며, 모델·임곗값은 유지한다.

## 이번에는 무엇을 해결하나요?

v1은 모델 고장이 아니라 시험 데이터의 손상·중복 때문에 점수 계산 전에
멈췄다. 그 중단 기록은 그대로 보존한다. 사용자의 결정에 따라 실험을
포기하지 않고 아래 세 문제를 각각 처리한 **별도 v2**를 실행한다.

| 문제 | v2 처리 | 평가 대상에 미치는 영향 |
| --- | --- | --- |
| `defect/0054`의 `grid1-3` 이미지 손상 | 공식 정렬 원본에서 같은 변환으로 파생 PNG 생성. 나머지 11영역 RGB가 기존 기록과 정확히 같아야 사용 | 불량 55장 모두 유지 |
| `defect/0006`의 `grid3-2` 마스크 손상 | 위치 평가 불가로 표시. 정상/불량 정답은 공식 폴더 분류 사용 | 사진 자체는 이미지 판정 평가에 포함 |
| `good/0013`이 보정 `0866`과 12영역 모두 동일 | 시험 집계에서 이 정상 사진 한 장만 제외. 보정·임곗값 유지 | 정상 55→54장 |

주 평가 대상은 **정상 54장 + 수동 변형 55장 = 109장**이다. 원래의 55/55
시험과 같다고 주장하지 않는다. 제외/복구/위치평가 불가 사유와 원래 분모를
함께 보고한다. 다른 오류가 나오면 자동으로 제외 범위를 늘리지 않는다.

## 손상 이미지를 어떻게 복구하나요?

[공식 Zenodo 메타데이터](https://zenodo.org/api/records/8213098)에서
`original_aligned.zip`(5,451,602,482바이트)을 확인했다. HTTP Range로 목록과
필요한 멤버만 읽으며 실측 전송량은 **4,222,589바이트**다. 전체 5.45GB를
받지 않는다. 서버가 부분 요청 대신 전체 파일을 보내면 즉시 거부한다.

원본은 `original_aligned/test/defect/IMG_0056.JPG.jpg`, 3,989,266바이트,
RGB 4096×2816 JPEG다. 원본 번호에 누락이 있어 번호만으로 대응을 정하지
않았다. 아래 변환으로 **11개 온전한 영역 모두의 RGB SHA-256 일치**를 확인했다.

- 가로 시작점 `(grid_x - 1) × 1024`, 세로 시작점 `(grid_y - 1) × 896`.
- 1024×1024를 잘라 256×256으로 4배 축소한다.
- half-pixel 중심 bilinear, antialias 없음. 각 출력 픽셀은 해당 2×2 입력
  픽셀의 합에 2를 더해 4로 정수 나눗셈한다. uint16 합으로 넘침을 막는다.
- 11영역 중 하나라도 기존 RGB 해시와 다르거나 재구성 영역의 고정 RGB
  해시가 다르면 추론 전에 중단한다. Windows 디코더 차이도 자동 수용하지 않는다.

AI로 결함 부분을 채우거나 새로 그리는 작업이 아니다. 공식 정렬 원본을
같은 변환으로 재구성한다. 다만 손상 PNG의 독립적인 정상 사본을 확보한 것은
아니므로 **검증된 파생 대체 이미지**라고 명시한다.

| 검증 항목 | SHA-256 |
| --- | --- |
| 공식 정렬 원본 멤버 | `126cf49bf0dedd8ba012a42a10c026240b5a8c0dd0d78ace293a50ce537a8845` |
| 손상된 기존 PNG | `3afef0d2f99ea390dc2e6b455630128c3a026feab03bc3929d278f2aa468ad1b` |
| 재구성된 RGB 픽셀 | `7ac16f5e75932c4eebe6ada691be04464272fa75125c5393393dad04bd7d54af` |

원본 ZIP은 수정하지 않는다. v2 출력의 `recovery/`에 공식 원본 한 장과
재구성 PNG를 따로 보관하고 읽을 때 해당 멤버 하나만 대체한다. 공식 원본
멤버의 ZIP CRC와 SHA-256은 확인하지만, **전체 정렬 ZIP을 받지 않았으므로
그 ZIP 전체의 MD5를 검증했다고 주장하지 않는다.** 기존 `extracted.zip`의
전체 MD5·SHA-256 검증은 연구실에서 그대로 수행한다.

### 복구 한 장 때문에 결론이 바뀌지 않나요?

결과를 두 가지로 모두 보고한다.

1. 주 평가: 정상 54 + 불량 55 = **109장**, 복구 사진 포함.
2. 사전 지정 민감도 분석: 정상 54 + 불량 54 = **108장**, 복구 사진만 제외.

모델·임곗값·나머지 사진은 같다. 좋은 수치만 골라 최종 결과로 보고하지
않는다. 복구 사진의 점수와 판정도 모델별로 따로 제시한다. 위치 지표는
계산하지 않으며 마스크 손상 사진은 위치 평가 불가로 계속 표시한다.

## 유지하는 것과 실행 순서

- 기존 두 checkpoint·정상 169장 명단 유지. 재학습 없음.
- Real-IAD 임곗값 **67.42196179599297**, VisA 임곗값 **66.18967593588481** 유지.
- 영역 상위 1% 이상 맵 평균 → 12영역 최댓값 → 사진 한 장 판정 규칙 유지.
- v1 handoff ZIP SHA-256
  `cee3ff8d11bf73df7c0128869449e2cfd29b20230fedb0a17a51651710f6cfa1`부터 검증한다.
  시험 점수가 0인 검토된 중단 기록이 아니면 진행하지 않는다.
- 원본·checkpoint·보정 보고서 검증 → 공식 원본 부분 다운로드·11영역 검증
  → 복구 이미지로 시험 파일 전체 재감사 → 승인한 세 처리만 적용
  → 정상 169장×12영역을 모델별로 재현 → 고정 임곗값으로 동일 109장 평가.
- 정상 재현 최대 차이 허용치는 이전과 같은 0.0001이다. 초과 시 시험 점수
  계산 전에 중단한다. 임곗값을 다시 계산하거나 바꾸지 않는다.
- 시험 내용은 이미 v1 감사에서 열었다. 다시 봉인됐다고 표현하지 않는다.
  변경 규칙은 시험 점수 관찰 전에 잠갔다. 정상 데이터 적응이 있어 zero-shot도 아니다.
- Wilson/짝지은 bootstrap은 사진 단위 기술적 요약이다. 한 기판의 반복 촬영·
  수동 변형이므로 현장 제조 불량 일반화 검증·생산 자동 합격 근거가 아니다.

## 연구실 Windows에서 할 일

GPU 검사 서버가 실행 중이면 **그 서버 터미널에서만** Ctrl+C로 종료한다.
기존 ZIP·v1 보고서·checkpoint·가상환경을 삭제하거나 교체하지 않는다.
인터넷 연결이 필요하지만 대용량 파일을 수동 다운로드할 필요는 없다.

```powershell
Set-Location "C:\개인 프로젝트\defectops"
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw "Git update failed. Stop and share the error." }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_mpi_pcb_external_evaluation_v2.ps1"
```

정상 완료 상태: `mpi_pcb_external_evaluated_integrity_amended_v2`.
완료 또는 중단 후 생성된 아래 파일을 첨부한다.

`C:\개인 프로젝트\defectops\artifacts\handoff\mpi-pcb-external-evaluation-v2.zip`

복구용 네트워크 요청·입력 검증처럼 출력 폴더 생성 전 실패는 ZIP이 없을 수 있다.
이 경우 오류 문구를 공유한다. 결과 폴더가 이미 있다면 지우지 않는다.
네트워크 실패 시 손상 사진을 자동 제외하는 대안으로 바꾸지 않는다.

정상 재현은 두 모델 합계 4,056영역, 시험은 2,616영역 추론이다. 학습은 없지만
GPU 계산 시간이 들며 정확한 소요시간은 아직 실측하지 않았다. 원시 이상 맵은
비압축 float32 기준 약 654MiB이며 실제 압축 크기는 달라진다. 인계 ZIP은
복구 근거·명단·감사·점수·성적표 JSON만 담고 이미지·마스크·맵·모델은 넣지 않는다.
