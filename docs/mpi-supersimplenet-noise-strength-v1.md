# SuperSimpleNet 합성 잡음 강도 제한 비교

2026년 10월 5일 사용자 승인 후 고정한 정상 전용 진단이다. 목적은 **합성 이상이 너무 약해서 학습하지 못하는지**를 좁히는 것이다. 실제 결함 성능 개선이나 서비스 모델 선택을 하는 실험이 아니다.

직전 [위치와 잡음을 바꾸는 실험](../reports/mpi-supersimplenet-varying-synthetic-v1-received-review.md)은 500회 학습을 완료했지만, 학습에 넣지 않은 합성 난수에서 추론 픽셀 AUROC가 0.5035로 약했다. 잡음 강도가 원인이라는 결론은 아직 없다. 이번에는 학습 조건 중 강도 하나만 변경한다.

## 고정 조건과 비교 대상

| 항목 | 조건 |
| --- | --- |
| 입력 | 이전과 같은 정상 원본 **한 사진의 8개 영역 타일**. 정상 사진 8장이 아님 |
| 시작 모델 | 기존 정식 300 epoch 최종 모델의 각각 새 복사본 |
| 업데이트 | 새 후보별 500회. 0.03 결과를 0.06에 이어 쓰지 않음 |
| 학습 대상 | adaptor와 segmentation/classification head. backbone 고정 |
| optimizer | 기존과 같은 새 AdamW. adaptor LR 0.0001/WD 0.01, head LR 0.0002/WD 0.00001 |
| 배치 | 입력 8타일, 공식 합성 단계의 복제 후 16개 |
| 합성 위치와 난수 | 공식 anomalib 2.2.0, Perlin 0.6, 평균 0. 학습 seed 10000부터 10499까지 |
| 기준 모델 | 직전 varying500, 표준편차 0.015. 재학습 없이 읽기 전용 검사 |
| 새 후보 | 표준편차 0.03과 0.06. 기존의 2배와 4배 |
| 평가 난수 | 900001부터 900004까지 평균, 참고 42는 별도. 모두 학습 seed와 분리 |
| 기록 시점 | 0, 100, 300, 500회. 기록 간격만 줄이며 학습률·업데이트 수는 유지 |
| 자동 선택 | 없음. 중간 성적으로 조기 종료·연장·잡음 재선택을 하지 않음 |

잡음은 이미지에 칠하는 것이 아니라 **현재 adaptor를 거친 특징에** 더한다. 특징 자체의 크기를 정규화하거나 잡음 크기에 맞춰 다시 조정하지 않는다. 모델마다 학습 후 특징 크기가 달라질 수 있으므로 실제 잡음 RMS와 같은 위치의 정상 특징 RMS 비율도 기록한다.

평가용 난수는 이번 학습에 넣지 않지만 이미 직전 결과를 본 난수다. 독립 검증용 새 데이터라고 주장하지 않는다. 같은 사진의 영역들·같은 타일의 합성 반복도 독립 제품 표본으로 세지 않는다.

## 왜 모든 모델에 같은 세 강도를 검사하는가

강한 잡음으로 학습하고 강한 잡음에서만 평가하면 검사가 쉬워졌을 뿐인데 모델이 좋아진 것으로 오해할 수 있다. 그래서 기준 모델과 두 후보 모두 **0.015, 0.03, 0.06**을 검사한다. 각 시점 3강도 × 5난수이며 최종 재로딩에서도 같은 조건을 재현한다.

가장 먼저 볼 것은 **원래 난이도인 0.015에서의 변화**다. 강한 잡음에서만 좋아지면 그 합성 문제는 배울 수 있다는 근거일 뿐이다. 실제 불량 회귀검사로 자동 확대하지 않는다.

각 비교에 합성 전 정상 특징을 그대로 넣은 대조군을 함께 둔다. 픽셀 AUROC만 높아져도 정상 대조의 같은 위치가 함께 높으면 위치 암기나 정상 외관 효과가 남은 것이다. 다음을 묶어서 판단한다.

- 사진·픽셀 AUROC와 학습 모드/추론 모드 차이
- 같은 원본의 정상 대조 대비 사진 점수 변화
- 같은 위치의 정상/합성 점수 구분력과 지도 변화
- 정상 지도에서 합성 위치만 빌려 계산한 대조 AUROC
- 위치 focal, 위치 truncated L1, 분류 focal 손실 및 부위별 gradient
- 실제 잡음 RMS, 특징 RMS, 마스크 밖 변화 0 여부

0 logit은 이 진단의 부호 관찰용이며 실제 서비스 경고 기준이 아니다. 작은 실험 결과에 사후 합격선을 붙이지 않고 세 후보의 모든 결과를 보고한다.

## 실행 순서와 보호 장치

1. 기존 정식 fit·고정500·varying500 폴더와 각각의 검토된 handoff를 검증한다. 입력 사진·코드·공식 구현·체크포인트의 기존 해시를 확인한다.
2. varying500 기준 모델을 세 강도로 평가하고, 0.015 결과가 직전의 다섯 난수 결과와 최대 절대차 0.0001 이내로 일치하는지 검사한다.
3. 정식 모델의 새 복사본으로 0.03을 500회 학습한다. 매 업데이트의 합성 마스크가 직전 varying500의 동일 step과 일치해야 한다.
4. 정식 모델의 새 복사본으로 0.06을 별도로 500회 학습한다. 0회 상태도 이전 정식 모델의 점수와 재현 대조한다.
5. 각 최종 모델을 다시 불러와 세 강도와 다섯 난수의 원시 지도·점수를 재현한다. 체크포인트는 연구실에 남기고 근거 수치만 ZIP으로 묶는다.

평가는 가중치·BatchNorm buffer·난수 상태를 복구하고 잡음 설정도 예외 발생 여부와 관계없이 원복한다. 원본 및 기준 모델은 덮어쓰지 않는다. 고정 checkpoint의 목적·실험 식별·후보명·표준편차·optimizer step을 검증해 후보 간 잘못된 재개를 막는다.

## 시간과 중단 조건

새 업데이트는 총 1,000회다. 직전 500회 전체 실행은 약 3분 12초였지만 이번에는 교차 평가와 잡음 측정이 늘어난다. 소요 시간은 연구실에서 확인하며 **누적 실행 45분, RAM 20 GiB, PyTorch GPU reserved 6 GiB**를 상한으로 둔다. 실행 전 디스크 여유 16 GiB와 GPU 여유 6 GiB가 필요하다. 디스크 상한과 GPU 전체 사용량은 별개이며 다른 GPU 작업을 정상 종료한 뒤 실행한다.

정상적인 Ctrl+C 중단은 완료된 체크포인트부터 같은 난수 순서로 이어갈 수 있다. 재실행한 계산 시간도 누적하며 미완료 구간 재처리를 포함해 총 시도 업데이트 1,200회가 한계다. 강제 종료, checksum 불일치, 자원 초과, 기타 실패는 자동 재시도하지 않고 검토를 요구한다. 제한을 맞추려고 크기·잡음·배치를 자동 축소하지 않는다. 기존 출력은 삭제하지 않는다.

원본 ZIP은 기본 `Downloads\extracted.zip`이다. 정상 종료 후 전달할 파일:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-noise-strength-v1.zip
```

기존 fit·learnability·varying 폴더 및 handoff ZIP을 유지한다. 새 결과는 `artifacts/analyses/mpi-supersimplenet-noise-strength-v1`에 보관한다. 오류가 나면 결과를 지우지 말고 오류를 전달한다.

## 결과에 따른 다음 판단

- 원래 0.015에서도 paired 정상 대조와 위치 구분이 함께 좋아지면, 그 조건을 더 다양한 정상 사진에서 확인할 별도 실험을 설계한다.
- 강한 잡음에서만 좋아지면 약한 신호에 대한 표현·손실 문제가 남아 있다. 실제 결함 성능 개선으로 발표하지 않는다.
- 모든 강도에서 분리가 약하면 데이터·epoch를 크게 늘리기보다 손실, gradient, train/eval 경로의 원인을 점검한다.

어느 경우든 실제 불량 시험·경고 기준 변경·Q90/서비스 모델 교체는 이번 실행에 없다. CPU 제어 테스트 통과와 실제 CUDA 실행 성공은 별도다.

공식 구현 근거: [anomalib 2.2.0 AnomalyGenerator](https://github.com/openvinotoolkit/anomalib/blob/v2.2.0/src/anomalib/models/image/supersimplenet/anomaly_generator.py). 설치된 소스는 기존 사전 고정 SHA256으로 검증한다.
