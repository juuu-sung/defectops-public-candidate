# SuperSimpleNet 미탐 지도 비교와 학습량 점검

2026-10-05. 정식300epoch 모델은 고정 불량12장을 모두 놓쳤다. 이번에는 저장된 지도로
결함 위치 반응과 사진 분류 점수를 구분해 확인한다. 새 학습·새 추론·임곗값 변경은 하지 않는다.
학습량 확대는 별도 설계 제안이며 이번 명령에 포함하지 않는다.

## 확인할 사례와 질문

- 고정 미탐12사진: 원본·공식 결함 위치·SSN 원시 지도·상위656픽셀 위치를 비교한다.
- 정상8사진: 개발128·보정169에서 분류 점수가 높은 사진을 각각3장, 보정 경고선 사진1장과
  중앙 점수 사진1장을 선택한다. 전체 명단과 동점 처리 규칙을 고정한다.
- 미탐12사진의 기존 Q90 저장 지도가 있으면 같은 타일에 나란히 표시한다.
  누락은 미비교로 명시한다. 파일이 있는데 손상되거나 지문이 다르면 중단하며 새 추론으로 대체하지 않는다.

결함 위치의 평균·최대 반응, 타일 내 AUROC와 상위656픽셀 겹침 범위를 기록한다.
동점 경계는 모든 동점을 그림에 표시하고 수치는 가능한 겹침 범위로 표현한다.
이는 선택 사례의 위치 진단이지 전체 Pixel AUROC나 새로운 모델 성능이 아니다.
지도 반응이 있다는 사실만으로 분류 head가 유일한 원인이라고 확정하지 않는다.

## 지도와 분류 점수의 구분

SSN 사진 판정은 분류 head의 원점수로 유지한다. 원시 위치 지도의 최대값으로 바꾸지 않는다.
SSN 지도는 모든 사례에서 -1~1 고정 색상 범위를 쓰며 범위 밖은 색만 포화된다.
Q90은 타일 안 반응 순위를 따로 표시한다. 두 모델의 색 강도를 직접 비교하면 안 된다.
Q90 원래 반응 수치와 위치 통계는 별도로 기록한다. 평평한 지도는 모두 같은 색으로 표시한다.

0006은 기존 손상 마스크 예외로 사진 전체 위치 지표를 제외한다. 정상 사례에는 결함 위치
통계를 만들지 않는다. 0054는 기존에 승인한 복구 파일의 바이트·픽셀 해시를 검사해 사용한다.
그 밖의 불량 이미지·마스크는 읽지 않는다. 결과는 탐색적 원인 진단이며 자동 합격·원인 확정·서비스 교체가 아니다.

CPU 전용이며 GPU 대기나 패키지 추가 설치는 필요 없다. 다만 같은 학습·평가 폴더를 쓰는 작업은
동시에 실행하지 않는다. 디스크 여유1GiB가 필요하다. 기존 원본·fit·evaluation·handoff·복구 파일을 유지한다.

## 학습량을 늘리는 두 가지 다른 방법

최근 MPI 실험에서 정상 원본64장은12영역으로 나뉘어768타일이 되지만,
독립 촬영된 사진768장을 확보한 것과 같지 않다. 각 영역이 본 원본 사진은64장이다.
현재 SSN은 이를300epoch 반복해28,800번 업데이트했고 입력 타일 노출은230,400회다.
합성 특징은 반복마다 달라질 수 있지만 새로운 실제 촬영 조건을 추가한 것은 아니다.

[원 SuperSimpleNet 논문 구현 조건](https://arxiv.org/html/2408.03143v1#S4.SS3)은300epoch와
batch32를 사용한다. 현재는 GPU 제약으로batch8이며 데이터·구현 조건도 다르므로 논문 성능
재현이라고 주장하지 않는다. 300epoch라는 이유로 충분함이 보장되지는 않지만, 반복 횟수가
명백히 작은 점검 학습만 한 것도 아니다. 학습 손실은 최초10epoch1.2030에서 최종10epoch1.0560으로
낮아졌으나 후반 개선은 작다. 이는 합성 이상 학습 과제의 변화이며 실제 결함 성능의 보장이 아니다.

EfficientAD는 같은 MPI 정상64사진의 타일을70,000회 업데이트했다. SSN의batch8과 달리batch1이므로
업데이트 숫자만 직접 비교하지 않는다. PatchCore·PaDiM은 이 신경망처럼 epoch를 늘려 같은 방식으로
최적화하는 모델이 아니다. 정상 특징의 구성·수량·대표 특징 선택과 비용을 검토해야 한다.
다른 품목·데이터셋을 한꺼번에 섞는 것은 단순 학습량 증가가 아니라 학습 대상 자체의 변경이다.

## 지도 진단 후 검토할 확장 설계

다음은 실행 확정이 아닌 제안이다. 64장으로 정상 변화를 충분히 배웠다고 단정하지 않으며
새 정상 자료를 늘리는 실험은 가치가 있다. 반대로 데이터 부족이0/12의 원인이라고 아직 확정할 수 없다.

1. 원시 지도까지 결함 반응이 약한지, 지도와 분류 점수 사이에 차이가 있는지 먼저 구분한다.
2. 추가 정상 자료 효과를 보려면 기존64장을 포함한256장 후보를 미사용 정상 학습 풀에서 고정 선택한다.
   손상·중복 픽셀·사진 단위 겹침을 다시 감사한다. 개발128·보정169·시험·별도정상 검증256장은 넣지 않는다.
   적격 사진 수를 확인하기 전에는256장 확보를 확정하지 않는다.
3. 계산량을 맞춘1차 비교라면256사진×12영역, batch8에서75epoch가28,800회 업데이트다.
   기존64장300epoch와 입력 타일 노출량을 맞춰 다양성과 반복의 배분을 비교한다.
   학습률 변경 시점도 epoch가 아니라 동일 업데이트 시점으로 사전에 고정해야 한다.
   단, 반복 수 감소가 함께 발생하므로 순수한 데이터 수의 인과효과라고 과장하지 않는다.
4. 데이터와 반복을 함께 확대해256장300epoch를 쓰면115,200회로 현재의4배 업데이트다.
   이는 계산 예산도 새로 승인해야 할 실험이며, 기존4시간 제한을 몰래 늘리거나 재시도로 우회하지 않는다.

모든 후보는 같은 구조·전처리·명단과 사전 결정한 회귀 기준으로 비교한다. 같은64장의 epoch만
600으로 늘리는 비교는 가능하지만 후반 손실만으로 효과를 보장할 수 없고, 우선순위는 지도 진단에 따라 정한다.
기존 시험은 이미 본 자료이므로 이후 결과도 탐색·회귀검증으로 제한한다. 기존 Q90과 서비스는 유지한다.
