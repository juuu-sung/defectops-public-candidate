# MPI 공간 평균 미탐6장 진단 v1

작성일: 2026-09-30. 상태: 진단 코드 준비, 실제72영역 재추론·정답 중첩 결과는 연구실 실행 대기.

## 목적과 범위

[공간 집계 수령 결과](../reports/mpi-spatial-score-v1-received-review.md)는 기존Q90 대비
검출53→49장, 기존 정상 오경보3→5장, 관찰 정상 오경보14→15장으로 악화됐다.
이번에는 다음 여섯 사진만 고정해 **결함 반응이 점수 집계에서 약해지는지, 결함 자체의 반응이
다른 정상 부위보다 약한지** 확인한다. 새 학습·새 점수 후보·임곗값 최적화가 아니다.

| 구분 | 사진 |
| --- | --- |
| 기존에도 놓친 불량 | defect/0019, defect/0024 |
| 공간 평균에서 추가로 놓친 불량 | defect/0021, defect/0027, defect/0028, defect/0047 |

각 사진의12영역, 합계72타일을 모두 본다. 주요 카드는 기존Q90 최고점 영역으로 고정하며,
결함 정답으로 좋은 위치를 골라내지 않는다. 두 방식의 최고점 영역이 다르면 JSON/HTML에
각각 표시한다. 이번 대상에는 알려진 복구 이미지0054·손상mask0006이 포함되지 않는다.

## 진행 순서

1. 이전 공간 집계ZIP 및 관련 전달물, 원본ZIP·checkpoint의 고정 해시와 입력 명단을 확인한다.
2. 정상8장 실행 점검과 기존 저장모델 reload 환경 대조를 통과한 뒤 진행한다.
3. 6장의12영역을 같은 모델로 추론해 top1/native/window26 원점수, 최고 창 좌표, 고정 판정을 재현한다.
   원점수 차이1e-4 초과, 창 좌표 변경, 판정 변경은 중단한다. 최고 창 동점은 기존 행우선 규칙이다.
4. 점수 검증 후 공식 결함mask를 읽어 원본/디코딩 기록을 확인한다. mask는 추론·창 선정·기준에 쓰지 않는다.
5. 전체 지도와mask를 저장하고 기존상위1%·공간창의 정답 중첩, 점수 기여, 결함/배경 통계를 계산한다.
6. 사진당 전체영역 카드2장과 주요영역 카드1장, 합계18장 및 로컬HTML·JSON·NPZ를 전달한다.

기존 Q90 기준2.3169610768645974와 후보 기준2.123865555187808 모두 그대로다. 서로 다른
점수 체계이므로 각자 기준 대비 차이를 본다. 정상 개발128/보정169장 계산은 전달 점수의
정합성 검산만 수행하고, 이들을 다시 추론하거나 보정값을 바꾸지 않는다.

## 무엇을 볼 수 있는가

카드 왼쪽부터 원본+정답(초록), 고정척도 이상 지도, 상위1% 반응(빨강), 최고26×26 창(파랑).
색상은 기존 표시 척도로 고정하며 포화될 수 있다. 빨강/파랑은 픽셀 불량 판정이 아니다.

- 기존 점수에 포함된 정답 픽셀 비율: top1 cutoff 동점은 가능한 최소–최대 범위로 표시.
- 창에 포함된 정답 픽셀 비율: 창 밖으로 결함 반응이 빠졌는지 확인.
- 창 점수 합 중 정답 기여와 창 안 정상배경 평균: 결함과 배경이 얼마나 섞이는지 확인.
- 영역 전체의 정답/배경 평균·최댓값·순위AUC: 결함 반응이 다른 정상 부위보다 약한지 확인.
- 두 점수의 정규화 값·고정 경고 기준과 차이·원점수 경계.

정답이 없는 영역의 정답 포함률, 점수 합0의 기여율 등 정의 불가능한 값은null로 남긴다.
기여율과 포함률은 고정 픽셀 임곗값 성능이 아니고 선택된6장의 순위AUC도 전체 새 성능이 아니다.
단일 원인을 자동으로 분류하지 않는다. 집계 손실과 약한 특징 반응이 동시에 있을 수 있다.
이 작업은 학습memory bank의 최근접 패치를 새로 추적하지 않으므로, 특정 정상패치 오매칭이나
학습자료 부족을 이 결과만으로 확정하지 않는다. 그런 추가 진단은 이 근거를 보고 별도 결정한다.

## 저장·안전성

기존 모델·기준·원본·이전 결과를 덮어쓰지 않는다. 완료된 사례는 입력·출력·실행gate 해시를
확인하고 지도/mask에서 통계를 재계산한 뒤 재사용한다. 중단 후 같은 명령으로 이어갈 수 있다.
모든 사례가 완료된 뒤 재실행하면 GPU 없이 검증·결과 재전달만 한다. 실패자료는 삭제하지 않는다.
결과ZIP에는72개 지도와mask를6개NPZ로 포함하므로 맥북에서 중첩 통계를 재검산할 수 있다.
원본 전체는 복제하지 않는다. 카드는MPI-PCB 출처·라이선스·파생 표시를 유지한다.

## 연구실 실행

다른GPU 작업 종료 후 PowerShell에서 실행한다. 원본 기본경로는Downloads\\extracted.zip이다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_spatial_miss_review.ps1'
```

다른 원본 경로는 마지막 명령에 `-Archive '실제 원본 ZIP 경로'`를 붙인다.
완료하면 전달할 파일:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-spatial-miss-review-v1.zip
```

연구실에서 직접 결과를 보려면:

```powershell
Start-Process '.\artifacts\analyses\mpi-spatial-miss-review-v1\result\index.html'
```

이 HTML은 설명용 읽기 화면이다. 검토 의견 저장·티켓·모델 승격 기능은 없다.
오류가 나면 결과를 삭제하지 않고 오류 메시지를 전달한다.

## 이번 결과를 받은 뒤

여섯 사례를 근거로 집계 손실·결함 반응 부족·복합 양상을 정리한다. 근거가 부족하면 그대로
미확정으로 기록한다. 창 크기를 연속 탐색하지 않고 다음 변경 하나의 필요성과 비용을 판단한다.
이미 본 자료의 사후 진단이므로 새로운 일반화 성능이나 생산 자동합격 근거가 아니다.
