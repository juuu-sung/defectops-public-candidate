# SuperSimpleNet 특징 변환부 시작 상태 대조 v1

이번 질문은 **“정식 학습을 마친 특징 변환부 때문에 새로운 합성 이상을 배우기 어려운가?”**이다.
정상 사진 수나 학습 시간을 늘리기 전에, 다른 조건을 맞춘 두 모델로 이 영향을 분리한다.
기존 모델을 교체하는 정식 학습이나 실제 불량 검사가 아니다.

## 비교하는 두 조건

모델은 이미지에서 특징을 추출한 뒤, 특징 변환부(adaptor)로 검사에 사용할 표현을 만들고,
검출부(segdec)로 위치 지도와 이미지 점수를 계산한다. 합성 잡음은 특징 변환 뒤에 넣는다.

| 항목 | A: trained_adaptor | B: initial_adaptor |
| --- | --- | --- |
| 특징 추출기(backbone) | 보존된 정식 학습 0단계, 고정 | A와 동일 |
| 특징 변환부 시작 상태 | 정식 학습 완료 28,800단계 | 보존된 정식 학습 0단계 |
| 위치·분류 검출부 시작 상태 | 보존된 정식 학습 0단계 | A와 동일한 가중치·BatchNorm 버퍼 |
| 최적화 상태 | 학습 이력이 없는 새 AdamW | A와 동일 |
| 제한 학습 | 변환부와 검출부 500회 업데이트 | 동일한 조건으로 500회 |

여기서 ‘새 검출부’는 실행할 때 새 난수를 뽑는다는 뜻이 아니다. 이미 저장된 **학습 전 검출부**를
두 모델에 똑같이 복사한다. 두 조건 모두 특징 변환부와 검출부를 업데이트한다.
따라서 비교 대상은 변환부의 고정된 표현만이 아니라 **시작 상태가 이후 학습에 미치는 영향**이다.
이전 검출부 초기화 실험의 다른 난수 초기화 모델과는 별도 비교다.

## 이 단계로 넘어온 근거

[첫 업데이트 차이 점검](mpi-supersimplenet-update-audit-v1.md)의 두 난수 조건에서
Anomalib 반복 실행과 동일 손실을 쓰는 독립 계산 경로의 출력·손실·기울기·업데이트가 일치했다.
저자 방식의 손실 표현과의 미세 차이는 따로 보존한다. 이번에는 손실을 바꾸지 않는다.
이 근거는 한 정상 사진의 8타일에 한정되며 전체 구현·실제 결함 성능을 보증하지 않는다.

실행기는 수령·검토한 `mpi-supersimplenet-update-audit-v1.zip`의 SHA256
`e2300535f78dc88c892162e2c06c5e829d1187a4485c36823c3f268cdbf5a179`와
원본 정식 학습 ZIP, 시작 전·완료 checkpoint, 기존 보정 결과를 확인한다.
조건이 맞지 않으면 다시 학습하거나 입력을 바꾸지 않고 중단한다.

## 고정 조건

- 자료: 정식 학습에 사용한 첫 정상 사진 `1073`의 첫 8영역. 새 사진·불량·시험 마스크는 열지 않는다.
- 입력: RGB 256×256, 기존 ImageNet 정규화. frozen WideResNet50_2의 layer2·3을 사용한다.
- 학습: 조건별 500회, 합계 1,000회. 정상 8타일에서 공식 생성기로 유효 batch 16을 만든다.
- 합성 이상: Anomalib 2.2.0 생성기, 잡음 표준편차 0.015, Perlin 기준 0.6, 현재 변환부 출력에 추가한다.
- 학습 난수: 업데이트 번호에 따라 10000~10499. 두 조건의 마스크·라벨 해시를 비교하고 바뀌면 중단한다.
- 손실: Anomalib 2.2.0 `SSNLoss`, 공식 학습 forward 그대로 사용한다.
- 최적화: adaptor 학습률 0.0001·weight decay 0.01, 검출부 학습률 0.0002·weight decay 0.00001.
  학습률 스케줄러와 혼합 정밀도는 사용하지 않는다.
- 저장 시점: 0, 50, 100, 200, 300, 400, 500회. **주 비교는 500회이며 가장 좋은 중간 모델을 고르지 않는다.**

변환부가 다르면 특징 크기도 달라질 수 있다. 잡음의 절대 표준편차는 같게 두며 특징 크기에 맞춰
잡음을 재조정하지 않는다. 시작·종료 시 변환 전후 평균·RMS·표준편차를 남겨 해석에 사용한다.

## 무엇으로 비교하는가

각 저장 시점에 난수 42, 900001~900004의 다섯 합성 문제를 검사한다.
주 요약은 이번 학습에 사용하지 않은 네 난수 900001~900004이다. 이 난수들은 과거 진단에서
관찰한 조건이므로 새로운 독립 시험이 아니라 **학습에서 제외한 고정 회귀 조건**이다.

1. **새 합성 이상 구분력:** 합성 이상 유무와 위치를 점수로 구분하는 AUROC를 본다.
2. **같은 위치의 정상 대조:** 동일 이미지·동일 위치에서 잡음을 넣기 전과 후의 반응을 비교한다.
   정상에도 같은 위치가 뜨면 위치를 외운 것일 수 있으므로 지도 AUROC만으로 성공이라 하지 않는다.
3. **학습·추론 모드 차이:** 두 모드의 지도·점수·손실을 모두 기록한다. 검사 자체가 모델 버퍼를 바꾸지 않는지도 확인한다.
4. **재현:** 모델 저장·재로딩 후 다섯 난수의 원시 결과를 다시 비교한다. 최대 절대 차이 허용값은 0.0001이다.
5. **원본 보존:** 정식 모델·기존 경고 기준의 해시가 실행 전후 같은지 확인한다.

합성 지도는 64×64 특징 격자의 진단이다. 픽셀값 0을 기준으로 계산한 정상 반응 비율은
진단용 수치이지 새 서비스 경고 기준이나 실제 정상 오경보율이 아니다.
두 조건의 차이와 시작 대비 변화, 난수별 편차를 함께 읽는다. 단일 평균의 작은 상승만으로
원인을 확정하지 않으며, 자동 합격·자동 모델 선택·다음 단계 자동 실행은 하지 않는다.

## 연구실 Windows 실행

다른 GPU 작업은 정상 종료하고 기존 학습 폴더와 모든 handoff ZIP을 유지한다.
기본 원본은 `$env:USERPROFILE\Downloads\extracted.zip`이며 실제 사용자 폴더는 자동으로 찾는다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git 업데이트 실패. 학습을 시작하지 않습니다.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_adaptor_start.ps1'
```

원본 ZIP이 다른 위치에 있으면 실행기에 `-Archive '실제 ZIP 경로'`를 지정한다.
정식 학습 환경과 라이브러리·SuperSimpleNet 소스가 같은지 먼저 확인하며 네트워크 가중치 다운로드는 하지 않는다.

이번 실행에는 **경과 시간 상한이 없다.** 다만 다음 보존 장치는 유지한다.

- 시작 전 GPU 여유 6GiB, 디스크 여유 8GiB 확인.
- 실행 중 프로세스 RAM 20GiB·PyTorch GPU reserved 6GiB 상한.
- 조건별 완료 500회 유지. 정상 중단 후 미저장 구간 재연산을 포함해 최대 시도 1,300회.
- 메모리 초과 시 batch·자료·잡음을 자동 축소하지 않는다.

Ctrl+C로 정상 중단하면 같은 명령으로 저장 시점부터 재개한다. A가 끝났다면 A를 다시 학습하지 않고
저장 결과를 재검증한 뒤 B를 이어간다. 미저장 업데이트만 같은 난수로 재연산하며 시도 수에 합산한다.
실패 오류나 강제 종료 흔적은 자동 무시하지 않는다. 이때는 폴더를 삭제하거나 이름을 바꿔 재시도하지 말고
오류 메시지를 전달한다. 이미 완성된 결과를 다시 실행하면 기존 파일을 검증하고 그대로 반환한다.

## 결과와 다음 판단

학습 모델은 `artifacts\analyses\mpi-supersimplenet-adaptor-start-v1` 아래 두 조건별로 보존한다.
전달용 ZIP에는 원본 사진·학습 모델을 넣지 않고 계획, 초기 상태 기록, 손실 이력, 지도·점수 배열,
원본·산출물 해시와 재로딩 검증 결과를 담는다.

완료 후 전달할 파일:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-adaptor-start-v1.zip
```

| 관찰 결과 | 다음 판단 |
| --- | --- |
| B가 A보다 새로운 합성 난수와 정상 대조에서 일관되게 우수 | 학습된 변환부 시작 상태의 영향을 의심하고, 별도 정상 사진에서 작은 일반화 점검 설계 |
| 두 조건 모두 구분력을 확보 | 더 많은 정상 사진으로 재현되는지 확인 후 다양성 확대 판단 |
| 두 조건 모두 약하거나 정상 위치 반응만 상승 | 시작 상태만으로 해결되지 않음. 장시간 학습 확대보다 합성 학습 신호·표현 조건 재검토 |
| 구현·입력·재로딩 검증 실패 | 성능 결론 보류, 기존 파일을 보존하고 실행 문제부터 점검 |

어느 경우에도 같은 한 사진의 합성 결과를 실제 불량 검출률이나 독립 사진 일반화 성능으로 해석하지 않는다.
기존 Q90 기준선·정식 SuperSimpleNet 모델·서비스·임곗값은 변경하지 않는다.
