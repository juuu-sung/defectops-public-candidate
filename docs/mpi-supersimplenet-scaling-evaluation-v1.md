# SuperSimpleNet 확대 학습 모델 전체 비교

2026-10-07. 정상 학습량 비교 A/C/D가 완료됐다. 세 최종 모델을 고정해 같은 관찰 자료에서 검출·오경보·위치 반응·실행 비용·보정 민감도를 모두 비교한다. 기존 12장 실패는 더 이상 전체 평가 중단 조건이 아니다. 새로운 학습이나 주 평가 임곗값 조정은 하지 않는다.

## 고정 자료와 평가 순서

각 모델을 독립 프로세스에서 순차 로딩한다. 임의의 다른 checkpoint를 선택하지 않는다.

1. 수령 ZIP, 최종 모델, 정상297장 캐시 영수증과 환경을 대조한다. 정상 첫8사진에서 raw 지도·native logit·사진 점수 오차1e-4 이하와 판정 변화0을 확인한 뒤 시험을 시작한다.
2. 불량55장·정상54장과 별도 정상256장 전체를 평가한다. 기존12장의 검출 유지는 별도 결과로 기록하고 실패해도 계속한다. 최종 모델과 이미 계산된 각 모델의 경고선을 그대로 쓴다.
3. 정상 첫20장에 예열5회 후3회 반복, 총60회 사진 단위 속도를 측정한다. Q90도 별도 프로세스로 같은 방식으로 측정한다. 시간 상한이나 속도에 따른 다음 단계 생략은 없다. 모델 로딩·결과 저장·UI는 이 지연시간에 포함하지 않는다.
4. 모든 불량55장과 정상 고점수6장의 저장 지도에서 결함 위치 통계를 계산한다. `defect/0006`은 손상된 정답으로 사진 전체 위치 평가에서 제외하지만 사진 검출에는 포함한다. GT는 분류 점수나 경고선 산출에 사용하지 않는다.
5. 개발128장만 / 보정169장만 / 양쪽을 바꾸는200회씩 총600회 정상 재표집을 수행한다. A/C/D/Q90에 같은 원본사진 인덱스를 쓴다.12영역은 묶어서 뽑는다. 주 판정은 그대로 두고 진단용 보정만 다시 계산한다. 무효 반복은 교체하지 않고 개수와 이유를 남긴다.

전체 정확도·속도가 낮아도 모든 단계를 실행한다. 기술 오류, 무결성 실패, 메모리 상한 초과만 중단한다. 기존 연구 목표 TP53/55 보존, FP2/54·12/256 이하와 보정 안정성 기준은 설명용 비교 항목으로 남기지만 자동 모델 승인 또는 후속 평가 차단 조건은 아니다.

## 지도 해석과 결과 보존

지도는 사진 분류 점수와 다른 출력이다. 영역별 분류 점수의 경고선 대비 차이, 결함 안/밖 평균과 최대, 타일 내부 AUROC, 상위656픽셀의 GT 겹침 범위를 기록한다. 동점은 범위로 표시한다. 타일 지표를 전체 제품의 독립 성능으로 해석하지 않는다.

모든55불량은 수치로 비교한다. 시각 카드는 고정12장과 각 정상 평가군 최고3장씩 총18사진·36장/모델을 담는다. 색상은 SSN 원점수 −1~1 고정 범위로, 확률이나 픽셀 판정이 아니다. Q90은 검증된 기존 지도가 있을 때 같은 사진을 나란히 표시하며, 파일 부재는 명시하고 새 지도 추론으로 숨기지 않는다. Q90 색상은 타일 내부 순위라 모델 간 색 강도를 직접 비교하지 않는다.

기존12장을 제외한 추가 미탐도 모든 raw 지도와 수치가 남는다. 전달 ZIP에는 JSON과 선택 카드만 넣고 최종 가중치·전체 raw 지도는 연구실에 보관한다. 기존 fit 폴더와 ZIP은 수정하지 않는다. 완료 사진·진단·재표집 단위로 원자적으로 저장하며 재개할 때 영수증을 검증한다.

## 연구실 실행

같은 기존 환경을 사용하며 추가 패키지 설치는 없다. 다른 GPU 작업을 정상 종료한다. 디스크20GiB 이상, 모델 시작 시 GPU여유6GiB가 필요하다. 프로세스 RAM20GiB·PyTorch GPU reserved6GiB 상한은 유지한다. 검사 시간 상한은 없으며 소요시간은 실제 실행 전 확정할 수 없다. 세 모델과 이미지 카드·보정 반복을 포함하므로 장시간 실행을 허용한다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_scaling_evaluation.ps1'
```

기본 원본은 `Downloads\extracted.zip`이다. 경로가 다르면 `-Archive '실제 경로'`를 지정한다.

전달 파일: `C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-scaling-evaluation-v1.zip`.

Ctrl+C를 한 번 누르고 작업 종료를 기다린다. 정상 기록된 중단은 같은 명령으로 이어간다. 강제 종료·일반 오류는 결과를 삭제하거나 재학습하지 말고 오류를 전달한다. 실행 중에는 git pull이나 fit 실행을 병행하지 않는다.

## 해석과 다음 결정

학습 확대의 이득은 검출 수뿐 아니라 어떤 불량을 새로 잡고 잃었는지, 정상 오경보, 정상 표본 변경에 대한 민감도로 판단한다. 각 모델의 경고선 숫자 크기만 비교하지 않는다. 재표집 범위는 미래 성능 신뢰구간이 아니다.

이미 관찰한55/54/256이므로 탐색·회귀검증이다. 최고 성적 모델을 새 독립 시험 결과처럼 주장하거나 자동으로 서비스에 배포하지 않는다. 결과 수령 후 A/C/D/Q90을 한 표로 비교하고 추가 학습 여부를 결정한다. 기존 Q90과 transistor 서비스는 유지하며 자동 PASS는 계속 금지한다.
