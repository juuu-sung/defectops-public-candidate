# SuperSimpleNet 새로운 합성 이상 구분 실험

같은 정상 타일을 반복해서 보더라도 처음 보는 합성 이상을 구분할 수 있는지 확인한다.
이전 고정 문제 학습은 손실을 낮췄지만, 이상을 넣지 않은 정상에서도 학습 때 이상이 있던 위치에
반응했다. 이번에는 학습 때마다 이상 위치와 잡음을 바꾸고, 학습에 사용하지 않은 난수로 평가한다.
실제 불량 시험이나 새 이미지에 대한 일반화 검증은 아니다.

## 바꾸는 조건과 유지하는 조건

변경 조건은 합성 이상 생성용 난수 순서 하나다. 정상 사진 1073의 기존 앞쪽 8영역 타일,
원래 300 epoch 모델 복사본, 특징 변환부와 검출부, AdamW 시작 학습률, 잡음 표준편차 0.015,
Perlin 기준 0.6, 500회 업데이트는 이전 제한 학습과 같다. 특징 추출기는 고정한다.
고정500 모델을 이어 학습하는 것이 아니다. 원본에서 새 최적화기로 다시 시작한다.

| 구분 | 난수와 사용 목적 |
| --- | --- |
| 새 학습 | 10000부터 10499까지 순서대로 500개, 업데이트당 하나 |
| 공통 평가 | 900001·900002·900003·900004, 가중치 업데이트에 사용하지 않음 |
| 이전 문제 재현 | 42, 이전 기록과 대조하는 별도 참고값 |

여기서 학습 미사용 난수는 이번 500회 업데이트에 사용하지 않는다는 뜻이다.
같은 정상 사진의 특징을 계속 사용하므로 새로운 제품이나 촬영 조건을 검증하는 자료는 아니다.
정답이 한 종류뿐인 학습 묶음이 나오면 조용히 다른 난수로 바꾸지 않고 중단한다.
평가에서 한 종류가 없으면 해당 AUROC를 미정의로 기록하고 평균에 포함한 난수 개수를 함께 보고한다.

## 한 명령으로 진행하는 순서

1. 원본 모델과 이전 고정500 결과 ZIP·로컬 체크포인트의 해시와 환경을 확인한다.
2. 이전 고정500 모델을 읽기 전용으로 불러와 공통 평가 난수 4개와 참고 난수 42를 평가한다.
   난수 42의 결과가 지난 ZIP과 허용 오차 0.0001 이내인지 확인한다. 이 모델은 추가 학습하지 않는다.
3. GPU에서 이전 모델을 해제하고 원래 300 epoch 모델의 새 복사본을 불러온다.
   0·50·100·200·300·400·500회에 동일한 평가 묶음을 기록한다.
4. 최종 모델을 다시 불러와 평가 난수 5개의 원시 점수·지도와 모델 지문을 검증한다.

평가 시 잠시 학습 모드의 출력을 측정하더라도 기울기와 최적화기 업데이트는 없다.
BatchNorm 통계와 난수 상태는 평가 전으로 복원한다. 두 모델의 평가 이상 위치 해시가 같은지도 확인한다.
추론 모드가 주 비교 대상이며 학습 모드 수치는 통계 차이를 살피는 진단이다.

## 결과에서 확인할 것

원본 모델, 이전 고정500 모델, 새로운 변경500 모델을 같은 평가 문제에서 비교한다.
난수 42는 이전 고정 모델이 학습한 문제이므로 새 난수 4개 평균과 반드시 분리한다.
각 난수의 결과와 정의 가능한 난수의 평균을 모두 남긴다. 네 번의 합성 결과를 독립적인 실제 제품 표본으로
취급하거나 실제 불량 검출률의 신뢰구간으로 해석하지 않는다.

- 사진 분류와 위치 AUROC가 높아지는지 확인한다. 사진 분류는 이번 배치의 타일 단위 분류다.
- 동일 정상 특징에 이상을 넣었을 때 분류 점수와 해당 위치 반응이 얼마나 증가하는지 확인한다.
- 이상을 넣지 않은 정상 지도도 과거 이상 위치에서 높게 반응하는지 확인한다.
- 같은 위치의 정상·합성 이상 점수만 비교한 AUROC도 함께 본다. 전체 배경과의 순위만 좋아지는 착시를 줄인다.
- 원시 출력 0 기준 양수 비율은 진단용이다. 실제 경고 기준이나 정상 오경보율로 보고하지 않는다.

공통 새 난수에서 구분력이 개선되고, 정상 대조와의 차이도 커지면 다음 정상 다양성 확대 설계의 근거가 된다.
위치 순위만 높고 정상 대조도 비슷하면 암기나 배경 반응이 남았을 가능성이 있다.
고정 문제에서만 좋고 새 난수에서 나쁘면 합성 문제 내 일반화가 부족한 것이다.
한 실험으로 실제 불량 성능이나 이전 전체 학습 실패 원인을 확정하지 않는다.

중간 최고 점수를 보고 모델을 고르지 않는다. 사전에 정한 500회 결과와 전체 궤적을 검토하며,
실험이 끝나도 자동 합격·서비스 전환·새 불량 평가·학습 연장은 없다.

## Windows 실행

이전 정식 fit 폴더, `artifacts\analyses\mpi-supersimplenet-learnability-v1` 폴더와
`artifacts\handoff\mpi-supersimplenet-learnability-v1.zip`을 그대로 둔다.
다른 GPU 작업을 정상 종료한 뒤 실행한다. 새 다운로드나 패키지 업그레이드는 없다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed. Stop here.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_varying.ps1'
```

기본 원본 경로는 `Downloads\extracted.zip`이다. 새 결과는
`artifacts\analyses\mpi-supersimplenet-varying-synthetic-v1`에 별도로 저장한다.
완료 후 `artifacts\handoff\mpi-supersimplenet-varying-synthetic-v1.zip`을 전달한다.
ZIP에는 수치·원시 지도·진행 기록·체크섬만 들어가며 원본 이미지·특징 텐서·모델 가중치는 포함하지 않는다.

## 자원 제한과 중단 대응

누적 계산 30분, RAM 20 GiB, GPU reserved 6 GiB, 디스크 여유 8 GiB 조건을 유지한다.
시작 전 원본 해시 검증과 최종 ZIP 내보내기 시간은 계산 예산 밖이다.
두 모델을 GPU에 동시에 올리지 않는다. 실제 소요시간은 연구실 결과로 확인한다.

정상적인 Ctrl+C는 같은 명령으로 마지막 완료 체크포인트부터 이어간다. 미저장 작업은 재실행하지만
학습 난수는 업데이트 번호로 정해져 있으므로 바뀌지 않는다. 재실행을 포함한 총 시도 업데이트는 650회 이하다.
이전 고정 모델의 완료된 대조 평가는 다시 실행하지 않는다.
강제 종료·자원 초과·기록 불일치는 자동 재개하지 않는다. 파일을 삭제하거나 난수를 바꾸지 말고 오류를 전달한다.
기존 원본 모델·고정500 모델·경고 기준·Q90·서비스는 변경하지 않는다.
