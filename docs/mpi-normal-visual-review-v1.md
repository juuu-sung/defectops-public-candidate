# MPI 정상 사진 원본 검토 실행 안내

정상 표본을 다시 뽑았을 때 경고 기준이 크게 바뀐 이유를 확인하기 위해, 선정한 정상 사진
10장의 원본을 검토합니다. **연구실 전달 ZIP의 검증과 외관 검토를 완료했습니다.**
[수령 결과와 다음 점검 제안](../reports/mpi-normal-visual-review-v1-received-review.md)을 참고하십시오.
이는 재학습이나 성능 평가가 아닙니다. 기존 Q90 연구 기준선, 모델, 임곗값, 데이터 구성은 유지합니다.

## 이번에 확인하는 내용

[정상 표본 영향 분석](../reports/mpi-normal-influence-v1-review.md)에서 개발 정상128장으로
영역 변동 폭을 추정하는 단계와 보정 정상169장으로 사진 경고 기준을 정하는 단계가 모두
표본 구성에 민감했습니다. 수치만으로는 정상적인 외관 차이와 확인이 필요한 품질 문제를
구분할 수 없어 원본을 봅니다. 높은 점수는 불량·라벨 오류·사진 제거의 근거가 아닙니다.

| 구분 | 사진 ID | 선정 이유와 우선 확인 영역 |
| --- | --- | --- |
| 개발 정상 | 1554, 1681, 1570 | 낮은 검출 반복에서 Q90 경계 지지 상위3장, grid3-2 |
| 개발 정상 | 1582, 0432 | 검출 유지 그룹과 원래 고정 분위수 경계의 대조 사진, grid3-2 |
| 보정 정상 | 1671, 0616, 0705 | 낮은 검출 반복의 경계 상위3장, 각각 grid2-1, grid1-2, grid4-1 |
| 보정 정상 | 1365 | 원래 고정 경계 대조 사진, grid1-1 |
| 보정 정상 | 0290 | 포함 횟수와 검출 수의 음의 연관성 최다, 12영역 전체 |

결과를 보고 고른 진단용10장이며 무작위 대표 표본이나 제외 명단이 아닙니다.
0290의 연관성과 다른 사진의 직접 경계 지지 횟수는 서로 다른 통계입니다.
각 사진의12영역을 모두 포함하므로 총120개 정상 타일입니다. 원본의 경로는 모두
`extracted/{region}/train/good/{photo_id}.png`입니다. 개발·보정은 우리 실험의 역할 구분입니다.

## 연구실 Windows 실행

프로젝트의 기존 가상환경과 Pillow를 사용합니다. GPU와 모델 파일은 필요하지 않으며,
다른 GPU 작업을 종료할 필요도 없습니다. 원본 압축파일의 기본 위치는
`C:\Users\user\Downloads\extracted.zip`이며 실제 사용자 프로필 경로를 자동 사용합니다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_mpi_normal_visual_review.ps1
```

원본 위치가 다르면 마지막 명령에 `-Archive 'D:\데이터\extracted.zip'`처럼 실제 경로를 지정합니다.
처음에는 약2.8GB 압축파일의 전체 SHA256을 확인하므로 디스크 속도에 따라 시간이 걸립니다.
압축파일 전체 바이트 해시와 ZIP 목차를 읽지만, 이미지 디코딩은 고정한 정상120타일만 합니다.
시험 이미지·마스크를 읽는 전체 ZIP 검사는 실행하지 않습니다.

완료하면 아래 ZIP만 이 대화에 첨부합니다. 2.8GB 원본 전체를 보내실 필요는 없습니다.

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-normal-visual-review-v1.zip
```

직접 보고 싶으시면 다음 명령으로 로컬 검토 화면을 엽니다. 별도 서버는 필요하지 않습니다.

```powershell
Start-Process '.\artifacts\analyses\mpi-normal-visual-review-v1\result\index.html'
```

## 화면과 전달 자료

- `index.html`: 선정 이유, 우선 확인 영역, 사진별12영역 보기와 원본 링크.
- `photos/{사진ID}/`: 압축파일과 바이트가 동일한 원본 PNG12개, 색 보정 없는 모음 이미지,
  사진 정보 및 파일 검증 기록.
- `selection.json`:10장 선정 근거, 원본·선행 검증 자료 해시,120타일의 파일·RGB 픽셀 해시.
- `report.json`, `receipt.json`: 검증 수와 범위, 코드·환경·출력 파일 해시.

원본 PNG는256×256입니다. 모음 이미지는 원본 픽셀을 그대로 붙이고 바깥에 영역 이름만 표시합니다.
화면에서는 줄여 보일 수 있으므로 세부 확인은 원본 링크를 사용합니다. 3열4행 배열은 검토용
목록이며, 겹치는 영역이 있으므로 전체 기판의 기하학적 복원이 아닙니다. 이상 지도도 아닙니다.

밝기·위치·부품 패턴 차이, 흐림·잘림처럼 눈으로 확인되는 사실을 사진 ID와 영역과 함께 기록합니다.
이 화면에는 검토 저장·삭제·판정 버튼이 없습니다. 전달 후 에이전트가 원본을 확인하고 결과를
설명하므로, 먼저10장을 모두 직접 판정하실 필요는 없습니다.

## 안전장치와 재개

기존 준비 ZIP의 고정 해시와 내부 파일 목록을 확인하고, 그중120개의 검증된 원본·픽셀 해시를
설정에 동결했습니다. 원래 점수 자료의 정상 cohort와 경로도 대조했습니다.
실행 시 압축파일·설정 해시, 선택 경로, PNG 형식·크기·내부 체크섬, RGB 픽셀 해시를 검사합니다.
새 점수 계산, 데이터 제외·교체, 모델 변경, 임곗값 변경, 자동 PASS는 없습니다.

사진별 완료 결과는 임시 폴더에서 검증을 마친 뒤 게시합니다. 중간에 끊기면 같은 명령을 다시
실행하여 검증된 완료 사진부터 재사용합니다. 미완료 시도 폴더는 보존하지만 재사용하지 않습니다.
완료 파일이나 환경·코드가 달라지면 덮어쓰지 않고 중단합니다. 이 경우 삭제하지 말고 오류를 보내십시오.
전체 압축파일 해시는 재실행할 때도 확인합니다. 동시에 두 번 실행하면 두 번째 실행은 중단합니다.

MPI-PCB 데이터의 이용 조건이 명확해지기 전 이미지·파생 시각화를 공개 재배포하지 않습니다.
이 ZIP은 요청한 비공개 검토 전달용입니다. Git과 Notion에는 이미지 대신 코드·선정 메타데이터·결정만 남깁니다.

## 검증 범위와 다음 결정

Mac 합성 이미지 시험19개로 고정 대상만 접근, 원본 보존, 잘못된 해시·PNG 거부,
중단 재개, 기존 증거 보호, 명령 인자 연결, 동시 실행 차단을 확인했습니다.
전체450개 테스트와52개 subtest가 통과했고 기존 경고3개는 유지됐습니다.
합성 모음 이미지의 글자·영역 배치와120타일 픽셀 보존도 확인했습니다. 이후 연구실의 실제 전달
ZIP에서120개 원본과10개 모음 이미지를 검증하고 외관을 확인했습니다. Mac에서 Windows
명령을 직접 실행한 것은 아니며, 전체 원본 압축파일 해시를 이번에 다시 계산하지는 못했습니다.

ZIP 수령 후 파일 검증과10장 외관 비교를 완료했습니다. 정상적인 다양성이면 자료를 삭제하지 않고
표본 대표성·보정 방법을 검토합니다. 객관적인 품질 문제가 의심되면 전체 자료에 적용할 수 있는
독립적인 품질 규칙부터 검토합니다. 외관만으로 원인이 정해지지 않으면 미확정으로 남깁니다.
그 근거를 바탕으로 다음 후보 하나의 실험 카드를 결정하며, 이번 검토 자체는 새 후보가 아닙니다.
