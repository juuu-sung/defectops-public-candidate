# MPI PatchCore 정상 개발자료 확대 비교

완성된 정상256장 PatchCore 모델은 그대로 두고, 정상 점수의 범위를 추정하는 개발자료를128장에서256장으로 늘린다. 모델 재학습이나 bank 재구성이 아니다. 기존128장을 유지하고 추가128장을 고정 규칙으로 선정한다. 기존 불량55장 검출을 보존하면서 정상 오경보와 보정 민감도를 개선할 수 있는지 한 번에 확인한다.

## 변경하는 것과 유지하는 것

| 항목 | 기존 | 이번 후보 |
| --- | --- | --- |
| 모델 학습 정상 | 256장 | 동일 |
| 대표 특징 bank | 78,643개 | 동일 파일 |
| 정상 척도 개발자료 | 128장 | 기존128장＋추가128장 |
| 사진 경고선 보정자료 | 169장 | 동일 |
| 점수 | 지도 상위1% 평균 → 영역 중앙값·Q90 폭 →12영역 최대 | 동일 산식 |
| 경고선 | 보정169장 사진 점수 Q95 higher, 이상이면경고 | 동일 산식, 새 수치는 별도 계약에 보관 |
| 시험 | 불량55장·정상54장·정상검증256장 | 동일 저장 원점수 재사용 |

중심·폭이 바뀌면 같은169장에서 계산한 사진 경고선도 자연스럽게 달라진다. 경고선 숫자를 임의로 조정하거나 불량 정답으로 최적화하지 않는다. 모델·기존 계약·서비스는 덮어쓰지 않는다. 기존 Q90 64장 모델이 아니라 **같은256장 모델＋개발128장**이 직접 비교 기준선이다. 이 기준선은55/55 검출·1/54 및16/256 오경보였다.

## 추가 정상 선정

고정된 `mpi-normal-diversity-preparation-v1.zip`의 적격풀1,086장을 사용한다. 풀은 손상·불완전 사진,보호 자료,알려진 시험 픽셀 및정확한 중복을 제외했던 목록이다. 풀 ID와12영역 픽셀 지문 해시를 확인한다.

1. 현재 학습256장과과거 다양성 비교에 사용한 학습64장을 제외한다.
2. 개발128장·보정169장·정상검증256장의 원본 ID 및모든 시험·보호 자료와같은 픽셀을 제외한다. 시험의사진번호는 별도 네임스페이스이므로 번호만 같다는 이유로 동일 사진으로 간주하지 않는다.
3. 남은 사진을 `SHA256(실험이름 + NUL + additional-development + NUL + photo_id)` 순서로 정렬해첫128장을 선택한다. 점수·외관·성적을 보고 선택하지 않는다. 부족하면 중단하며역할 이동·중복 보충·다른 난수 재선택은 금지한다.
4. 12영역 모두 원본 바이트 및디코딩 픽셀 지문을 재검증한다. 선택명단과실행소스 지문을 저장한뒤추론한다.

현재 보존 풀은 기존 보호 자료를 제외한 풀이다. 현재 학습 256장과 과거 학습 64장이 서로 모두 다르다고 보수적으로 계산해도 766장이 남을 규모다. 실제 선정 수·명단·지문과 추가 교집합 검사는 연구실의 원래 풀 ZIP으로 확정한다. Mac에는 그 풀 ZIP 실물이 현재 없으므로 실제 새 128장 명단까지 로컬 검증했다고 표현하지 않는다.

미사용은 지정된 학습·개발·보정·평가 역할에 사용하지 않았다는 뜻이다. 적격 풀 전체는 과거 정상 특징 기반 선정 과정에서 관찰되었다. 정확한 픽셀 분리는 같은 물리적 기판·촬영 세션·유사 사진의 독립성을 보증하지 않는다. 이번 결과는 모두 탐색·회귀검증이다.

## 명령 하나로 진행되는 네 단계

1. **자료와 모델 확인:** 원본 ZIP,이전결과,고정모델과환경을검증한다. 추가128사진의1,536타일을읽어검사하고기존보정정상8사진을재추론해점수·지도·판정을대조한다.
2. **추가 정상 추론:** 추가128사진만계산한다. 사진마다12영역점수와지도를원자적으로저장한다. 기존개발128·보정169·시험109·검증256의원점수는변경하지않고재사용한다.
3. **새 계약과 재로딩:** 개발256장으로중앙값과Q90−중앙값폭을계산하고같은보정169장으로Q95경고선을고정한다. 같은모델을해제후다시불러와추가정상중처음8장을재현한다. 점수·지도최대차이≤1e-4,판정변경0이어야한다.
4. **전체 비교:** 저장점수로전체55불량·54/256정상판정,증감사례,AUROC,600회보정민감도를계산한다. 고정12장검사는설명용이며실패해도전체비교를중단하지않는다. 새시험이미지·정답mask를읽거나GPU로재검사하지않는다.

검사 속도와 위치 지도는 모델·계산 방식이 같아 직전 측정을 참조한다. 이번에 새 속도 측정이나 새 위치 성능을 얻었다고 표현하지 않는다. 각 실행 시도의 전체 경과 시간과 메모리 최고값을 기록하며, 단계별 정밀 시간 측정은 하지 않는다.

## 재표집과 통과 기준

기존과같이개발만·보정만·양쪽각200회,총600회로검사한다. 원본사진을단위로12영역을함께뽑는다.

- 기준선은이전128장재표집인덱스600회를그대로재현하고결과건수가같은지검증한다.
- 후보는256장전체에서256개를복원추출한다. 기존128＋추가128을각각고정수로뽑는층화표집이아니다.
- 보정169장인덱스는양쪽모델이같이사용한다. 개발집합크기가다르므로개발인덱스까지같다고주장하지않는다. 후보개발난수는PCG64 seed81001·81003으로고정한다.
- 무효폭/비유한시행은숨기거나다시뽑지않고실패로기록한다. 고정계약의폭이0이거나비유한이면기술오류로중단한다.

정확도목표는 **현재검출55/55 보존·오경보≤2/54 및≤12/256**이다. 정상시험오경보가1→2라면목표이내여도증가사실을표시한다. 민감도는각조건검출하위2.5백분위≥50,검출백분위폭≤직접기준선폭＋0.5,오경보상위97.5백분위≤5/54·25/256,무효시행0이다. 백분위는현재자료에대한민감도이며미래성능신뢰구간이아니다.

정확도·민감도실패는결과로남기고전체비교를완료한다. 입력손상·모델변경·재현실패·메모리초과는즉시중단한다. 통과하더라도자동서비스승인·자동PASS는하지않는다. 실패했다고표본·경고선·학습량을자동추가탐색하지않는다.

## 연구실 실행과 재개

다른GPU작업을정상종료한다. 시작시디스크5GiB·GPU여유6GiB가필요하다. RAM20GiB·PyTorch reserved6GiB 제한은유지하고시간상한은두지않는다. 모델초기화·원본해싱·파일저장이있어사진추론시간만으로전체시간을보장하지않는다. 재학습이나긴대표선택은없다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_patchcore_development_scaling.ps1'
```

원본기본경로는 `Downloads\extracted.zip`이다. 이전 `mpi-patchcore-scaling-v1.zip`, `mpi-normal-diversity-preparation-v1.zip`, `artifacts\mpi-patchcore-scaling-v1` 모델및정상지도캐시는그대로둔다. 새결과는 `artifacts\analyses\mpi-patchcore-development-scaling-v1`에저장한다.

Ctrl+C는한번누르고정리가끝날때까지기다린다. 같은코드·입력으로같은명령을다시실행하면완료사진을재사용한다. 실행중git pull하지않는다. 일반오류·자원초과·강제종료는파일을보존하고오류를전달한다. 실패기록을지우거나출력폴더를임의교체하지않는다.

완료후전달파일:

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-patchcore-development-scaling-v1.zip
```

전달 ZIP은 명단·계약·점수·판정·민감도·검증·시간/메모리 및 영수증만 포함한다. 모델·원본 이미지·대형 지도는 연구실에 유지한다.

## 실행기 검증 범위

Mac CPU 전체 테스트에서 1,118개 통과, 6개 건너뜀, 하위 검사 52개 통과를 확인했다. 새 검사 15개에는 자료 분리, 고정 선정, 600회 재표집, 불량 성적과 무관한 전체 비교 완료, 중단·재개, 캐시 변조 거부, 모델 보존 및 동일 결과 재출력이 포함된다. 실제 Windows PowerShell·CUDA 실행은 연구실에서 확인해야 한다. 로컬 가짜 실행 장치를 사용한 흐름 검사를 GPU 성능 검증으로 해석하지 않는다.
