# 모델 실험 카드 — 실행 전 작성 양식

상위 계획: [모델 개발 통합 계획](model-development-plan-v1.md).
이 파일은 빈 양식이다. 실제 실험은 복사해 고유 ID로 기록하고 실행 전에 커밋한다.
빈 항목·`미정`이 있는 카드는 GPU 실행/최종 시험 승인으로 쓰지 않는다.

- 실험ID / 계획버전 / Phase / 작성일 / 승인자·승인기록:
- 유형: 읽기전용진단 / 정상학습 / 점수보정 / 개발비교 / 독립최종평가 / 비용측정
- 한문장질문:
- 근거보고서·반증가능한가설:
- 바꾸는요인정확히1개:
- 유지할항목(checkpoint·자료·전처리·bank크기·점수·보정규칙 등):
- 이번사이클후보한도중몇번째인가 / 이전실패:
