# SuperSimpleNet 합성 이상 반응과 학습 추론 모드 점검

2026-10-05. 현재300epoch 모델을 다시 학습하지 않고, 학습 때와 같은 방식으로 만든 합성 이상을
찾을 수 있는지 확인한다. 실제 결함 위치에 반응이 약했던 원인을 좁히기 위한 기능 점검이다.
이 실행은 추가 학습이나 새 모델 선택, 실제 불량 성능 평가가 아니다.

## 왜 점검하는가

이전 지도 진단에서 위치 비교가 가능한11사진의 결함 포함63영역 중 SSN 상위656픽셀과 정답이
겹친 영역은3개였다. 같은 영역에서 기존 Q90은52개였다. 위치 AUROC의 영역별 단순 평균은
각각0.38261과0.93693이었다. 선택 사례의 탐색적 통계이며 전체 데이터 성능이 아니다.

같은 정상 사진을 오래 반복하기 전에, 모델이 학습한 합성 이상에는 반응하는지 확인한다.
정상64장의 다양성이 충분하다는 뜻도, 추가 학습이 무의미하다는 뜻도 아니다.

## 고정 입력과 비교 방식

- 정식 학습 manifest 순서의 첫8개 학습 정상 사진과 첫8개 개발 정상 사진을 사용한다.
  개발 사진은 가중치 학습에 사용하지 않았지만 독립 최종 시험 자료는 아니다.
- 각 사진의12영역을 사용한다. 192타일을8개씩 묶고 고정 난수42·43으로48회 검사한다.
  이는 서로 다른192사진이나 독립768개 사례가 아니다. 원본 사진은16장이다.
- 사진에 가짜 흠집을 그리지 않는다. 기존 Anomalib2.2.0 합성 생성기가 특징에
  표준편차0.015 잡음과 Perlin0.6 마스크를 적용하도록 그대로 호출한다.
- 공식 학습 forward를 실행하되 역전파·optimizer 호출은 없다. 생성 직전 정상 특징과
  생성 직후 혼합 특징을 hook으로 받아, 정확히 같은 혼합 특징을 추론 모드에서도 비교한다.
- 원본8개 특징은 공식 생성기 안에서16개로 복제된다. 그 모두가 불량은 아니다.
  생성 마스크가 비어 있으면 그대로 기록한다. 유리한 결과를 얻기 위한 재추첨은 없다.

| 출력 | 비교 목적 |
| --- | --- |
| train_mixed | 학습 모드가 같은 합성 이상을 구분하는가 |
| eval_mixed | 고정 추론 모드에서도 같은 합성 이상을 구분하는가 |
| eval_clean | 같은 원래 정상 특징과 비교해 합성 이상 점수가 올라가는가 |

학습 모드는 현재 묶음 통계를, 추론 모드는 저장된 통계를 이용하는 BatchNorm을 포함한다.
학습 모드의 통계 변화는 메모리에서만 일어나며 즉시 복원한다. 원본 checkpoint에 저장하지 않는다.
BatchNorm의 모드 차이는 정상적인 설계이므로 차이를 발견해도 곧바로 버그라고 판정하지 않는다.
고정 묶음은 과거300epoch의 원래 셔플 묶음을 재현한 것이 아니므로 당시 학습 손실과도 구분한다.

## 확인하는 안전성과 수치

공식 소스 지문·최종 checkpoint·동결 가중치·기존 보정 계약을 확인한다. RGB/255와 ImageNet
정규화가 한 번만 적용되는지 독립 계산으로 대조하고, 분리한 추론 경로와 공식 전체 forward의
사진 점수·지도 차이가1e-4 이내인지 확인한다. 개발 정상 첫 타일의 저장 예측도 재현한다.

마스크 밖 특징은 그대로인지, 빈 마스크 사례의 추론 결과가 정상 특징과 같은지 검사한다.
각 검사 전후 모델 전체 가중치·버퍼 지문을 확인한다. 임시 모드 변경 전후 정상 예측도
같아야 한다. 난수 상태와 학습 모드 상태를 복원하며 중간 예외 때도 버퍼를 복원한다.

결과에는64×64 원시 위치 지도, 합성 정답 마스크, 분류 원점수, 모드별 분류·위치 AUROC와
손실 구성값을 포함한다. 64지도 통계는 이전256지도 진단 수치와 직접 같은 지표로 비교하지 않는다.
점수0 초과 비율은 학습 목적의 설명용일 뿐 서비스 경고 기준이나 자동 합격 규칙이 아니다.
특징 텐서·원본 사진·모델 파일은 전달 ZIP에 넣지 않는다.

## 연구실 실행

다른 GPU 작업은 정상 종료한다. 추가 패키지 설치나 재학습은 필요 없다.
기존 fit·handoff와 원본을 유지한다. 기본 원본은 Downloads의 extracted.zip이다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
git rev-parse --short HEAD
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_synthetic_check.ps1'
```

실행 중 학습 업데이트는0회다. GPU를 쓰지만 장시간 학습 명령은 아니다. 아직 실제 Windows
소요 시간은 측정하지 않았다. 계산 누적 상한15분, RAM20GiB, PyTorch GPU 예약6GiB,
시작 시GPU 여유6GiB와 디스크 여유2GiB를 요구한다. 입력 해시 검증·내보내기는 계산 상한 밖이다.

완료하면 아래 파일을 전달한다.

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-synthetic-check-v1.zip
```

완료 묶음은 지문 검증 후 재사용한다. 정상적으로 처리된 Ctrl+C 중단은 같은 명령으로 이어갈 수
있으며 실패한 시도도 시간과 횟수에 포함한다. 총 시도 상한은50개다. 강제 종료로 종료 기록이
없거나 자원 한계·예측 불일치 오류가 나면 자동 재시작하지 않는다. 파일을 보존하고 오류를 전달한다.
파일 삭제, 조건 축소, 합성 재추첨, 예산 확대는 자동으로 하지 않는다.

## 결과 이후 결정

합성 이상도 약하면 학습 동작·손실·특징 잡음 크기와 저장 추론 통계를 먼저 점검한다.
학습 모드에서만 강하고 추론에서 약하면 같은 특징에서 확인된 모드 차이를 추가 분석한다.
두 모드 모두 합성 이상에는 강하지만 실제 결함에는 약하면 합성 이상과 실제 결함의 차이 및
정상 다양성 확대를 검토한다. 이것만으로 원인이 하나라고 확정하거나 BatchNorm을 고쳐 서비스에 쓰지 않는다.

현재 모델·기존 Q90·보정 기준·서비스는 그대로 유지한다. 정상 원본256장 확대나 epoch 연장은
이 결과를 근거로 별도 조건을 정한 뒤 진행한다.
