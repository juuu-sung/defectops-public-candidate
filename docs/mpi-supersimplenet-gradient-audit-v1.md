# SuperSimpleNet 정상과 합성 이상의 학습 신호 진단

2026년 10월 6일. 잡음 강도 비교에서도 구분력이 개선되지 않아, **정상과 이상을 구분하도록 요구하는 학습 신호가 어디에서 약해지거나 충돌하는지** 확인한다. 가중치를 업데이트하지 않는다. 검출부 초기화 비교는 이 결과를 검토한 뒤 필요하면 별도로 설계한다.

## 이번에 비교하는 것

기존 정식 300 epoch 모델, 잡음 0.015 varying500 모델, 잡음 0.06 varying500 모델을 읽기 전용으로 불러온다. 이전과 같은 정상 한 사진의 8개 영역 타일을 사용하고, 잡음 0.015와 0.06 및 난수 900001부터 900004까지를 고정한다. 총 **3개 모델 × 2개 강도 × 4개 난수 = 24회 진단**이다. 강도 후보를 새로 탐색하는 것이 아니다.

학습 때 사용한 공식 forward로 점수를 구하고, 저장된 직전 학습 모드 출력과 최대 절대차 0.0001 이내인지 확인한다. 역전파로 신호를 계산하지만 optimizer.step은 호출하지 않는다. backbone은 고정하며 평가 동안 바뀔 수 있는 BatchNorm buffer와 모드, 난수 상태, 잡음 강도를 원복한다.

## 무엇을 측정하는가

학습 신호인 gradient는 “이 손실을 줄이려면 가중치를 어느 방향으로 얼마나 바꿔야 하는가”를 나타낸다. 손실을 아래 여섯 항으로 나누되 **기존 손실의 가중치와 평균 분모는 바꾸지 않는다.**

| 손실 | 정상 부분 | 합성 이상 부분 |
| --- | --- | --- |
| 위치 truncated L1 | 정상 픽셀의 별도 평균 | 이상 픽셀의 별도 평균 |
| 위치 focal | 정상 항의 합 ÷ 전체 픽셀 수 | 이상 항의 합 ÷ 전체 픽셀 수 |
| 분류 focal | 정상 항의 합 ÷ 전체 샘플 수 | 이상 항의 합 ÷ 전체 샘플 수 |

여섯 손실의 합이 공식 전체 손실과 일치하는지 확인한다. 각각의 gradient 합도 공식 전체 손실에서 직접 구한 gradient와 비교한다. 최대 절대차 0.00001 또는 상대 L2 차이 0.001 이내여야 한다.

특징 변환부, 위치 검출부, 분류 convolution, 분류 최종층별로 다음을 기록한다.

- 각 손실이 전달하는 신호 크기와 연결되지 않은 parameter 수
- 정상 신호와 이상 신호의 방향 유사도인 cosine
- 두 신호를 합쳤을 때 크기가 얼마나 남는지
- 신호 내적 행렬과 합 재현 오차, 입력 출력 재현 오차

cosine이 음수면 해당 입력과 상태에서 두 신호가 반대 방향이라는 뜻이다. 그것만으로 학습 실패 원인이 확정되지는 않는다. 0인 신호의 cosine은 계산 불가로 기록한다. 분류 손실이 stop-gradient 설정으로 위치 검출부에 전달되지 않는 등 설계상 연결되지 않은 경로도 있으므로, 모두 코드 오류로 해석하지 않는다.

이 값은 **원시 gradient**이며 AdamW의 momentum·적응적 크기 조절·weight decay까지 적용한 실제 업데이트 방향은 아니다. 기존 학습 난수와 분리됐지만 이미 관찰한 네 합성 난수이고, 같은 한 사진의 타일들이므로 실제 불량·새 사진 일반화 성능도 아니다.

## 실행과 보존

원본 ZIP과 기존 fit, fixed500, varying500, noise-strength 폴더 및 handoff를 보존한다. 이전 결과의 해시·공식 코드 버전·세 모델의 상태를 확인한 뒤 실행한다. 새 데이터·실제 불량·시험 mask는 사용하지 않는다. 임곗값과 서비스도 바꾸지 않는다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_gradients.ps1'
```

기본 원본은 `Downloads\extracted.zip`이다. 완료 후 다음 파일을 전달한다.

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-gradient-audit-v1.zip
```

반복 역전파가 있어 정확한 시간은 연구실 실행에서 측정한다. 누적 실행 상한 45분, RAM 20 GiB, PyTorch GPU reserved 6 GiB, 디스크 여유 2 GiB다. 모델 로딩 전 GPU 여유 6 GiB가 필요하다. gradient 벡터는 CPU에 임시 보관해 GPU 사용량을 줄이고, 전달 ZIP에는 벡터나 모델 가중치가 아닌 요약 내적·수치·출력 배열만 포함한다.

정상적인 Ctrl+C 중단 후에는 같은 명령으로 완료된 진단을 재사용한다. 시도 30회 상한과 누적 시간을 적용하며 실패·자원 초과·강제 종료는 자동 재시도하지 않는다. 결과를 지우거나 난수를 다시 뽑지 말고 오류를 전달한다.

## 다음 판단

먼저 손실·gradient 합 재현과 원본 보존을 확인한다. 신호가 어느 부위에서 충돌하거나 약해지는지 근거가 생기면, 해당 원인을 겨냥한 한 가지 변경만 비교한다. 기존 학습 상태의 영향을 확인할 필요가 있으면 **같은 입력·학습률·횟수에서 검출부 초기화 여부만 바꾸는 대조 실험**을 다음 단계로 설계한다. 이 진단 결과만으로 자동 초기화·재학습하거나 정상 사진 수와 학습 시간을 확대하지 않는다.
