# MPI 정상 다양성 후보 점수 변화 분리 진단

2026-10-02. 사용자 진행 동의에 따른 CPU 진단 계약이다. 계산 전에 이 문서를 고정한다.
두 모델을 섞은 새 후보나 세 번째 성능 실험이 아니다. 저장 원점수만 읽으며 모델·이미지·마스크를 열지 않는다.

## 질문과 계산

기존 모델에서 후보2로 바뀌면서 생긴 경고 여유 변화가 원점수, 정상 중앙값, 정상 폭,
사진 경고 임곗값에 어떻게 나뉘는지 계산한다. 경고 여유는 다음과 같다.

`margin = max_over_12_regions((raw - center) / scale) - threshold`

0 이상이면 경고다. 양의 기여는 경고를 높이는 방향이며 정상에는 나쁘고 불량에는 유리할 수 있다.
이는 변화의 산술 설명이지 물리적 원인이나 앞으로의 정확도 개선을 증명하는 수치가 아니다.

네 요소 각각에 기존/새 값을 넣는16가지 상태를 계산한다. 네 요소를 바꾸는 모든24가지 순서에서
한 요소가 추가될 때의 경고 여유 차이를 구하고 균등 평균한다. max 영역이 바뀌는 경우도 매번
다시 계산한다. 평균 기여 합계는 실제 두 결과의 경고 여유 차이와 일치해야 한다.
순서별 최소/최대 기여도 같이 보존하며 이것을 신뢰구간으로 해석하지 않는다.
동점 영역은 전부 기록하고 대표 영역은 고정12영역 순서의 첫 영역을 사용한다.

중앙값·폭·threshold는 같은 정상 자료와 모델에서 파생돼 서로 의존한다. 중간 조합은 실제
정상 보정을 거친 유효 모델이 아니다. 중간 상태의 정확도·FP/FN을 계산하거나 순위를 매기지 않는다.
기여도의 합산·상쇄가 있을 수 있으므로 전체 평균 하나로 원인을 단정하지 않는다.

## 입력과 고정 조건

- 기존: 검토된 `mpi-spatial-score-v1.zip`, SHA256 `8429a970864c1116d5f52b786057fc84c3e48f465b5c502715ab7f61d35e13dc`.
- D단계 실제 원본 기준선: `mpi-score-validation-v1.zip`, SHA256 `4f995562c08b3c768ff591025a5f22db01daad5d52020b2d296912f4814bd73a`.
  공간 재현본과 원점수·명단이 완전히 같음을 확인하고, 이 원본의 지문이 D단계 기록과 같아야 한다.
- 후보2: 검토된 `mpi-normal-diversity-evaluation-v1.zip`, SHA256 `7d2d859341ffdd1607fe8982de11063fbd796c0a174dfbe86c095729d49ad5f4`.
- 두 ZIP의 CRC·파일 목록·payload 해시, 후보2에 기록된 기존 원점수 지문·동결 실행 소스를 검증한다.
- 정상128/169장에서 기존 median/Q90/Q95 계약을 재계산해 원계약과 점수 오차≤1e-12·판정 차이0을 요구한다.
  실제 모델의 보정값을 바꾸는 작업이 아니라 기록 재현이다.
- 관찰 시험109장과 정상256장, 총365장을 하나도 빼지 않고 분석한다. 정상 보정297장은 계약 재현용이다.
- 추가 미탐3장과 정상256장 제거8/추가13 오경보는 필수 설명 대상이다. 유리한 사례를 새로 뽑지 않는다.

## 성공과 중단

실제 두 결과의 사진 순서·라벨·영역·경로·계수·미탐/오경보 명단을 재현한다.
실제 끝점 점수와 기여 합계 오차≤1e-10, 판정 변화0을 요구한다. NaN·0에 가까운 폭·누락·변조는 중단한다.
CPU 계산30분·프로세스 peak RSS2GiB 상한이다. 입력 검증과 계산을 포함하며 최종 파일 쓰기는 제외한다.
넘으면 축소·재선정하지 않는다. 출력은 새 파일에만 기록하고 기존 결과는 덮어쓰지 않는다.

분석 성공은 성능 통과가 아니다. 결과를 근거로 변경 방향을 제안할 수 있지만 새 후보 실행·학습은
별도 카드와 동의가 필요하다. 새 독립 시험·자동PASS·서비스 교체는 하지 않는다.
기존 보정 민감도3,000회는 재실행하지 않으며 이미 검산한 실패 상태를 유지한다.

## 재현 방법

Mac 저장소 루트에서 실행한다. Windows/GPU 작업은 필요 없다.

```sh
.venv/bin/python scripts/analyze_mpi_diversity_score_changes.py \
  --baseline-zip "$HOME/Downloads/mpi-spatial-score-v1.zip" \
  --evaluation-zip "$HOME/Downloads/mpi-normal-diversity-evaluation-v1.zip" \
  --validation-zip "$HOME/Downloads/mpi-score-validation-v1.zip" \
  --output reports/mpi-diversity-score-decomposition-v1-results.json
```
