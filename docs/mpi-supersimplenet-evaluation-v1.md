# SuperSimpleNet 최종 모델의 불량 검출과 실행 비용 검증

2026-10-05. 정상 자료로 학습한 300epoch 모델을 고정하고 기존 불량 검출을 유지하는지 확인한다.
학습 완료는 검출 성능의 증거가 아니다. 이번 실행은 학습을 늘리거나 임곗값을 바꾸지 않는다.
이미 관찰한 MPI 자료를 사용하므로 결과는 탐색 및 회귀검증이며 독립 일반화 성능이 아니다.

## 실행 순서와 중단 기준

1. **정상 8사진 재현:** 연구실의 최종 모델·정상 예측 파일·보정 계약을 수령 ZIP과 대조한다.
   정상 보정 명단 첫 8사진에서 원점수·지도·사진 점수 차이가 각각 1e-4 이하이고 판정 변화가 없어야 한다.
   가중치 지문도 정식 학습 최종 지문과 같아야 한다. 실패하면 불량을 열지 않는다.
2. **기존 검출 12사진:** 이전부터 고정한 명단과 순서를 그대로 검사한다. 12/12 유지 시만 다음 단계로 간다.
   하나라도 놓치면 정상 종료된 실패 결과 ZIP을 만든다. 나머지 불량·속도·민감도는 검사하지 않는다.
3. **전체 비교와 반복 속도:** 불량 55사진, 시험 정상 54사진, 별도 정상 256사진을 비교한다.
   두 모델을 GPU에 순차 로딩해 같은 정상 사진으로 속도를 잰다. 전체 성적이 실패해도 비용은 기록한다.
4. **보정 민감도:** 전체 성적과 후보 속도가 모두 통과한 경우에만 정상 자료를 사진 단위로 재표집한다.
   개발만·보정만·둘 다 변경하는 세 조건에서 각 200회, 총 600회다. 모델과 원점수는 그대로이고
   개발 중앙값·Q90 폭·보정 Q95만 다시 계산한다. 주 비교의 임곗값 파일은 바꾸지 않는다.

12사진 순서는 `0006, 0025, 0048, 0000, 0054, 0051, 0013, 0033, 0038, 0001, 0034, 0042`이다.
모두 `defect/` 사진 ID다. 이들은 기존 검출 사례이므로 12/12 자체는 전체 검출률 추정치가 아니다.

## 고정 모델과 판정 방식

- 학습 결과 ZIP SHA256: `ae4ccc9e7164e2a052efd1c3ef9be600f956f9fbab8eae7898e1f1cda73ce2e7`.
- 최종 모델 SHA256: `727be89a18c9f8e00eeb5824f157cdb16d99097197d3f8fb7650bc077ff1891e`.
- `step-028800/model.pt`만 사용한다. 중간 모델 비교나 최적 checkpoint 선택은 하지 않는다.
- 타일 점수는 분류 head의 부호 있는 원점수다. 지도 최대값·확률·0 이상 값으로 변경하지 않는다.
- 정상 개발128사진으로 구한 영역별 중앙값과 Q90 폭을 사용한다. 사진 점수는 표준화한 12영역 최대값이다.
- 정상 보정169사진의 Q95 경고 기준 **2.0253641229135124**를 그대로 사용한다. 경계는 `>=`다.
- 실제 불량 마스크를 읽지 않는다. 원시 지도는 향후 설명용으로 연구실에 저장한다.
- `0054`는 이전 외부 평가에서 승인된 복구 PNG를 바이트·픽셀 해시 검증 후 사용한다.
  원본 손상을 무시하거나 새로 복구하지 않는다. 복구 파일이 없으면 중단한다.

## 전체 비교의 합격 조건

| 항목 | 기준 |
| --- | --- |
| 불량 검출 | 55장 중 53장 이상이며 기존에 잡았던 53장을 모두 유지 |
| 시험 정상 오경보 | 54장 중 2장 이하 |
| 별도 정상 오경보 | 256장 중 12장 이하 |
| 반복 사진 처리 시간 | 정상 사진 하나의 12영역 처리 p95가 2초 이하 |

기존 Q90 기준선은 검출 53/55, 정상 오경보 3/54·14/256이다. 총 검출 수가 같더라도
기존 불량을 놓치고 다른 불량을 잡는 교환은 검출 보존 통과로 보지 않는다.

속도는 같은 정상 보정 첫20사진을 3회 반복하고 그 전에 첫5사진으로 준비 실행한다.
ZIP 읽기·픽셀 검증·디코딩·전처리·추론·지도 전송·사진 점수 계산을 포함한다.
모델 로딩·파일 저장·화면/API 응답은 제외한다. 따라서 서비스 전체 응답시간으로 표현하지 않는다.

보정 민감도는 기존 비교의 난수 seed와 수치 기준을 유지한다. 검출 수 2.5% 분위수≥50,
검출 구간 폭≤기준선 폭+0.5, 오경보 97.5% 분위수≤5/54·25/256이어야 한다.
분모가 퇴화한 표집은 실패로 기록하며 다시 뽑지 않는다. 이 구간은 정상 보정 민감도이지
새 모집단 성능 신뢰구간이 아니다. SuperSimpleNet에는 EfficientAD의 지도 분위수 보정을 적용하지 않는다.

## 연구실 실행 명령

기존 파일을 유지하고 다른 GPU 작업을 정상 종료한 뒤 실행한다. 패키지를 새로 설치하지 않는다.
GPU 여유 6GiB, 디스크 여유 12GiB가 필요하다. 시간은 학습과 별개로 평가 누적 4시간 상한이며,
실제 소요 시간은 연구실 측정 전이므로 확정하지 않는다. 12장 실패 시 이후 계산은 생략한다.

```powershell
Set-Location 'C:\개인 프로젝트\defectops'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Git update failed; stop here.' }
git rev-parse --short HEAD
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_mpi_supersimplenet_evaluation.ps1'
```

기본 원본은 `Downloads\extracted.zip`이다. 기존 `artifacts\handoff`의 준비·비교 ZIP,
`artifacts\mpi-supersimplenet-fit-v1` 학습 폴더, Q90 모델,
`artifacts\evaluations\mpi-pcb-external-evaluation-v2\recovery\grid1-3-defect-0054.png`를 재사용한다.
누락되면 임의 대체하거나 다운로드하지 않고 오류를 보고한다.

완료하면 다음 파일을 전달한다. 성능 기준을 통과하지 못했더라도 생성된 ZIP을 전달한다.

```text
C:\개인 프로젝트\defectops\artifacts\handoff\mpi-supersimplenet-evaluation-v1.zip
```

세부 출력은 `artifacts\analyses\mpi-supersimplenet-evaluation-v1`에 저장한다.
Ctrl+C 정상 중단은 동일 명령으로 검증된 사진 단위 결과를 재사용할 수 있다.
OOM·해시 변경·자원 상한·강제 종료 등 오류는 자동 재시도하지 않는다. 파일 삭제나 임곗값 변경 없이
오류를 전달한다. 완료 후 재실행은 기존 결과를 검증해 내보내며 새 검사를 하지 않는다.

## 결과 해석과 다음 결정

불량 결과는 아직 없다. 12장 실패 시 놓친 사례의 원점수·위치 지도를 검토하고 바로 재학습하지 않는다.
모든 비교 기준을 통과해도 자동 채택하지 않는다. 기존 Q90 기준선과 transistor 서비스,
자동 합격 금지 상태를 유지한 채 결과를 검토한다. CPU 모의 테스트는 CUDA 정확도 증거가 아니다.
