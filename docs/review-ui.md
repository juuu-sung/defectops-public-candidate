# 맥북 로컬 작업자 검토 화면

연구실 Windows의 검사 결과 **전체 폴더**를 맥북으로 복사해 [검토 저장소](review-store.md)에
등록한 뒤, 맥북에서 원본·오버레이·히트맵과 모델 점수/임곗값을 나란히 확인하는 화면이다.
모델 추론은 이 화면에서 수행하지 않는다. 등록된 검사 1건을 읽고 사람이 관찰한 의견을
별도 이력으로 남긴다.

## 실행 — 맥북에서만

프로젝트 폴더에서 한 번만 설치한다. Python 3.11 이상이 필요하다.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[data]' -r requirements/ui.txt
```

검사 결과가 이미 등록되어 있다면 다음 명령으로 화면을 연다.

```sh
python scripts/serve_review_ui.py
```

맥북 브라우저에서 `http://127.0.0.1:8501`을 열면 된다. 종료는 실행 중인 터미널에서
`Ctrl+C`를 누른다. 기본 DB는 `artifacts/review/reviews.sqlite3`이며 다른 로컬 DB가
필요하면 `python scripts/serve_review_ui.py --db <DB 경로> --port 8502`를 사용한다.
명령은 네트워크 전체가 아닌 `127.0.0.1`에만 연결한다. 이 화면에는 로그인 기능이 없으므로
포트 포워딩·외부 공개·여러 사람의 동시 사용을 하지 않는다.

## 화면에서 하는 일

1. 검사 ID를 선택한다. 목록에는 모델 판정과 최근 검토 revision이 함께 표시된다.
2. 원본과 모델 오버레이를 비교하고 필요하면 히트맵·영역 좌표·실행 근거를 펼친다.
   모델 점수는 결함 확률이나 심각도가 아니다. `PASS`도 자동 합격을 의미하지 않는다.
3. 실제로 이미지를 보고 확인한 내용(`이상 징후가 보임`/`눈에 띄는 이상 없음`/`판단 보류`),
   검토자 표기, 관찰 근거를 입력한다. 확인 체크 후 **검토 의견 저장**을 누를 때만 새 이력이
   기록된다. 기존 모델 판정은 바뀌지 않는다. 검토자 표기는 인증된 신원이 아니다.
4. 저장된 의견은 아래 검토 이력에서 확인한다. 이력은 덮어쓰지 않고 revision을 추가한다.

원본 검사 폴더와 모든 등록 checksum을 매번 재검증한다. 이미지가 바뀌거나 빠졌으면
화면 표시와 의견 저장을 모두 중단한다. 검사 자체가 실패한 기록에는 시각적 판정을
입력할 수 없다. 다른 화면에서 먼저 검토한 경우 revision 충돌로 저장이 거부되므로
새로고침 후 다시 확인해야 한다.

## 현재 한계

- 로컬 1인 데모용이다. 인증, 장비 간 자동 전송, 승인/거부 워크플로우, SOP 연결은 없다.
- 검토 의견은 화면 관찰 기록이지 실제 공정의 합격·원인 확정·안전 인증이 아니다.
- MVTec 이미지는 연구·비상업용 데이터다. 원본, 파생 이미지, DB를 Git에 넣거나 외부에
  공개하지 않는다.
- 2026-09-18 현재 실제 등록 검사 1건의 원본·오버레이 화면과 저장 전 revision 0을
  맥북에서 확인했다. 사람의 실제 의견은 입력하지 않았다.
