# MPI 정상 순위 기반 영역별 경고 비교

2026-10-03 실행 전 규칙. 구조 검토·구현·비교를 묶어 진행하라는 사용자 동의 범위의 단일 CPU 후보다.
정답 사용 가능성 진단의 경계는 쓰지 않는다. 기존 raw top1·bank·12영역은 유지하고 모든 영역에
같은 정상 순위/오경보 배분 규칙을 적용한다. 특정 영역 제외,사진ID 예외,임곗값 탐색은 없다.

## 정상 자료만 쓰는 규칙

기존 개발128장과 보정169장을 새 버전에서는 정상 보정297장으로 합친다. 기존 Q90 계약은 그대로
비교 기준으로 보존한다. 정상 bank64장, 관찰 시험109장, 관찰 정상256장은 보정에 추가하지 않는다.
이 변경은 정상-only 영역 점수/사진 집계 구조 한 가지를 대체한다. 기존 개발/보정 역할 변경은 숨기지 않는다.

영역r의 입력 점수x에 대해 p_r=(1 + 정상297개 중 x 이상인 점수 수)/298이다.
사진 경고는 어느 영역이라도 p_r≤0.05/12인 경우다. 동점은 정상 꼬리 수에 포함한다.
정수로는240×(1+꼬리 수)≤298이며, 이 표본 수에서는 꼬리 수0일 때만 가능하다.
즉 각 영역에서 관찰 정상297개의 최댓값을 **엄격히 초과**하면 경고하는 구조다.
동일한 정상 점수도 경고하는 기존 >= 규칙과 다르며 새 계약에 명시한다.

12영역 동시 검사의 보수적 위험 배분이다. 유한 표본 p값의 기본 정의는
[Royal Holloway 연구팀 설명](https://cml.rhul.ac.uk/CP/)을 참고했다. 5%/12 배분과 표본 해상도는
위 식에서 직접 산출했다. 169개로는 최소p=1/170>0.05/12여서 이 엄격한 규칙으로 경고할 수 없다.
최소239개가 있어야 경고 가능한 순위가 생긴다. 297개가 충분한 통계적 검증 표본이라는 뜻은 아니다.
교환가능성·동일 분포 가정이 실제 MPI 실물/세션에서 확인되지 않았으므로 미래 오경보5% 보장은 주장하지 않는다.
영역별5%를 그대로 쓰면 사진 전체5%가 되지 않으므로 그렇게 기준을 완화하지 않는다.

## 성적 전에 고정한 종료 조건

- 기존 Q90의662장 재현, 원점수/명단/계약/ZIP 해시 검증 후 새 정상 계약을 저장한다.
- 기존 검출53장 모두 유지, 정상54장 FP≤2, 정상256장 FP≤12를 모두 요구한다.
- 고정 성적이 실패하면 **즉시 비채택, bootstrap 미실행**. 그 상태를 안정성 검증 완료로 표시하지 않는다.
- 고정 성적이 모두 통과한 경우만 기존과 동일한3상황×1,000회 paired 재표집을 실행한다.
  각 반복에서 기존128/169장 인덱스를 함께 사용하고 후보는 둘을 합친297장으로 계산한다.
  하단TP≥50·폭≤기준선절반·FP상단≤5/25·무효0 조건을 유지한다.
- CPU 누적30분·RSS2GiB, 추가 공식·alpha 변경·표본 재선정·자동 재시도 없음.
- 정답 진단 해를 초기값으로 쓰지 않는다. 이 후보가 실패하면 순위/영역 경계 후보 추가를 멈추고
  현재 점수에서 정상과 결함을 분리하는 표현력 문제와 지원 범위의 재설계로 넘어간다.

현재 자료는 모두 관찰된 탐색/회귀 자료다. 정상만으로 계약을 계산해도 독립 평가가 되지 않는다.
학습·GPU 추론·서비스 교체·자동PASS·새 데이터는 없다. 결과 전 설계·실행기·테스트를 커밋한다.
