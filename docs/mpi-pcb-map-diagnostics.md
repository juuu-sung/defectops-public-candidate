# MPI-PCB: 놓친 불량의 저장 맵 원인 진단

상태: 코드·Mac 합성 검증 완료, **실제 연구실 맵 분석은 실행 대기** (2026-09-26).

## 무엇을 확인하나요?

이미 완료한 외부 시험에서 Real-IAD PCB / VisA PCB3 PatchCore는 불량 55장 중
각각 2장 / 3장만 경고했다. 이 단계는 그 성적을 바꾸는 학습이 아니라
**왜 놓쳤는지 기존 결과를 읽어 보는 진단**이다.

| 질문 | 읽어 볼 근거 | 주의점 |
| --- | --- | --- |
| 실제 결함에 반응이 약한가? | 결함 픽셀과 비결함 픽셀의 평균·최댓값, 같은 영역 안 점수 순위(AUC), 상위 1%와의 겹침 | 낮은 반응을 기술할 뿐 물리적 원인을 확정하지 않음 |
| 다른 정상 부분의 반응이 더 큰가? | 12영역 최고점 위치의 정답 존재 여부, 결함 포함 영역의 최고 점수와 차이 | 영역에 결함이 있어도 강조 픽셀이 결함과 일치한다는 뜻은 아님 |
| 작은 결함의 신호가 집계에서 약해지는가? | 결함 픽셀 수·범위, 상위 656픽셀에 들어간 결함 수와 점수 기여 비율 | 현재 입력이 이미 256×256이므로 축소 전후 정보 손실은 증명하지 못함 |

상위 1%는 `ceil(256 × 256 × 0.01) = 656`픽셀이다. 결함이 4픽셀이라면
그 4픽셀의 점수가 높더라도 나머지 652픽셀과 평균되는 구조다. 실제로 이 현상이
어느 사진에서 나타나는지는 맵 측정 후 판단한다. 상위 1% 경계에서 점수가 동률이면
임의로 픽셀을 고르지 않고 정답 겹침·점수 기여의 최솟값/최댓값을 둘 다 기록한다.
픽셀 판정 임곗값은 새로 만들지 않는다.

## 무엇을 바꾸지 않나요?

- 두 checkpoint, 고정 임곗값, 이전 성적, 원본 ZIP, 저장 맵 모두 읽기 전용.
- PyTorch/GPU 모델 로딩·추론·재학습·인터넷 다운로드 없음. CPU로 파일을 읽고 계산한다.
- 새 해상도·새 상위 비율·새 임곗값의 성능 탐색 없음.
- 기존 시험 109장을 모두 수치 분석. 12영역을 독립 사진 12장으로 세지 않는다.
- 시각 자료는 **불량 55장 전부(검출 성공 포함) + 정상 오경보 6장**.
  두 모델 모두 비경고인 정상 48장도 수치 검사와 맵 검증에는 포함한다.
- 이미 관찰한 시험의 탐색적 진단이며 자동 PASS·생산 판정·확인적 성능 주장 금지.

## 기존 데이터 예외를 유지하는 방법

1. 정상 중복 `good/0013`은 기존 평가에서 제외한 그대로 유지한다.
2. 복구 `defect/0054`는 v2 출력에 저장된 파생 PNG를 읽는다. 원본 손상 멤버의
   해시와 파생 PNG/RGB 해시가 기록과 일치해야 한다. 재다운로드·재복구하지 않는다.
3. 마스크 손상 `defect/0006`은 사진 점수 확인과 검토 카드에는 포함한다. 읽을 수
   있는 11개 정답은 표시하되 누락된 한 영역은 명시한다. **사진 전체를 모든 위치
   요약 통계에서 제외**하여 위치 통계의 불량 분모는 54장이 된다. 없는 마스크를
   빈 정상 마스크로 대체하거나 추정하지 않는다.

검증 순서: 검토한 v2 ZIP의 고정 SHA-256·내부 JSON 해시 → 고정 설정·109장 명단·판정
→ 원본 ZIP 전체 SHA-256 → 복구 파일 → 각 이미지/마스크의 바이트와 픽셀 기록
→ 저장 NPZ 218개의 해시·shape·dtype·영역 순서 → 2,616영역 상위 1% 점수 재계산.
맵은 `allow_pickle=False`로 읽고, 다른 경로·순서·NaN·음수·점수 차이 1e-5 초과 시
중단한다. 새 오류를 자동으로 제외하지 않는다.

## 연구실 Windows에서 실행

기존 v2 결과와 `Downloads\extracted.zip`이 있어야 한다. GPU를 쓰지 않으므로
검사 서버를 종료하거나 가상환경을 다시 설치할 필요는 없다. 파일 읽기·압축·그림 생성에
시간과 디스크 공간은 필요하다. 실제 소요시간은 아직 측정하지 않았다.

```powershell
Set-Location "C:\개인 프로젝트\defectops"
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw "Git update failed. Stop and share the error." }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_mpi_pcb_map_diagnostics.ps1"
```

완료 상태: `mpi_pcb_saved_maps_analyzed_post_test_exploratory`.
`map_files_verified`는 218, 검토 사진 수는 61이어야 한다.
아래 **새 파일 하나**를 첨부한다.

`C:\개인 프로젝트\defectops\artifacts\handoff\mpi-pcb-map-diagnostics-v1.zip`

직접 사진을 보시려면 완료 후 다음을 실행한다.

```powershell
Start-Process ".\artifacts\analyses\mpi-pcb-map-diagnostics-v1\index.html"
```

오류나 기존 출력 경고가 나오면 데이터를 지우거나 평가를 재실행하지 말고 메시지를
공유한다. 기존 폴더·ZIP을 덮어쓰지 않는다. 최종 진단 산출물은 검증을 모두 통과한 뒤
발행하며, 발행 중 실패한 진단 파일이 있으면 확인할 수 있도록 보존한다.

## 결과를 읽는 방법

- `analysis.json`: 전체/미탐/정상 오경보별 요약, 검증 개수, 해석 한계.
- `cases.json`: 전체 109장의 모델별·영역별 수치. 결함이 있는 영역별 수치를 사진 안에서
  평균하고, 그 사진 평균들의 중앙값을 요약한다. 겹치는 타일 픽셀을 합쳐 물리적 결함
  면적이나 독립 표본 개수라고 해석하지 않는다.
- `source-evaluation.json`: 바꾸지 않은 기존 성적의 사본.
- `index.html`: 한국어 설명과 검토 사진 목록.
- `cards/`: 61장 × 2쪽 = 122개 JPG. 한 쪽에 6영역씩, 왼쪽 원본+정답,
  가운데 Real-IAD 맵, 오른쪽 VisA 맵. 모든 12영역을 표시해 일부 영역만 골라 보지 않는다.
- `handoff-manifest.json`: 진단 파일의 SHA-256.

초록 테두리는 정답이다. 색은 모델별 **사진 경고 기준의 1.5배를 표시 상한**으로 삼아
고정하고, 이미지마다 최솟값/최댓값으로 자동 확대하지 않는다. 이는 표시 척도일 뿐
픽셀 불량 기준이 아니다. 높은 값은 포화될 수 있으니 숫자와 함께 보고, 서로 다른
모델의 색 농도만으로 우열을 비교하지 않는다. 확대가 필요하면 화면에서 확대하되,
이미 존재하지 않는 원해상도 세부를 복원했다고 부르지 않는다.

## 해석과 다음 결정

이 진단만으로 자동 원인 라벨을 만들거나 최적 모델을 선택하지 않는다. 결함 순위가
낮은 경우, 결함이 아닌 영역이 점수를 지배하는 경우, 결함이 상위 점수에 들어가도
기여가 작은 경우를 **증거와 그림으로 구분**한다. 축소의 인과적 영향은 고해상도 입력을
사용한 별도 통제 실험 없이는 미확인이다. 그 결과에 따라 새 정상 뱅크 학습 또는
전처리·집계 개발 실험을 설계하며, 이미 본 시험에 맞춘 개선을 독립 최종 성적으로
주장하지 않는다.

## 확인한 범위

- Mac의 `python -m unittest discover -s tests -q`: **221개 통과**. 신규 진단 테스트
  16개에는 동률·신호 희석·정상 영역 지배·맵 변조/순서/크기·누락 마스크·CLI 인자 연결·
  결과 보존 및 합성 109장 처리와 ZIP 생성이 포함된다.
- 실제 수령한 고정 v2 ZIP이 새 입력 검증을 통과하는 것을 확인했다.
- 합성 검토 카드를 생성해 배치·범례·모델별 숫자 표시를 직접 확인했다.
- Mac에는 전체 원본 ZIP과 연구실 맵이 없고 PowerShell도 없어 **실제 맵 분석 및
  Windows 실행은 아직 검증하지 못했다**. 합성 성공을 실제 진단 결과로 보고하지 않는다.
- 실행 시작 시 Git 작업 상태를 확인한다. 코드/설정 또는 추적되지 않은 파일 때문에
  중단되면 사용자 파일을 삭제하지 말고 상태를 공유한다.

검토 ZIP에는 출처를 표시한 파생 그림과 JSON/HTML만 포함한다. 원시 이상 맵,
checkpoint, 전체 데이터셋은 포함하지 않는다. 이미지·산출물은 Git에 올리지 않는다.
